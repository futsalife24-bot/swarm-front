# 回避と横移動射撃の修正

2026-10-09、公開版を操作したユーザーの指定により、低い踏み込みをローリングへ変更。回避距離・時間0.32秒・無敵時間・入力・通信仕様は変更しない。短い武器の床めり込みは以前の本人許容を維持し、体の接地と握りは検査する。

## 変更

- `restore-soldier-roll.py`で保存済み武器別ローリングの3クリップだけを現在のGLBへ移植。骨・形状・素材・他31動作・現在の背面装備ソケットを保持。入力baseはc529694のGLB（SHAはスクリプトに固定）。既存Blender原本と出力bankは `assets/blender/source/swarm_soldier_20261009/soldier-motion-20261009/`。出力SHAはroll-scope.json。
- 発射点は本人が許容した「体の中心に対して固定位置」を選択。権威側は従来から体中心＋高さ1.5。兵士の描画補間に対し射撃だけ未補間座標で出ていた差を解消し、描画体中心へ合わせる。0.065秒の発光のみ体に追従、発射後の弾・権威側着弾点は追従させない。敵と跳弾等の二次効果は従来の座標。

## 確認と限界

- 専用回帰6件＋既存兵士/再生テスト13件の計19件成功。client/Worker型検査成功。既存aim.testの期待1.25/実測1.875はbase c529694の独立展開でも再現。別紙ログ参照。
- ロール3種を240Hzで測定し、体の床下頂点0、最小高さ1.265mm。握り最大差はライフル約3.10mm、散弾銃約2.65mm、ロケット約2.02mm。回避中の武器の一瞬の床干渉は許容対象、全地形の保証ではない。
- `live/`は通常ソロ・通常敵あり・Controls自動入力。10ゲーム秒、61.6309実秒、172描画。左右射撃、装填途中切替、回避、回避後射撃を実状態で確認。映像は実時間を保持し、録画環境のコマ抜けがあるため滑らかさ/性能の証明にはしない。
- `fixed/` は `?review=roll-shot` の7.5秒・180コマを武器3種それぞれ保存。通常ゲームのstep/Rendererを使用し、敵なし・影なし・注目1人・24fps固定書き出し。前方4秒・左方向6.5秒の回避と復帰を確認。2回の間隔は既存の再使用待ち2.2秒以上。
- 実描画の発光と体中心＋高さ1.5の距離は、ライフル30コマ・散弾銃40コマ・ロケット3コマで最大0。発射済み弾は追従させず、ロケット実体・煙は従来の権威projectile座標を使用。着弾・威力を変えない。通常プレイや通信性能の証明とは区別する。
- 旧5198の検証ではService Workerのcache-firstにより描画コードが古く、発光計測0かつ旧踏み込みだった。そこで新しい5199へ移し、3種の実動作と発光計測が有効な記録だけ採用。録画のやり直しでもevent IDを巻戻せるようRendererの既存リセット経路を使用。検証サーバーの保存originは固定5198から実際の起動ポートへ変更（127.0.0.1限定を維持）。

主担当が回避・統合・実画面・監査/公開を担当、子1体が発射位置と局所テストを担当。子から再委任なし。モデルID/推論設定は未確認。
