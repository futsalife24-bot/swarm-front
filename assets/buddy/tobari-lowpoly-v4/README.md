## 形状変更

- 楕円の周囲へ均等に回り込んでいた前側の面を、正面を向く二枚の広い面と、側面へ折り返す面に変更。
- 左前端の最下部0.21m、右前端0.24mは前版の丈を維持。側面へ向かって裾を11〜25cm持ち上げ、ひし形・台形を意識した斜めの裾と角のある輪郭にした。
- 下部を横へ広げ続けず、正面の長い裾へ絞った。後方の襞も下部を短くし、裾が一周そろう筒状の形を解消。
- 前側は表裏のY方向間隔4mmの薄い面。顔、配色、3動作、骨数を継承し、白線位置を調整した。
