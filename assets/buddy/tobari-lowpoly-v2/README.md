# トバリ試作02：薄く広いマント状の外套

2026-11-04。本人の「外套はマントのようにもっと薄く広くして」に対応。

[前後比較](review/cape-comparison.png) ／ [12秒動画](review/tobari-motion.mp4) ／ [確認資料](review.html) ／ [編集用blend](tobari.blend) ／ [ゲーム用GLB](tobari.glb)

## 変更

- 外套と前襟の面厚を18mmから4mmへ削減。面中央の折れの深さを20mmから6mmにし、膨らみを抑えた。
- 全幅0.54mから0.82m。外側と後ろの襞を広げ、尖った細い先端を幅のある裾へ変更。
- 顔・細い琥珀スリット・浮遊する体を継承。白い二本線を新しい面位置へ合わせた。
- 待機・追従・開閉の3動作を継承。布シミュレーションは使用せず、7骨の動きで表現。

## 実測・検証

1,428三角形、1材質、1メッシュ、7骨、テクスチャ0枚。不透明・頂点色。GLB 288,956 bytes、blend 213,200 bytes。体高0.7324m。形状数・骨数は増加なし。
