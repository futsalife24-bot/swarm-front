# トバリ試作03：胴体を包む外套

2026-11-04。本人の「外套の向きが真横はおかしい。胴体を包むような角度にして」に対応。

[前後比較](review/cape-comparison.png) ／ [12秒動画](review/tobari-motion.mp4) ／ [確認資料](review.html) ／ [編集用blend](tobari.blend) ／ [GLB](tobari.glb)

## 修正

左右へ平たく広がっていた面を、胴体の前・側面・背面に沿う楕円断面へ変更。前に開き目を残して包む形にした。薄い面を維持し、表裏の頂点間隔は約3.2〜4mm。前襟は前版を継承。
全幅は0.82mから約0.6074m、奥行きは約0.4746m。面を回り込ませた分だけ横幅が減り奥行きが増えている。
開閉時の追加回転を前側約31.5度から17.2度、後側約12.6度から8.0度へ抑えた。白線の位置と向きも面に合わせて調整。

GLBを別途読み込み、境界差0m、色・階層・骨・3動作を確認。3フレーム間隔の最低点は地上0.1510m以上。[再読込み](review/roundtrip.json)
正面・側面・背面・斜め、兵士比較、844×390／640×360の0／1／4体を独立プレビューで確認。[描画検証](review/validation.json)
追加描画は1体あたり影なし1回、影あり2回。4体は協力4人各1体の仮定。PC CPU送信時間はGPU完了時間・スマホ性能ではない。
12秒・30fps・960×640の動画で待機・追従・開閉を確認。動画実再生と小画面操作も検証。[操作検証](review/ui-validation.json)
