# ヨスガ試作03：鳥類を意識した眼差し

2026-11-04。本人の「ただ楕円的に細くして角度を変えただけでは違う」「もっと鳥類のような眼光」に対応。前版の細い楕円形の目を置き換え、猛禽類を意識した目元の構造を作った。

[目元の拡大比較](review/eye-comparison.png) ／ [確認資料](review.html) ／ [12秒動画](review/yosuga-motion.mp4) ／ [編集用blend](yosuga.blend) ／ [GLB](yosuga.glb)

## 今回変えた形

- 眼窩の暗がりを作り、その内側へ琥珀色の円形の虹彩と黒い丸い瞳孔を配置。
- 額へつながる厚みのある上まぶたで虹彩の上部を覆い、目の下側に縁を追加。正面を見据える眼差しを、角度だけでなく遮蔽・陰影・色の対比で表現する。
- 小さいキャッチライトは形状と頂点色で表現。発光・追加テクスチャ・粒子は使用していない。瞳孔は縦スリットにしていない。
- 初期確認では上まぶたが虹彩の途中に線として重なったため、上部を面で遮る厚みに修正。正面・斜めで最終の被さりを確認した。
- 台形頭の輪郭・胴・尾・脚・配色・3動作を継承。目の追加で後続部位の乱数が変わらないよう生成状態を保持した。鳥のくちばし・耳・羽などは追加していない。
