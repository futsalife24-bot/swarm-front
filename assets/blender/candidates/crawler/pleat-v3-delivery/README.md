## 判定の範囲

造形は、乾いた被覆が示す獣らしい背と、その形に収まらない支持構造の不一致を表現。被覆の連続面と不均一な裾に整理したv3で固定。毛皮や骨格を他種へ強制する制作見本ではない。

未適用統合案は、0.45秒の発動、攻撃方向保持、攻撃後の追跡復帰、戦闘切替時の向き/Controller履歴消去を検査。18条件とリセット6条件は制作側の実Renderer検査に合格し、監査側は証拠照合と独立した実ロジック実行で確認した。監査側によるWebGL・正式tsc/Vitestの再実行ではない。

6条件すべてで確認したのは方向保持の解除。時刻巻戻りや非activeでアニメーションが即Idleになる保証ではない。第3案の新動画は作成しておらず、数値/実Renderer検査と新たな目視確認を混同しない。
