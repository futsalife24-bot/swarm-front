# P3-01 初回監査後の作業記録

原提出版 `submission1/` は凍結し、作業候補と混同しない。

原提出版の同一姿勢を通常/半透明で確認した結果、C1最大43.5mm、C2最大17.3mm、C3指定区間最大44.7mmの武器頂点の内包を記録した。3mmは報告閾値であり、許容値ではない。

局所試作では、ライフルの始点を80mm前へ、上半身を約17.2度斜めへ向けた。収納の冒頭に前方向への退避点を追加し、上半身は切替25%までに正面へ戻す。ロケットの保持を20mm上げ、側方で銃身を外へ向けて回す経路を試している。手の握りは武器に追従させ、武器だけを独立移動していない。元15Action、全身体比率、0.5秒・格納45%・取り出し60%を維持。

これらの試作でC1/C3の指定区間が改善しても、全区間に別の接触や回転の急変が残るため、P3-01合格とは扱っていない。確認済みの身体/前腕防具の線形スキニングとBlender評価メッシュの差は最大0.0003mm未満。単純なカプセル判定だけでは袖の表面を代表できなかったため、実頂点を使う `skin_clearance_solver.py` を追加した。

肘位置だけを変える試行で解消できない背面区間があり、ランチャーと手首/前腕の干渉が見つかった。現在の肩姿勢・固定握りに対する観測であり、全ての人体姿勢で成立しないという証明ではない。`render_clearance_proposal.py` はソケットを変更せず表示位置のみ比較する配置案。監査役へX=0.225→0.275/0.325/0.375mの限定試作を相談している。返答前にそのbind変更を実装しない。

回転の連続性は、肘32方向×前腕のひねり8方向と全フレームの経路選択で検討中。手・ソケットの世界行列は保持する。現在の試作は未合格。最終候補が決まった時点で検証JSON、近接画像、往復動画を揃え、実際に開いたうえで新しい提出フォルダーへ固定する。
