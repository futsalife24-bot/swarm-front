## 変更内容

- 人体の大きな形は第1段階から保持。身体ウェイトはheat weightingを初期値とし最大4影響へ正規化、胸郭はChestへ追従し襟・脇との境界を滑らかに配分。Blender専用のdual-quaternionには依存しない。
- 掌と各指は閉じた個別メッシュで、指の根元を掌内部に重ねる。指関節の前後にループを配置。隣指の骨の影響は渡さず、掌中央をHandに保持。全手袋が一体のmanifoldであるという主張はしない。
- 許可された指30本だけを、手首を原点としたキャラクター座標の幅1.24・厚さ1.22・長さ1.32へ適合。全身のroll再計算なし。開手/半握り/握り、左右・掌側/側面の通常画像と同カメラ骨投影で監査済み。
- 胸・背は短い剛体プレート。保存された服メッシュへレイを当てて断面を合わせ、厚み12mm、表面から10mmの中心間隔。白い別面は6mm厚。腹部の可動部分は空ける。肩は短い外側曲面、前腕は短い巻き形、膝は小さなカップ、脛は縦形に区別。ポーチ・溝・ボルトは追加しない。
- 背面2ソケットは専用非変形骨。全メッシュの使用ウェイト0、関連制約/ドライバー0を確認し、親Chest・名前・57本構成を保持して移設。武器側のローカル平行移動は0。二重の補正なし。短い剛体固定具を2個追加。

## 検証と限界

`stage2-validation.json`：元メッシュ頂点/面のハッシュ不変、保護5ファイルのSHA-256不変、元15Actionの全カーブ・全キー・補間/ハンドルのハッシュ不変。各Actionは570カーブ、そのうち指300カーブを含む。制約とドライバーなし。

表示20スキンメッシュの有限座標・1〜4影響・ウェイト合計1を確認。左右10指を1本ずつ動かし、他指/掌への不要な変形がないことを実評価頂点で確認。元アクションのデータ保持と、修正骨格で動作が合格することは別。連続動作・再ベイク・GLB/runtimeは未検証。

`render_poses.py` は保存blendを開き直して静止診断を生成。既存Actionから姿勢を読み、試作の両手IK・指・背面取付の姿勢を診断用に上書きするが、元Actionにはキーを書かず保存しない。これらは完成アニメーションではない。肘/膝120°は極端屈曲の局所確認であり接地した立ち姿ではない。

## 再現

Blender 5.2.1 LTSで以下を順に `blender --background --python <script>` として実行。すべてこのディレクトリーにだけ書き込む。実行すると中間候補を再生成するため、合格時の候補は別名保存してから再実行する。

1. `build_armor.py` → `fit_fingers.py` → `rebuild_glove_topology.py`
2. `refine_carrier.py` → `fit_torso_weights.py` → `seat_thorax_plates.py`
3. `fit_back_mounts.py`（変更前の診断画像と影響検証）、画像を開く
4. `fit_back_mounts.py -- --apply`（承認済み背面2本と固定具のみ）
5. `validate_stage2.py`、`render_poses.py`、`render_hand_fit.py`
6. Pillow入りPythonで `make_hand_boards.py` と `make_submission.py`

`diagnose_hand.py` と `test_weight_only.py` は旧骨/旧メッシュの診断記録。最終候補の生成経路ではない。`refine_carrier.py` の短縮板は実表面へ作り直す前の中間形状として非表示保存される。

監査記録：`finger-fit-approval.md`、`hand-pass-back-approval.md`。自己検証の数値を独立監査が実データ照合したとは扱わない。
