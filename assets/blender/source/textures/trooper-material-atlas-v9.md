# Trooper material atlas v9

Generated with the built-in image_gen tool on 2026-09-15 for this project. New asset, no source photograph copied. Four albedo regions (cloth, webbing, coated armor, ceramic) share one runtime texture; the model shader supplies the military palette. The untouched generated PNG is the source. Normal weave and the S-01 stencil are generated deterministically by build-trooper-design.mjs.

## Initial prompt

Use case: photorealistic-natural. Asset type: production game material ALBEDO TEXTURE ATLAS, one square image, precisely 2 by 2 equal square tiles with NO margins, NO separator lines, NO labels, NO text. This image will be applied as actual PBR diffuse textures to a near-future practical military trooper, not shown as concept art. Top left quadrant: tightly woven military ripstop combat fabric, fine irregular cloth fibers with faint large ripstop grid; no folds. Top right: rugged tactical nylon webbing canvas, coarser woven fibers with subtle linear thread bands, no straps or buckles. Bottom left: matte hard coated armor metal/polymer surface, very restrained fine rubbed wear, few tiny random hairline scratches, subtle grime variation; NO panels, NO objects. Bottom right: matte ceramic helmet coating, very fine pore grain, subtle tiny scratches and lightly handled wear. ALL four surfaces must be near-neutral LIGHT GRAY, average albedo about RGB 205,205,205, with understated local variation between 175 and 225, so that game shader colors can tint them. Orthographic macro material scan with completely even shadowless neutral illumination, no highlights, no directional shadows, no gradients, no borders, no perspective, no relief baked lighting. Each quadrant fills its area edge-to-edge and should tile seamlessly independently on both axes. Make the textures physically convincing, restrained and realistic, not grungy, not camouflage, not glitter. Large-resolution square atlas.
