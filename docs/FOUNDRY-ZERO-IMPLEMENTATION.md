# FOUNDRY ZERO 実装記録

2026-09-12。[制作コンセプト正本](FOUNDRY-ZERO-CONCEPT.md)と、その後ユーザーが「オッケー」で採用した統合初版に従う。「公開までやっていいよ」により公開まで承認済み。サブエージェントの担当範囲を分け、実装者以外による監査を実施する。

## 実装

- `src/shared/worm.ts` / `foundry-navigation.ts` / `foundry-defs.ts`：頭1＋胴7の固定スロット、連続した生存部位だけの鎖、地上巡回と障害物回避。通常4.2m/秒、胴体破壊後は全生存鎖6.3m/秒で生存・接続中プレイヤーを追跡する。頭部だけの破壊では高速化しない。
- `src/shared/foundry-spawning.ts` / `game.ts` / `stages.ts`：頭部破壊直前の接続胴体数を記録し、1回だけ追加生成。同一時刻の胴体破壊を先に反映。マップ別通常敵を等確率・重複可で抽選し、頭部周辺の通行可能地点へ配置する。40体上限・空リスト・場所不足ではキューを保持し、生成待ちを残したままwaveを終了しない。残存胴体は存続する。
- 各生存unitの光学部から0.8秒予告後、間隔3.2秒、基本威力10、60m/秒・100mの直進光弾を発射。砲口の3D距離で射程を判定し、連続した弾道とプレイヤー・壁・床の交差を計算してすり抜けを防ぐ。
- `src/client/foundry-worm.ts` / `foundry-worm-gait.ts`：独立した節・接続部・脚を保持したモデルを、5素材のBatchedMeshで描く。地上支持足と2関節の脚運び、分離表示、8砲口の照準、表示位置・向きの補間を担当。shared状態を書き換えない。
- `render.ts` / `enemy-viewer.ts` / `bestiary.ts`：連結炉を新モデルへ置換し、通常型は維持。報告文は形態別に切り替える。途中退出・遅延ロード・失敗時の代替表示と破棄に対応する。
- `server/testing.ts`：本番から参照されない隔離fixtureのみ追加。実Workerで頭部1HP・胴4切断の初期状態を用意し、その後の射撃・生成・同期は通常コードと通常入力で検証する。
