# ANOMALY ボイス再制作（2026-10-13）

本人がPR177公開版を「全部同じ音。高さが若干違う程度で、群れで分からなくなる」と不採用。v1は共通の声帯式・共鳴・包絡を用い、別パターンも主に0.91倍の音程差だった。技術的な読込・再生の確認を、聴感の採用判断と混同しない。

## 変更

- 生成元 `scripts/generate-anomaly-voices-v2.py`。8種それぞれ別の音源・発声順序を定義。v1生成元と音声は比較のため保持。
- HARROW: 非線形の声帯と不規則振動。前鳴き→長い咆哮。
- CALYX: 声帯なしの帯域ノイズ。吸気が膨らみ、閉口で急停止。
- VOLLEY: 明確に区切った二連吠え。各発声が急降下。
- LEAPER: 短い非線形の擦れ声を5〜6回。発声間隔と個数が変わる。
- PLEAT: 摩擦ノイズの塊と不規則な湿った破裂。
- PRISM: 呼気なしの非整数倍の殻共鳴、三段の打音。
- RAY: 高域の息を細かく刻み、後半のみ細い笛へ収束。
- FOUNDRY: 外殻の二打音と、長い座屈音。スマホで残る中域も含む。
- 種内の2パターンは回数・間隔・息継ぎ・終止が異なる。単純な一括移調は不使用。
- ゲームとエネミーレポートの参照先をv2へ統一。発声タイミング、同時2声、距離、消音制御、攻撃・モデルは変更なし。
- 試聴一覧に旧版8声の比較、2声ずつの4組（0.65秒差）、4声同時の2組を追加。すべてモノラルで、左右定位に依存しない比較。ミックスのみ音割れを避けるため各声を減衰。4声同時は実ゲームより厳しい試聴条件。

## 素材と再生成

`public/assets/audio/anomaly-voice-v2/`、PCM16 / mono / 32 kHz。16声は1.12〜2.10秒、合計1,686,464 bytes。ピークは−4.26〜−3.24 dBFS、RMSは−15.34〜−13.98 dBFS。無音端点・有限波形。初稿はRMSが低すぎたため、単発ピークで全体を下げる処理を滑らかな出力制限へ変えて調整した。外部サンプル・生成AI・外部API不使用、クレジット0。manifestに全WAVのSHA256とミックスの発声時刻を記録。

Python 3.12.14 / NumPy 2.3.5で `python scripts/generate-anomaly-voices-v2.py`。NumPyの数値処理変更でハッシュが変わり得るため、保存済みWAVが実行時の正本。
