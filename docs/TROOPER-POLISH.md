# 2026-09-10 走りの再監査・兵士の細密化

ユーザー指摘「ひょうきんで緊張感がない」「グラフィックがチープ」を受けた修正。前回の「滞空が存在する」中心の自己検証では、姿勢・重心移動・ゲーム内の武器保持を十分に評価できていなかった。本記録はCodex内の自己監査であり、外部監査承認ではない。

## 監査所見と修正

|所見|実装した対応|
|---|---|
|実行時の腰の上下差18.6cmに対し前傾8.0度。前進より跳ね上がりが目立つ|安定した前傾17.2度、周期の腰上下差5.5cmへ変更。着地の過度な沈み込みを抑える|
|膝屈曲約140度・足の前方リーチが大きく、足運びが誇張されている|膝屈曲約113度。着地を身体寄りにし、コンパクトな足の回復軌道へ|
|1周期3.6mで脚が忙しい|4.2m/周期。7m/s時は約0.6秒/周期、約200歩/分|
|走る下半身に立ち姿勢の上半身を合成していた|武器保持まで含むRun上半身を使用。前傾しても頭と銃口を水平に保持。射撃は走行姿勢に反動を重ねる|
|後退を逆再生していた|Run_BackwardとRun_Backward_Rocketを追加。時間を前へ進めた専用の着地・蹴り出しに変更|
|走り・待機・前後切替の姿勢が直接切り替わる|状態切替を0.08秒でブレンド|
|大きな面の角張り、少ない造形、材質の分離不足|細密形状、面取り、加重法線、微細テクスチャ、局所陰影、金属反射を追加|

判断の参考: [AnimSchoolの接地・荷重・蹴り出し解説](https://blog.animschool.edu/2024/04/10/the-key-poses-of-a-run-cycle/)、[MoCap Onlineのライフル姿勢・方向別移動](https://faq.mocaponline.com/en/articles/4127639-rifle-animation-packs)。上記角度・振幅は、本作の武器を構える兵士として選んだ演出値であり、研究が唯一の正解として示した値ではない。

## グラフィック

- ヘルメット: シール、通気ルーバー、レール、光学機器マウント、留め具、識別番号、バッテリーのラッチ。
- 胴体: 装甲のパネル境界、皿ねじと溝、刻印、装備取付帯とステッチ、弾倉ポーチの縫い目・縁・プルタブ。
- 腕・脚: 袖とズボンの折り目、肘・膝の蛇腹、分割された手袋の関節、装甲の留め具・通気溝。
- 靴: 鳩目、交差する紐、つま先の縫い目、底の縁。
- 背面: 点検ハッチ、識別文字、放熱口、固定フレーム、ジッパー、ケーブル。
- 面取りと加重法線で板の面と丸い部品を描き分ける。ベース色・粗さは512px、法線は256px。布柄の強すぎるコントラストを再調整。
- 9cm以内の局所遮蔽を16方向から計算し、頂点色へ焼き込む。大きな手足の影を固定していない。金属・バイザーだけに共通の小さな反射環境を使用し、ワールド全体の照明は変更しない。
- 拡大検査で胸脇の浮いた追加パーツ、ケーブル端、背面識別文字と旧マークの重なりを発見し、配置を修正。
- 本体は約6.7万三角形、6材質、24ボーン。元の約2万三角形より細密化。ゲーム内は同等材質を統合して本体6描画。4人＋武器＋床の検査は58描画、約28.9万三角形。
- 兵士と3武器をv3の別URLにして旧キャッシュと分離。旧v1/v2を保持。
