# FOUNDRY ZERO 描画の独立監査

2026-09-12。描画実装者とは別の Codex 担当が最終差分・検証 JSON・実表示画像を確認。以下の範囲に、残る必須修正は見つかっていない。外部 Chat 監査や AAA 品質の保証ではない。

## 対象と独立性

- `src/client/foundry-worm.ts`：固定8スロット、切断箇所の接続非表示、砲口座標・照準、描画バッチと資源の所有権。
- `src/client/foundry-worm-gait.ts`：34脚の支持点・関節長・空中の足送り・停止復帰。
- `src/client/render.ts`：表示用コピー、角度補間、非同期ロードの破棄、通常型との共存、レーザー表示。
- `src/client/enemy-viewer.ts`、`src/client/bestiary.ts`：フォーム切替、遅延ロードの破棄、連結炉に限定した説明。
- `scripts/check-foundry-render.mjs` と `dist-validation/foundry-production-render/` の最終証拠。

監査担当が編集した `src/shared/worm.ts` 等は、この独立監査の対象外。[shared 監査](FOUNDRY-ZERO-SHARED-AUDIT.md)で別担当が確認する。

## 指摘と修正確認

初回の緩い円弧だけの検証では、実際の shared 入力による急旋回を覆えていなかった。実移動・頭部破壊・胴体破壊の241 tickを723描画フレームで再現し、最短角の表示補間、最大4 rad/sの表示回転、最短0.11秒の足送りを確認した。節の中心経路は描画側で変更していない。

最終の同条件では表示角変化が最大0.046421 rad/frame、同一鎖の中心間隔は隣接最小3.026006 m・非隣接最小5.094181 m。`renderer-sharp-turn.png` の上面像でも、既知の折返しによる胴の重なりは見られない。この中心間隔は入力を含む再現計測であり、監査担当自身による shared 修正の独立評価には数えない。

切断後に固定インデックスを詰めず、各接続は両端の生存時だけ表示する。モデルの砲口を回転中心にして共通原点・標的から照準し、最大原点差は0.000000842 m。ロード中の削除・フォーム切替は状態同一性または世代番号で検出し、遅延して届いたモデルを破棄する。図鑑のモデル範囲は、親行列を更新した後の元メッシュだけから求め、未変換のバッチ頂点を重複計上しない。通常型の共存、ロード失敗時の代替表示、World 不変、削除時の離脱は最終 `checks.json` で成功し、該当コードも再読した。

## 足送りと残る確認範囲

実移動条件の支持足11,612サンプルで最大滑り約4×10⁻¹⁵ m、到達制限による補正は0。別の移動・停止条件では34足が接地へ復帰し、脚長・床下への誤差は浮動小数点精度内だった。

最大足移動は **0.502326 m/frame**。`movement.json` の tick 164/frame 0、`FZ_BODY_01_LEG_L1_FOOT` で、前後とも空中、足送りの全距離は1.811288 m。`maximum-foot-0.png` / `maximum-foot-1.png` を同じカメラで実表示し、空中の足送りと膝の追従を確認した。支持足のワープではないが、速い足送りは残る。スクリプトの `< 0.8 m/frame` は大きな跳びを検出する暫定スモーク上限で、見た目の自然さや AAA 品質の合格基準にはしない。

`renderer-coexistence.png` / `renderer-split.png` も実表示確認済み。今回の証拠は Chrome SwiftShader の再現場面と静止画像であり、モバイル実機のフレーム時間、長時間の混戦、全フレームの映像による動作の自然さは未確認。参考画に対する造形・素材の完成度は、この描画機能監査とは別に評価する。
