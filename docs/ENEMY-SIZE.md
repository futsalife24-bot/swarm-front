# 全エネミーの固定サイズ・性能個体差（2026-09-13）

ユーザー指定: FOUNDRY ZERO通常型は現行の2倍。その他はミミズ型・今後追加する敵を含め0.8〜2.0倍。全20ステージで個体差を固定。追加指定によりHPと攻撃力もサイズに比例し、現行サイズ以下（倍率1.0以下）の移動速度は基準の1.5倍、超える個体は基準速度を維持。

## 実装

- `src/shared/enemy-size.ts`: 共通の32枠固定配列。0.8〜1.2倍が26枠、1.3〜1.5倍が4枠、1.75・2倍が各1枠。通常型FOUNDRY ZEROのみ2倍固定。
- `game.ts`: 敵に`size`を持たせ、HP・命中球半径・狙い中心・通常攻撃威力・移動速度へ反映。通常配置は前ウェーブまでの配置数＋現在の配置番号で決定し、乱数seed・射撃回数・増援数から独立。生成敵も共通の規則を使用。
- `worm.ts` / `foundry-defs.ts`: 節間距離・履歴長・レーザー発射位置・威力・分離後速度へ反映。サイズによる速度倍率は通常／分離後それぞれの従来速度へ適用。
- 通常型FOUNDRY ZEROは攻撃後の待ち時間を3秒から6秒へ変更し、2倍威力の連発を抑制。
- バランス調整として、ミミズ型のレーザー間隔を基準4.8秒（従来3.2秒）、大型はさらにサイズ倍率分延長。1発の威力は指定どおり10×サイズ、弾速・射程・予告時間は維持。
- `render.ts` / `foundry-worm.ts`: 通常敵・フォールバック・連結炉の全描画へ反映。連結炉の関節と接地計算はモデル座標へ変換してからサイズを適用し、節のワールド位置は維持。
- 経路探索と障害物回避の通行幅、各攻撃の射程・範囲、出現数、ステージ係数は既存値を維持。巨大化で洞窟経路を通行不能にしない。命中判定は見た目と同じ倍率。
- レポートの標本表示は従来の比較表示を維持。通常戦闘・増援が調整対象。
