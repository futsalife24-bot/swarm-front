# 武器系統と派生（6系統・12丁）

## 何が変わったか

武器は3丁（ライフル / ショットガン / ロケット）から **6系統・12丁** になった。各系統は2丁で構成する。

| 系統 | 1丁目 | 2丁目 | 系統の性格 |
|---|---|---|---|
| ライフル | AR-9 リーフ | **SMG-3 ワスプ** | 連射。中距離 |
| ショットガン | SG-4 ブレイカー | **SG-7 スパイク**（スラッグ） | 標準で最大3体貫通 |
| ロケット | RL-2 コメット | **RL-9 メテオ**（重ロケット） | 直進する弾体と爆風 |
| **スナイパー** | **SR-1 ソーン** | **LZ-2 グリム**（レーザー） | 長距離。拡散・距離減衰なし |
| **グレネード** | **GL-6 ホロウ** | **ST-3 リンバー**（粘着） | 山なり弾道と爆風 |
| **特殊** | **KB-6 ケストレル**（反動射出器） | **MD-4 ブルーム**（支援回復銃） | 道具枠 |

### スナイパー系統の中の使い分け

同じ遠距離枠に、**狙って1体を撃ち抜く** SR-1 と、**当て続けて列を薙ぎ払う** LZ-2 を並べた。

| | SR-1 ソーン | LZ-2 グリム |
|---|---|---|
| 1発 | 165 | 8 |
| 連射間隔 | 1.05秒 | **0.045秒**（連続照射） |
| 射程 | **140m** | 95m |
| 貫通 | 1体 | **3体** |
| スコープ倍率 | **2.4倍** | 1.6倍（当て続ける前提で控えめ） |
| 持続DPS | 114 | 114 |

**持続DPSは意図的にほぼ同値にしてある。** 強さではなく形で選ばせるのが狙いで、単発火力・射程・倍率を取るか、貫通と継続を取るかの差になる。

### 特殊枠は「機構」ではなく「役割」

特殊枠は5つの射撃系統のどれにも属さない道具を入れる場所で、**2丁に固定されていない**。`FAMILY_KINDS` はテーブルから自動生成され、ドロップは系統→武器の2段抽選なので、ここに何丁足しても**他系統の出現率は 1/6 のまま**変わらない。

## 設計：`kind` と `family` を分ける

`Kind` は武器1丁、`Family` はその武器の機構。`WEAPONS[kind].family` で引く（`familyOf()`）。

戦闘コードにあった `weapon.kind === "rocket"` / `=== "shotgun"` の直書き分岐は、すべて **テーブルの属性** に置き換えた。

| 属性 | 意味 |
|---|---|
| `family` | 機構の所属。SE・武器モデル・被弾エフェクト・兵士の構えはこれで引く |
| `falloff` | 距離減衰の曲線を `"rifle" / "shotgun" / "smg" / "none"` から選ぶ |
| `pierce` | 標準で貫通する体数（`1` か `3`） |
| `speed` | 指定すると hitscan ではなく弾体を発射する |
| `gravity` | 弾体を落下させる。共通の弾体物理に元からあった項目 |
| `zoom` | スコープ倍率。未指定は従来どおり2倍 |
| `recoil` | 射撃時に**自分**を後方へ運ぶ距離（m） |
| `heal` | 射線の走査先を敵から味方へ切り替える |

`Event.weapon` は **kind ではなく family** を載せる。これにより音響・描画・ヒットエフェクトの既存分岐が一切増えない。

### KB-6 ケストレル（反動射出器）

至近距離へ散弾5発を撃ち込むと同時に、`recoil: 9` の分だけ自分を後方へ運ぶ。移動には **ショットガンの `repel` が敵を押すのと同じ `move()`** を使う。`move()` は距離を0.2m刻みに分割して壁と床を毎回見るので、壁抜けも落下も起きない。

**反動は水平成分のみ**（`yaw` だけを使い `pitch` を無視する）。上下成分を入れると、上を向いて撃った瞬間に地面へ叩きつけられたり空へ飛んだりするため。

特殊効果「撃退散弾」を積める唯一の非ショットガン武器で、押し返しと自分の離脱を同時に行える。

### MD-4 ブルーム（支援回復銃）

`fire()` が敵ではなく `w.players` を走査する専用経路（`healShot`）へ分岐する。敵向けのエイムアシストより**手前**で分岐するので、味方を狙っているのに敵へ吸い付く事故が起きない。

**単発ではなく散弾7発。** 細い1本の線を、動いている味方に、スマホの視点操作で当てるのは現実的でない。

ただし**円錐を広げすぎると遠距離でかえって当たらなくなる**（的より散弾の広がりが大きくなり、周りに散る）。実際に拡散0.085で試したところ40m先で1発も当たらなかったため、**拡散は0.05に抑え、代わりに味方の判定半径を1.8mと太くした**（通常の射撃判定より広い）。狙いのズレは「回復量が減る」で払わせ、「空振り」にはしない。

- 射程45m。まっすぐ狙えば40m先でも7発中6発が当たる
- `damage` の数値が**散弾1発あたりの回復量**（全弾命中で7倍）
- レア度とバリアンスがそのまま回復量に効くので、進行システム側に第2の経路を作らずに済む
- ダウン中（HP0）の味方は対象外。蘇生は従来どおり
- 回復は `maxHp(w)` で頭打ち
- 特殊効果「貫通」を積むと一直線の味方を最大3人まとめて回復
- 回復量は**味方ごとに合算して1回だけ報告**する。散弾7発で数字が7個飛ばないようにするため

**フィードバックを機構と同時に入れてある。** 2026-09-06 の「味方が救助できない」バグは、処理が正しいのに救助側の画面が無反応だったのが真因だった。回復銃は同じ形をしているので：

- 回復量を緑の `+38` として**撃った本人に必ず表示**する。ダメージ数字の表示設定が「オフ」でも回復だけは出す
- 味方が満タンで回復量0でも、**射撃イベントと効果音は必ず出す**。「当たったが何も起きなかった」と「壊れている」を区別できるようにするため

## セーブ互換

- **既存3丁の数値は1つも変えていない**（`tests/weapon-families.test.ts` がリテラルで固定）
- 新規セーブの初期装備も従来どおり3丁のみ。新系統は入手して増やす
- 旧セーブに新 `kind` は存在しないので、そのまま読める
- 効果の可否判定のうち `repel` と `chain` は「その武器の抽選プールに入っているか」を見る形にした。`pierce` だけは family 判定のまま残してある（旧セーブのショットガン+貫通を読めなくしないため）

⚠️ **逆方向は非互換。** 新 `kind` を含むセーブを旧クライアントで読むと `validWeapon` が弾く。公開後に巻き戻すと、その武器は失われる。

## ドロップ率

`rollWeapon` / `loot` は **2段抽選**。まず6系統を均等に引き、次にその系統内から引く。

系統が増えても「ライフル系が出る確率」は 1/6 に下がる（従来 1/3）が、**系統内で2丁目が1丁目の出現率を食わない**ため、単純な12種均等（1/12）よりは希釈が半分で済む。`tests/game.test.ts` が10万件のドロップで各系統の比率が 1/6 ± 2% に収まることを検証する。

## 武器庫の上限

`CAPACITY.perKind = 16` は元から「系統ごと」と文書化されていたが、実装は `kind` 単位だった。系統が6つになると 12 × 16 = 192 で全体上限160を超えるため、**実装を文書どおり family 単位に揃えた**（6 × 16 = 96）。

対象: `progression-save.ts`（検証・`bank`）、`save.ts`（`trimToKindCap`・報酬受領・保留の引き上げ）、`daily-rewards.ts`。

## 性能（グレードN・バリアンス0）

持続DPS＝`1発 × 散弾数 × 装弾数 ÷ (装弾数 × 連射間隔 + 装填時間)`。ゲーム自身の `stats()` から算出。

| 系統 | 武器 | 1発 | 持続DPS | 射程 |
|---|---|---|---|---|
| ショットガン | SG-4 ブレイカー | 152 | 138 | 23m |
| ライフル | AR-9 リーフ | 24 | 132 | 65m |
| ライフル | SMG-3 ワスプ | 13 | 126 | 38m |
| スナイパー | SR-1 ソーン | 165 | 114 | 140m |
| スナイパー | LZ-2 グリム | 8 | 114 | 95m |
| 特殊 | KB-6 ケストレル | 170 | 100 | 14m |
| ショットガン | SG-7 スパイク | 110 | 90 | 45m |
| グレネード | ST-3 リンバー | 135 | 89 | 50m |
| グレネード | GL-6 ホロウ | 90 | 80 | 55m |
| ロケット | RL-9 メテオ | 430 | 75 | 80m |
| ロケット | RL-2 コメット | 170 | 68 | 75m |

MD-4 ブルームはダメージを与えないので上表に含めない。回復量は散弾1発9・全弾命中で63、装弾5発。

射程と範囲攻撃が伸びるほど単体DPSが下がる形に揃えてある。

## 未検証・限界

- **実際にプレイしていない。** 手触り、難易度曲線、戦闘のテンポ、12丁の体感バランスは未評価。上のDPS表は算術であって遊んだ結果ではない
- **実スマホ未検証。** 反動射出器の移動距離が実機の視点操作で扱えるか、レーザーを95m先の的に当て続けられるかは未確認
- **実協力通信での検証が未了。** 回復銃は4人協力でこそ意味を持つが、権威サーバー経由の複数人同時回復は単体テスト止まり
- 新系統の3Dモデル・発砲音は**既存アセットの流用**。スナイパー/特殊はライフル、グレネードはロケットの見た目と音を使う。回復音は蘇生音の流用
- レーザーは「連射間隔0.045秒の hitscan」であって、専用の連続ビーム描画や過熱処理を新規実装したものではない
- 反動射出器の移動は水平のみ。段差や崖を跳び越える用途では、落下の扱いが `move()` の既定挙動に従う

## ローカル検証時の罠

**サービスワーカーが古いバンドルを返す。** 開発サーバーを立て直してもブラウザが以前のコードを実行し続けることがあり、変更が反映されていないのに「検証した」と誤認する。`navigator.serviceWorker.getRegistrations()` を解除し `caches` を消してから再読み込みすること。今回の作業中に実際に1回踏んだ。
