# 照準・弾道修正と全武器スコープ（2026-09-12）

状態: 実装・ローカル検証・公開完了。公開後確認の結果は末尾に記載。

## 利用方法

全武器（AR・ショットガン・ロケット）で「スコープ」をタップ、またはPCでZキーを押すと約2倍へ切り替わる。再操作で解除。持ち替え・一時停止・ダウン・画面離脱・フォーカス喪失では解除し、持ち替え中はボタンを無効化する。スコープ中も射撃・射撃ドラッグ・移動・装填が可能。ドラッグとジャイロの感度を半分にして、拡大時の細かな操作を補助する。

ボタンは右側の装填の上、武器切替の左に配置。配置編集にも追加し、以前保存した配置にはスコープの初期位置だけを補う。旧位置が新ボタンと重なる場合は既存の重複検出による標準配置フォールバックを使う。

## 射撃の変更

従来はカメラが30m先を見る一方、弾はキャラクターから同じ角度で進み、近距離の狙い位置と一致しなかった。

新しい共通関数 `aimCamera` / `cameraShot` は、肩越しカメラの光線が最初に捉える敵の当たり判定・壁・地面を狙い点にする。描画カメラはその点を向き、権威射撃はプレイヤーの発射位置から同じ点へ進む。空を向く場合は射程を基準とする遠点へ向く。スコープはFOVのみ変更し、狙い点は変えない（65度→約35.337度、正確な角倍率2倍）。

実際の発射位置から壁への衝突判定を維持するため、カメラから敵が見えても銃の直前の遮蔽物は貫通しない。新方式の下向きの通常弾も地面で止める。キャラクターより後ろのカメラ側障害物によって後ろ向きに撃たないガードを追加。

新クライアントは検証済みの任意boolean `cameraAim: true` を送る。サーバーが狙い点を再計算し、クライアント指定の任意座標や命中結果は受け取らない。旧クライアント・既存の直接角度入力は未指定のまま利用できる。新方式では照準から外れた敵へ不可視で曲げる旧補助を適用せず、武器固有の散布・射程・威力・射撃間隔は維持。

上半身の±0.8rad固定上限を取り除き、実際の射撃角度に追従させた。ローカルの構えは最新の照準を使い、協力相手の構えはサーバーが計算した射撃角度を使う。クロスヘアも文字の字形に依存しないCSSの十字へ変更。スコープ時は自キャラを非表示にして視野を確保する。
