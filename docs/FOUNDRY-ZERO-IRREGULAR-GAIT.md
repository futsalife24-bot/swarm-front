# FOUNDRY ZERO 不規則な足運び（公開済み）

2026-09-12 ユーザー指示「脚の動きは統一せずに不規則にして」に対応。

## 変更

`src/client/foundry-worm-gait.ts` の左右交互・全脚共通周期を廃止。脚ごとの独立した移動距離スケジュールへ変更し、一歩ごとに次の踏み出し間隔、足送りの速さ、持ち上げ高さ、着地点の前送り量を変える。各脚に固定seedと歩数を持たせ、一歩の開始時だけ値を選ぶため、同じ再生条件は再現でき、フレーム単位の震えを生じさせない。ゲーム側の乱数は消費しない。

接地中の足の固定、2関節IK、伸び切る前の踏み直し、停止時に空中の足を着地まで動かす処理は継続。モデル形状・GLB・敵の速度・攻撃・当たり判定の変更なし。

変更した主な値は、次の踏み出しまでの距離を基準周期の0.72〜1.17倍、空中の送り距離を0.30〜0.45倍、最低送り時間を0.11〜0.155秒、持ち上げ高さを0.14〜0.29m、前送り量を基準周期の0.25〜0.42倍とする範囲。毎歩の値はその歩行中に固定する。
