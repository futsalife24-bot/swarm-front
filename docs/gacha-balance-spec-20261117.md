### 1-4. 遡及配布

- 保管庫に紐づく補給口座が付与を集計するとき、**保管庫の進行保存にある過去の初回クリア・星・最高到達をすべて対象にする**。「この更新以降の達成」を区別する記録はいらない。
- 対象は1回きりの3種類（初回クリア・星・最高到達）。週ごと・日ごとの分は遡らない（過去の週の記録はサーバーに残っていないため）。
- 最初の集計で一度に入るので、補給画面に「過去の達成分 +N枚」を1回出す（1-6）。
- 旧方式の端末口座（F-17 以前に作られた、保管庫に紐づかない口座）は遡及の対象外。クラウド保存を作って移行した時点で、保管庫の口座側で遡及される（旧口座の残高は既存の `absorb` で1回だけ移る。`server/supply-vault.ts:103-141`）。

### 6-10. Lv1 統一による火力の低下と既存武器の扱い（新規・大きい）

- 現行は Lv1つごとに威力+6%（`weapon-growth.ts:47`）。ST25 で拾う武器は Lv25 で威力 2.44倍。Lv1 に統一すると、レア度（SSR 1.52倍）と性能のぶれ（最大+20%）だけになり、ST25 の SR（1.32倍×2.44 = 約3.2倍）と比べると、**Lv1 の SSR は性能のぶれが最大（+20%）でも約1.8倍で、現行の ST25 の SR の6割弱**にとどまる。敵の体力はステージで上がる（`stages.ts:431` `1 + i×0.025`、HARD は×1.25）ので、新しく始めたプレイヤーには終盤が今より大幅に厳しくなるおそれがある。
- 既存プレイヤーの Lv2 以上の武器は**変えない**（仮）。保存の移行をしない。この場合、既存プレイヤーと新規プレイヤーの強さの差が残る。下げる場合は保存の書き換えが要り、高リスク変更になる。
- 判断の順序の提案: T6 の計測（Lv1 の装備で ST12・ST25・HARD 終盤）→ 結果を見て、敵の体力の調整・段階表の上振れ（6-8）・据え置きのどれにするかを本人が決める。

### 6-12. 保管庫の作り直しで遡及分も再付与される（新規）
