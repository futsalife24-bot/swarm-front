# タイトルロゴとドット拡大の入口（2026-10-14）

本人依頼: 既存の最初の画面の前にタイトルロゴのみを表示し、タップするとFRONT.のドットが広がって既存画面へ遷移する。

既存title-logo-v2.pngをそのまま使用。黒背景・中央ロゴだけの全画面ボタンを共通タイトルへ追加。水色のドット位置から円が680msで画面隅まで拡大し、240msで既存メニューへ溶け込む。既存メニュー構成は変更しない。1文書につき1回で、同じ画面内のタイトル復帰では再表示しない。再読み込み/新規ページでは再表示。solo/coop/frontRoom/roomの直接リンクは従来の動線を優先する。

ネイティブmodal dialogで背景操作を遮断、タップ/Enter/Spaceに対応。開始後は二重操作を止める。縮小モーション設定では拡大を省略。開始後のリサイズ/非表示/設定変更/アニメーション例外時は後始末してメニューへ進み、1400msの復旧上限を設ける。PNGのドット座標をピクセルで確認した。素材生成/改変なし。

自己検証: src型チェックexit0、共通タイトル既存テスト1件成功、Vite build成功。iabの公開用ビルドで1280×720・844×390のロゴのみ表示、ドット拡大の途中画像、遷移完了、既存ソロ選択、出撃準備→タイトル復帰（再表示なし）、Enter操作、設定の「動きを抑える」ON時の即時遷移、solo直接リンクの入口省略を確認。ローカルの設定はOFFへ復元。実スマホ・長時間の操作は未確認。開発サーバー初回の白画面読込が遅く、公開用ビルドで確認を継続した。監査・main反映・公開は準備中。

変更: src/client/title-entry.ts、title-entry.css、共通mountTitleMotionの呼出追加のみ。ゲームルール/報酬/ネットワークを変更しない。主担当の実モデルID/推論設定は未確認、子担当なし。

追加確認: 通常入口でも同じロゴを表示しSpaceで遷移。遷移中の844×390→640×360リサイズでも入口を除去し、メニュー操作を塞がない。viewportは復元済み。本番設定Worker dry-run成功。
