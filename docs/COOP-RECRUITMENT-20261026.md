# マルチ募集画面の更新（2026-10-26）

本人依頼: パスワード付き（招待リンク・パスワード共有の両方）とフリーマッチングを選択できるようにする。フリーは本人回答「公開中の部屋一覧から選んで参加する」。パスワードは既存の自動発行8文字コードを使う実装判断とし、任意の文字列を設定する機能は追加していない。

## 対象と変更

base main `e91d7953bfda10150b4d14a9e5fcf8fe03d7841d`、branch `codex/coop-recruitment-20261026`。HARROW公開記録main `fc7cd208656623b3c230fcc2c05852cd703321b2` を取り込み済み。元worktreeの未コミット成果・他担当差分・別候補は保持。

- 生存・進撃の共通募集入口を「パスワード付き」「フリーマッチング」の2ボタンへ整理。初期値は非公開。招待側は一覧に載せず、フリー側は公開一覧から選択して参加する。部屋を作る側と参加する側を同じ画面に配置。
- フリーを選んだ時だけ一覧を取得する。素早い切替中の古い応答はrevisionで無効化。作成・参加中は切替と重複処理を止め、エラー後に戻す。作成待ちに画面を離れた場合は遅い応答で画面を引き戻さない。
- 生存ロビーにパスワード/招待リンクのコピーを明示。進撃の既存IDコピーも同じ用語へ変更。共有先への送信は行わず、利用者がコピー・共有するUIである。
- 生存の共有リンク `?frontRoom=8文字` を貼り付けできなかった問題を修正。同じ設置先だけ許可し、生存リンク共有時は開発用queryと古いhashを除外。既存の進撃32文字hashリンクも維持。
- 生存募集画面に残っていた防衛/日替わりの選択欄は表示せず、生存へ固定。進撃は既存の共通タイトル導線を維持する。サーバーの旧モードや保存処理は変更しない。
- 640×360で作成ボタンが隠れる問題を検出し、入力部分だけスクロールさせ、作成ボタンを常に表示する形へ修正。

戦闘数値・通信API・サーバー権威・認証・作成制限・保存・報酬は変更なし。新しいパスワードDBやサービスは作っていない。
