# ジャンプとステージ固定の高台ルート（2026-09-20）

## 仕様

- 画面の「ジャンプ」ボタン／Fキー。既存Space回避を維持。初速8m/s、重力20m/s²、最高約1.6m。空中で再ジャンプしない。屋上へ着地し、縁から離れると落下する。落下ダメージは追加しない。
- ボタン配置の編集・旧配置読込に対応。協力プレイのサーバー入力保留・消費、送信待ち入力の合成にも対応。旧クライアントのjump省略を許容。
- ユーザー指示により、地形の選択UIは追加しない。ステージ3・7・8・12・14・17・18・19・20を高台ルートへ固定。その他は通常版。分岐21は従来どおり作戦3のマップを使用。洞窟の地形は変更しない。
- 灰明の街区には28〜42mの高層ビル8棟を追加。市街系3地域の追加版には、外周サービス通路の保守棟2棟、各12段の外階段と屋上踊り場を設ける。階段・屋上は共有当たり判定と同じ寸法で描画。
- 草原は広い山腹斜面、雪山は中央が低く周囲の高い窪地。追加版には幅広い自然の高台と徒歩経路を加える。岩の足元は現地標高へ持ち上げ、地面だけを下げた穴にしない。
- 通常版と追加版で元のGLBを共有し、地形の変形と追加構造物で差分を描画。作戦ID・敵編成・報酬・保存キーは変更しない。中断データの足元が新地形へ埋まっていた場合は支持面へ補正。専用訓練場・日次防衛場は維持。
