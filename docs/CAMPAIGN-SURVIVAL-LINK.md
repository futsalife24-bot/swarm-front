# 攻略・生存の相互連携仕様（2026-10-06）

状態：利用者との相談で合意した方向と、実装前の設計整理。下記の未決事項を確定するまで、ゲーム本体・保存・通信の仕様を変更しない。公開済み版は維持。

## 合意した方向

- 攻略モードは従来のステージ攻略を土台とし、既存の武器・コイン報酬を維持。指定ステージのクリアで生存モード用の3択強化候補を追加解放する。
- 生存モードは常設の主戦場1つで生存時間を伸ばす。攻略で得た武器と解放済み強化候補を活かす。期間限定の戦場は候補であり、初回実装の必須範囲に含めない。
- 生存の成果を攻略側の育成へ持ち帰る。具体的な報酬額・節目は検証用の調整値として別途定義する。
- 両モードでソロ・協力を可能にする。
- 生存モードの経験値は部隊共有、強化選択の開始タイミングは全員同時。
- 3択候補は各プレイヤーが設定した種類を反映して個別にランダム抽選。候補を全員共通にしたり、ホストの設定で全員分を上書きしたりしない。
- 武器の組み合わせによる進化を加え、長時間生存中の育成余地を増やす。
- 従来の保存データ・獲得物・進行を保護する。解放済み強化を新しい解放条件の導入で没収しない。

## 設計上の推奨（数値・細部は未確定）

1. 経験値は誰が拾っても部隊へ1回だけ加算。3択の内容と選択結果は個人単位。候補には同じカードを重複表示しない。
2. 出撃前の候補設定を作戦中は固定。途中の設定変更・再接続で抽選し直せないようにする。
3. 選択中は部隊の戦闘を停止し、全員の選択完了で選択演出後に即再開。無操作の人で永久停止しないよう期限を設け、期限後は本人の候補から自動選択。ソロの時間制限は追加しない。
4. 一度に複数レベル上がった場合は全員共通の未処理回数として保持。再接続や連打で権利を増殖させない。候補が尽きた人には回復・補給等の選択を出す。
5. 進化・作戦内の武器強化はその出撃中の効果とし、所持武器の現物を破棄・変換しない。
6. 進化後に追加育成段階を用意し、構成完成後は回復・補給・小幅な能力強化へ移る。無限に乗算して性能値が破綻する設計は避ける。
7. 攻略からの解放は各プレイヤー自身の確定クリアに基づく。既クリア者への遡及解放と、導入前の解放保持を検証する。
8. 帰還・敗北時の報酬、二重タブ、保存失敗、クラウド競合を同じ受取記録で管理し、別モードへの持ち帰りで二重付与しない。
