# 攻略・生存の連携と強化融合（2026-10-06）

利用者が「武器ではなく3択強化2種の融合」と訂正し、1枠へ統合・新しい育成段階・種類追加・光る枠を承認した。実装対象は強化の融合。倉庫の武器融合は含めない。

## 今回の仕様

- 攻略は従来のステージ、武器・コイン報酬、ソロ・協力を維持。従来の入口 `/` と生存の入口 `/front` を相互に行き来できる。
- 生存は常設の戦場1つ。9分の終了と最終補給を撤廃。ソロは全滅または任意帰還まで、協力は全滅または出撃から60分まで継続。通常敵の基本体力半分・出現頻度4倍・同時数上限96を維持し、3分ごとに体力倍率を0.35加算する。期間限定の追加戦場は今回は含めない。
- 攻略の所持武器から2本持ち込み、特殊効果・威力・弾倉・装填・射程・連射を維持。作戦内の育成は複製へ反映し、倉庫の現物は書き換えない。攻略保存がまだない場合は従来の支給武器を使う。
- 新規強化は生命回収（攻略2）、出力増幅（攻略4）、弾薬循環（攻略6）。難易度を問わず、そのステージのクリア済み記録から遡及解放する。従来16種は没収しない。既存の初期候補9種と勝利解放も維持。
- 基地で6〜19種類を候補登録し、初期候補は解放済みの各系統から1つ。設定は端末へ保存、次の出撃時に固定する。日替わり・協力も本人の設定を使う。
- 経験値・選択開始は部隊共有、抽選・選択結果は個人単位。選択中は戦闘停止。全員完了後に0.2秒の選択演出だけで再開。協力の期限15秒と自動選択、再接続時の候補保持・要求重複防止を維持。
- 素材2種を最大まで育てると、その融合を含む候補を提示する。選ぶと素材を消費して1枠になり、1段階から3段階まで追加育成できる。素材の最大効果を引き継ぎ、融合段階分を加算する。消費した素材はその作戦では再取得できない。
- 同時6枠。候補がすべて最大になると構成完成、強化選択を終了して戦闘を続ける。回復等の無限繰返し選択は今回追加していない。取得権の安全上限120、経験値閾値は `12+24n+8n²`。
- 融合候補・取得アイコン・詳細行に金色の発光枠。カードは「融合進化」「2枠→1枠・1段階」、以後「融合強化」で区別。動きを減らす設定では発光アニメーションを止める。

## 戦果と保存

生存の終了時は1分につき10コイン、1作戦最大300コインを攻略へ持ち帰る。ソロは1分以降、一時停止から帰還できる。協力は全滅、または出撃開始から60分で帰還し、各人が自分の端末へ戦果を保存する。利用者の訂正により準備時間は60分へ含めず、帰還後に保存・再接続用の2分を別途確保。受付登録・接続判定・掃除の期限を揃える。ロビーと終了前のHUD、一時停止に帰還の案内を表示する。ソロには部屋寿命の制限はない。功績・既存勝利報酬は別に維持。

共有保存の既存排他ロック・改訂番号・受取記録を使う。コインと受取済み記録は同じ保存へ一括反映。先に専用の未保存戦果控えへ記録し、保存失敗は結果画面の再試行・次回タイトル起動で回復する。同じ作戦は再送しても二重付与しない。破損した保存を初期化して上書きしない。

旧成長規則1・2の作戦を新仕様へ変換しない。新規作戦は規則3。古いクライアントと規則3の混在開始は更新案内で止め、旧規則2の再接続は規則3クライアントでも継続可能。サーバーは武器値・候補形式を検証する。従来同様、端末の所持履歴自体をサーバーで証明する仕組みではない。

利用者の追加指示により融合名はカタカナへ変更。カードは主要能力を短文で示し、素材は小型アイコン付き「素材A × 素材B」。継承性能の詳しい内訳は詳細へ移した。

生成アイコンは `public/rebuild/upgrades/fusion-atlas.png`。透明な3×3画像を1枚生成し、上段に新規3種、以降に上記融合6種を順番に配置。既存16種の画像は維持。
