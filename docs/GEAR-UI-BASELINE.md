# 2026-09-14 出撃準備の既存UIを基準にした修正

ユーザー添付Photo 2と `WEAPON-ROW.md` を基準に、出撃準備の武器一覧だけを修正。初回復元の最低600pxの性能欄と常時チェックボックス、30px見出し・重複案内行が、旧UIより多くの幅と高さを消費していた。

- 左は小さいレア度枠・武器名・装備番号、中央は短い特殊効果と威力/装弾/装填/射程/連射、右端はロック固定。性能欄は最大桁の数値も検証し、最低316pxまで縮小した。
- 名前・数値は13px、行高44px、共通見出し20px。無駄な専用案内行を削除。単位は見出しの長文化を避けて数値側へ置き、散弾の発数表示を復元。元の正確な値と効果名は詳細に保持。
- 通常時はチェックボックスなし。「整理」で表示し、終了で選択を解除。選択中の品をロックした場合もチェックを外して保護。超過品の状態表示を保持。
- 新しい行部品 `src/client/gear-weapon-list.ts` と専用CSSに出撃準備の表示規則を集約し、`playtest-app.ts` の既存比較・ロック・解体・ソート処理へ接続。他画面の共通 `playtest.css` は開始前とSHA256一致。
- `AGENTS.md` に「既存UIを変更のベースとする」「横スクロール許可は幅を広げる許可ではない」と受入条件を明記。確認スクリプトで既存UIの1行構造、文字の収まり、見出し高、固定ロック、整理時だけのチェックを保護する。
