# SWARM FRONT ガチャ合図「金のマーク」作り直し依頼（2026-11-16）

## 背景と本人の決定

ガチャ合図の実装後、本人が実画面（お試し/本編）を確認し、次のフィードバックがあった：

- 追加された**金のマーク全般**（六角形＋ダイヤの金バッジ、金の角ブラケットや線）が「AI Slop 感が強い」。平たい汎用アイコンを金のプレートに載せた質感が、立体感のある補給箱とホログラム系の画面から浮いている。
- 本人決定：**世界観に合わせて作り直す。それでもおかしいなら無くす。** 立体感を持たせ、補給箱にちゃんと合わせること。

## 対象（金バッジ表現を使っている箇所すべて）

コード上で同系統の金バッジ/マーク表現を洗い出し、全て対象にする。少なくとも次を含む：

1. 射出局面に出る金アイコン（金の四角プレート＋六角形＋ダイヤのシンボル）
2. 「目印の先読み」のマーカー（金の六角バッジ＋角ブラケット＋引き出し線）
3. 個別タップ局面の金章（箱の面に表示される金バッジ）
4. 上記以外で同じ金バッジ素材・スタイルを使っている合図があれば、それも対象

## 作り直しの基準（受け入れ条件）

- **補給箱の質感に合わせる**：箱の金属質、面の陰影、パースに馴染む立体感のある描画にする。「平たいアイコンを金のプレートに載せて貼った」見た目は禁止。
- **ホログラムとして統合する**：マークは箱へ投影されたステンシル/ホログラムタグとして描き、画面全体の青緑ホログラムUIと同系統の表現にする。金を使う場合も細いラインのアクセントまでで、ベタ塗りや金グラデーションのプレートは使わない。
- **判定**：スクリーンショットで見て「箱の一部・投影に見える」こと。浮いて見えるものは不合格として扱う。
- **フォールバック（本人の決定）**：この基準に合わせられないマークは、そのマークだけを取り外す（その合図の他の要素＝動き・音・その他の視覚要素は残す）。無理に残さない。取り外した箇所は状態ファイルに必ず明記する。
