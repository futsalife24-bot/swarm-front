## 攻撃の契約

原則としてwind前半を構えのみ、後半を赤い予告、wind終了後を攻撃とする。最短は0.4秒の構え＋0.4秒の赤予告。PLEATと同じタイミングを共有するLEAPERのwindを0.45→0.8秒へ延長し、実モデルの衝撃姿勢0.45秒へ再生時間を対応させる。

| 種類 | 対象 |
|---|---|
| HARROW | 短距離突進、山なり弾、直射弾、翼爪回転、空中山なり弾、爆撃通過、爪先行急降下 |
| CALYX | 花弁叩きつけ、花粉弾と着弾後の雲 |
| HOUND / VOLLEY | 山なり弾３発、近距離パルス |
| HOUND / LEAPER | 近距離パルス。無傷の移動跳躍を新たな攻撃にはしない |
| PLEAT | 前方の衝撃波 |
| PRISM | 直進するエネルギー弾 |
| RAY | 電撃杭 |
| FOUNDRY ZERO | 通常型の範囲攻撃、連結形態の各節レーザー |

CALYXの予測と実弾は同じ弾道・衝突関数を使い、壁・天井で実着弾点が変わる場合も照合する。HARROWは弾/爪の実判定に対応する既存形状を保つ。

## ボイスの制作方針

| 種類 | 声の方向 |
|---|---|
| HARROW | 掠れた喉鳴りから低い唸りを重ねた鋭い咆哮 |
| CALYX | 空洞の花弁が鳴る、吸い込むような共鳴 |
| HOUND / VOLLEY | 乾いた骨の震えを伴う短い二連の吠え声 |
| HOUND / LEAPER | 喉を絞り、せり上がる高めの唸り |
| PLEAT | 胸の奥の低い喉鳴りと襞の擦れ |
| PRISM | 硬い面がずれて響く澄んだ不協和音 |
| RAY | 長く曲がる笛状の声と電気的な震え |
| FOUNDRY ZERO | 巨大な炉の重低音と金属の軋み。通常/連結で共通 |

各種２変奏、攻撃予備開始時に再生。権威スナップショットを観測するだけで戦闘に作用しない。近い個体を優先し、最大同時２声・個体間隔2.2秒・全体間隔0.65秒で密集時の飽和を抑える。無音中/初回受信/タブ復帰/復元時は過去の声を再生しない。

外部サービス調査ではElevenLabsのログイン画面まで到達したが、Googleログインを押しても画面が進まず、アカウント/契約/残高は未確認。移動の自動承認レビューが１回時間切れ、許可された１回の再試行で画面へ到達。クレジットは未消費。利用済みサービスを本人へ非同期で照会中。

独自合成の候補は `scripts/generate-anomaly-voices.py` に用意。声帯相当の非対称パルス、息の乱流、共鳴、硬質音を種別に生成する。外部サンプルや既存作品の声は使用しない。**これはAIサービスでの生成ではなく、独自の手続き的音声合成**。方法・消費額・各WAVのSHA/音量をmanifestに記録し、AI生成と偽って報告しない。

RAYは照準の固定後に赤予告を出すため、構え約1.65秒、赤予告0.4秒とする。VOLLEYの3発、PRISM、RAYは標的の後方を含め、壁・地形または弾寿命までの実弾軌道を警告する。HARROWの突進は壁沿いの滑りも含む移動予測へ合わせる。
