## 1. 武器詳細（`.weapon-detail-dialog`）

```
┌ SWARM FRONT（高さ420px以下では省略）                                 ┐
│ 武器名 / レア度（1行・長ければ省略）                        [閉じる ×] │
├────────────────────────────┬─────────────────────────────────────────┤
│ ┌3D画像（300:170）─────┐ │ 性能  実数値  同レア基準差             │
│ │                        │ │ 威力 / 装弾 / 装填秒 / 射程m / 連射/秒 │
│ └────────────────────────┘ │ 同種・同レアの標準性能との差。…        │
│ 特殊効果の文                │ （注記：入口ごと。無ければ出ない）      │
├────────────────────────────┴─────────────────────────────────────────┤
│ （エラー：出た時だけ・全幅）                                          │
│ [🔒 ロックする] [共有] [装備1へ] [装備2へ] [変換・恒久改造]   ←全幅の段 │
└──────────────────────────────────────────────────────────────────────┘
```

判断：

1. **左右2列＋全幅の操作段**。右列の箱（`.weapon-detail-data`）は `display: contents` にした。これで性能表・説明・注記は右列に、エラーと操作の段は全幅に置ける。入口によって最大5つのボタン（ロック・共有・装備1へ・装備2へ・変換・恒久改造）が並ぶ。全幅なら568幅でも1段に収まり、高さを使わない。DOMは変えていない。
2. **3D画像は列の幅と画面の高さで決める**。既存の `#pt-weapon-preview`（高さ170px固定・最小幅300px）は、この画面の中だけ解除した。比は300:170のまま、幅は `min(列幅, (100dvh − 200px) × 1.76)`。three.js が描画面へ直接書く高さ170pxは、`!important` で `height: auto` に上書きして縦横比を保つ。読み込みに失敗した時の文は、同じ枠の中央に出す。
3. **ロックする・共有は同じ段の同じ高さ**。全ボタンを最小44px、`align-items: stretch`、アイコンは20pxで、上端と高さがそろう。ロックの錠アイコンは文字と同じ中心線に置く。
4. **見出しと閉じる**：武器名は1行で、長ければ省略記号にする。閉じるは44pxで押し出されない。高さ420px以下では「SWARM FRONT」の小見出しを省き、余白を詰める。
5. **溢れた時だけ本文をスクロール**。通常はスクロールなしに収める。長い効果・注記・エラーで溢れた時は本文がスクロールし、操作の段は `position: sticky; bottom: 0` で下端に貼り付いたまま押せる。dialog自体は画面の高さ − 16px を超えない。
6. **性能表**：13px・等幅数字・右寄せ。行の余白は3px（高さ340px以下では2px）。見出しの行は11px。数値の印（上付き）は既存のまま残す。
7. 既存のテーマ（紺の面・細枠・角の飾り・ボタンの見た目・色の段階 `pt-var-*`）は共通 `menu-dialog` から継承する。新しい色はエラー欄と注記の文字色だけで、既存の警告色に合わせた。

## 2. 生存結果の報酬武器行（`front-result-ui.css` 末尾）

- 行の高さ30px・名前列174px・右端48pxの既存の1丁1行はそのまま。

## 修正1（2026-11-07）：844×390で本文が縦7px溢れる件

- 原因：

## 修正3（2026-11-07）：未保存の注記が操作の段の下へ押し出される件

- 対応：

  - 操作の段の上の余白は変数 `--wd-actions-space` にまとめ、通常6px・高さ340px以下で4pxとした。
