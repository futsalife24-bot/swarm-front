## 共通ルール（Opus・Sol 両判断の一致点＝確定仕様）
- (a) 合図が伝える約束は増やさない。BUDDY合図＋別局面のSSR合図でも「SSRが別にある」とは約束しない。箱を指す合図は、その箱ごとに約束を守る。
- (b) 1回の再生で、同じ局面に出す主たる合図は1つまで。同じ局面に候補が複数ある場合は、結果が約束を満たすものの中から選ぶ（①BUDDY の Fable B-1 と Astra B-1 は回ごとにどちらか）。
- (c) 既存4の対象修正は上記のとおり。
- (d) 10連の最後枠がデフォルト色で出ること自体を②のSSR合図として数える。その回は②の他の合図を出さない。表示予定は再生前に、結果配列から一つの計画として確定する（再生中に決め直さない）。
- 複数局面に合図が立つのは、10連＝SSR2個以上またはBUDDYあり、単発＝BUDDY のときだけ。それ以外は合図は1局面まで。
- 単発でも②の合図が成立するようにする（現行の本編単発には②のSSR合図が1つも無い。Fable S-3・Astra S-4 は単発でも使えること）。

## 実装の進め方
1. 土台を先に作る：演出の選び方を「局面ごとに0か1つ選ぶ」形へ拡張し、検査（verify の eligible 等）に新規合図の下限と複数局面ルールを追加。まず既存候補だけで複数局面の再生が通ることを確認する。
2. BUDDY の3局面を揃える（Fable B-1／Astra B-1／Fable B-2／既存10）。
3. SSR の新規を局面ごとに1つずつ追加し、各追加ごとに固定結果での表示確認と検査を通す。S-6 は最後。
4. 確率・天井・レア度・課金・保存には一切触れない（表示専用）。箱そのものの色は変えない（最後枠ルールの表示色は従来どおり）。
