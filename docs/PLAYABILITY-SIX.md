# 操作・出撃・協力の6件改善と通常入口の一本化

2026-09-15。ユーザー指定のランキング1/2/3/5/8/10を実装。追加指示「試遊版はもういらない、管理者モードだけあればいい」に対応し、試遊版の区分を廃止した。

## 動作と範囲

| 項目 | 実装した動作 |
| --- | --- |
| 出撃前ロード | 地図・兵士・武器・初回描画の準備を待つ共通処理。取得失敗と60秒の期限超過を表示。通常ソロは準備完了後の入場操作まで時間を進めない。協力は全参加者の装備をプレビューして準備し、ステージ・参加者装備・画質の変更で準備をやり直す。 |
| スコープ2個 | 配置編集で1/2個を選択。既定は1個。第2ボタンも位置・大きさ・濃さを保存し、両方が同じスコープ状態を操作する。旧配置を保持。訓練へ未保存の配置も渡す。 |
| 選択UI | ステージ・難易度・武器絞り込み・並び順を既存テーマのゲーム内ダイアログで選択。元の値/change処理・disabledを保持。矢印キー、Home/End、Escape、フォーカス復帰に対応。 |
| 名前 | 初めてプレイへ進むと名前登録。20文字まで。設定から変更し、協力メンバーとチャットに表示。ブラウザ保存に失敗した場合は未保存のまま進めず、既存セーブは変更しない。 |
| 協力ロビー | OPERATION / 参加メンバー縦4枠 / チャットの3列。横640×360でも操作を収める。 |
| チャット | ロビー内のテキスト送受信。200文字・最新50件、再接続時の履歴同期。送信者はサーバーで確定。制御文字正規化、連投制限、HTMLを実行しない表示、他部屋への隔離。勝敗後も送信できるが戦闘中は不可。 |

### 通常と管理者の入口

- `/` は従来の進行機能を持つ通常ゲーム。旧 `?playtest=1` はクエリを除去して同じ通常へ入る。
- `?developer=1` は認証済みの管理者だけが全解放状態へ入る。未認証なら通常へ戻して認証画面を表示する。通常・管理者の表示名に試遊版を使わない。
- 旧ローカルテストセーブへの隠し切替を画面から撤去。管理者の変更は一時的で、再読込でリセットする。
- 既存の通常進行保存キーと旧test保存を保持する。通常初期化は既存の明示確認・バックアップ処理を使用し、勝手に旧武器保存を変換・削除しない。
- 協力は `?coop=1` または招待hashから既存の権威サーバーへ接続。通常ソロの進行と既存協力の武器保存を統一するデータ移行は含めない。
- ホーム画面へのインストール機能を通常入口にも引き継ぐ。実スマホのインストール受入は未実施。
- `playtest-app.ts`、CSSクラス、既存保存キーなどの内部名は保持した。別の試遊版を公開する入口ではない。
