対象はユーザー添付の2画面。改装版 `/front` を従来の出撃準備・読み込みへ揃える。

- `front-app.ts` は既存の `gear / pt-screen / gear-workspace / loadout-slots` 構成と `playtest.css / gear-weapon-list.css` を使用。準備中だけ既存メニューの `playtest` クラスを有効にし、タイトル・部屋一覧・戦闘への移行時に外す。
- `gear-weapon-list.ts` に支給品用の行を追加。旧版と同じ見出し・30px行・性能列・装備印・狭幅時の固定端と同期スクロールを使う。支給品は有限在庫でないためロック・整理・レア度は導入せず「支給」と表示する。
- 左の装備枠を選び、武器名または右端で入替。既にもう一方にある武器は交換し、常に異なる2種を保持。初期強化は装備変更や作戦切替でも選択を保持。選択値はメモリ内だけで管理。

- `front.css` の独自大型表や余白指定を削除し、改装版固有の初期候補と支給品の差分だけを追加。
