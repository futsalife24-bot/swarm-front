# 次はモーションに進む

ただし、いきなり「完成アニメーション一式」はやめたいです。

まず **HOUND Motion Prototype v1** として3動作だけ作るのがええです。

1. **Idle**
   - 胴体がわずかに上下・傾斜
   - 浮遊脊椎3枚が別々の周期で漂う
   - 肩リングが微妙に補正回転
   - 普通の動物の呼吸には見せない

2. **Locomotion**
   - 5脚を普通に歩かせない
   - 長い前脚2本で地面を掴み、身体を引き寄せる
   - 後脚3本は推進・姿勢補正
   - 「犬走り」「蜘蛛歩き」を避ける

3. **HOUND Attack / Lunge**
   - 現行AIの0.45秒予兆と同期できる設計
   - リング収縮→前脚を固定→胴体を前へ射出
   - 実ダメージ判定はまだ変更しない

特に**Locomotionが一番重要**です。見た目がどれだけ良くても、普通の蜘蛛歩きした瞬間に虫感が戻ります。

## モーション側の設計ルール

Blenderではv3の結合済み4メッシュを無理に直接動かすんやなく、**生成前の論理パーツからRig用モデルを組み直す**べきです。

- body root
- front leg L/R
- rear leg A/B/C
- shoulder ring
