# CALYX — ゲーム統合

2026-09-20。中型・非ボス。ユーザー指定の植物型、五枚の外花弁・中央の芯・三本の根脚を持つ歩く蕾。単体候補v2からゲーム導入を再開。

## 実装

- 作戦7「物流争奪」第2波へ2体追加。既存の敵数は保持。FOUNDRYの通常生成候補にも入り得るが、作戦7未満では生成しない。
- 通常サイズ1、モデル倍率1、高さ約2.3m。HP360に既存の作戦/人数補正。移動0.65m/s、GLBの歩行と実移動距離を同期。
- 前方打撃: 開始時の方向を固定、1秒の予兆後に距離4m・120度の扇へ24ダメージ。地面への打撃と短い衝撃の広がりを表示。壁/高度差/回避を考慮。2.2秒まで復帰、その後0.5秒の間隔。
- 花粉弾: 距離8〜28m、狙いを開始時に固定。PollenShotの1.6秒で前方花粉嚢から放物線発射。壁/床/天井と衝突し、着弾地点へ花粉雲。発射後の再選択まで12秒以上。
- 雲は1秒で半径9mへ拡散し、着弾から8秒で消える。最後の0.5秒は縮小。0.5秒ごとに4ダメージへ既存作戦補正。同じ時計で判定し、複数雲が重なっても加算しない。雲から出ると停止。追加の毒/鈍足/失明なし。
- 壁遮蔽と垂直距離を権威側で確認。描画も同じ判定で固定セルを間引く。低解像度の表示セルと厳密な円周は約0.6mの視覚差がある。残留花粉は発生元死亡後も持続し、波切替・戦闘終了で消去。最大16雲。
- ソロとWorkerは同じshared処理。Worldの攻撃開始時刻/固定方向/弾/雲を配信する。図鑑は歩行・待機・両攻撃を表示。CALYX用の会敵ムービーは未制作で、欠損動画ボタンを表示しない。
