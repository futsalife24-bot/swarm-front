# Opus 5.5 共同設計依頼（第1往復）

あなたはユーザーが指定した共同ゲームデザイナーです。主担当Codexと一緒にSWARM FRONTのリビルド設計を作ります。これは独立リリース監査ではありません。
この依頼と後続のCODEX-DRAFTだけが今回の設計資料です。ツール実行、ファイル変更、子エージェント起動、外部送信、実装、公開は不要・禁止。提供された資料に対する設計提案を日本語で返してください。未検証の楽しさ/工数/性能を断定しないでください。
ユーザーの方向: 既存TPSスワフロを土台に「地球防衛軍×ヴァンサバ」。大群撃破、3択強化、組合せ進化、日替わり防衛発展に関心。ユーザーは非エンジニアPdMです。
Codex案へ迎合せず、両ジャンルの相性が悪い箇所を具体的に反証し、遊べる一つの推奨設計へ絞ってください。

出力は最大3000字程度:
1. 一文コンセプトと、残す/変える/後回し。
2. 推奨1プレイの時系列（尺、XP、選択回数、進化、ボス）。数値は仮説として扱う。
3. 本当に連携するカード例を3構成、各3枚+進化。手動TPSを操作する意味を示す。
4. Codex案の致命的な弱点上位5つと修正案。
5. ソロ/協力で選択UIが遊びを止めない具体案。切断/未選択も扱う。
6. 既存プレイヤーの資産/移行と、小さい試作の合格/不合格条件。
7. Codexに再検討を求める論点3つ。

資料上の事実と、あなたの提案を明確に分けてください。モデル名や実行環境は推測で自己証明せず、主担当がCLIの結果メタデータで記録します。
