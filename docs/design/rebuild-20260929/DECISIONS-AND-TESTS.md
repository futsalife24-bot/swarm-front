# 共同設計の論点と検証案

2026-09-29。Codexによる準備資料。Opusの回答は未受領。以下は承認済み仕様ではない。

## 決める順序

1. 何を操作して気持ちよくなるゲームか。
2. 1プレイで何回選び、いつ構成を完成させるか。
3. 強化と敵の配置が、どんな戦術の変化を作るか。
4. 協力で待ち時間・成長格差をどう扱うか。
5. 既存資産・報酬・保存とどう共存するか。
6. 表示/通信の負荷を測り、人数と敵密度の提供範囲を決める。

## Codexが共同検討で確かめたい設計上の対立

|論点|案A|案B|検討する根拠|
|---|---|---|---|
|主操作|主武器は手動、支援は自動|主武器も自動、弱点狙いだけ手動介入|移動だけで成立し過ぎないか、スマホで操作量が過多でないか|
|成長の契機|XPレベルアップですぐ3択|XPで権利を得て共通休息時に3択|気持ちいい即時報酬と、4人の中断回数|
|進化|系統カードの条件達成で自動進化|条件達成後に進化カードを提示|運で完成しないストレス、意図しない武器変化|
|初期資産|所持品性能を持込|新モード内だけ標準化|収集の意味と、1プレイ内の成長幅|

## 仮の1出撃（Codex側の比較基準）

目標は戦闘時間8分前後、強化選択などを含む所要10分以内。ただし人間の選択時間を固定値として保証しない。

|戦闘時刻|体験|強化との関係|
|---|---|---|
|開始前|初期3択で戦い方を決める|方向性が最初から分かる|
|0:00〜0:45|少数の通常敵で操作と最初の効果を試す|初回の追加強化を早めに獲得|
|0:45〜2:30|複数方向から群れ、遠距離敵が混ざる|2〜3枚で連携の予感が見える|
|2:30〜4:00|中型/精鋭への対処|防衛/単体火力を補う選択|
|4:00〜5:00|構成の完成に必要な機会|少なくとも1系統の進化を狙える|
|5:00〜6:30|圧倒できる群れと位置取りが必要な脅威|完成構成を十分に使う|
|6:30〜8:00|予兆のある大型敵と援軍|選択と手動操作の両方で決着|
|終了後|構成と見せ場を振り返り、即再挑戦|未採用の方向性を試したくなる|

これは演出順の仮説。時刻に合わせて敵HPを自動補正する設計ではない。敵が残る区間の切り替え方法は、協力3択同期と合わせて確定する。

## 3択UIの要件案

- 横3枚を基本とし、各カードに短い効果・現在→変更後・影響する装備・進化条件を表示する。
- 長文は詳細へ。説明を理解するために一覧を上下スクロールさせない。
- レア度の色だけで優劣を決めさせず、組合せと発動条件を比較できるようにする。
- 選んだカードは即座に構成欄へ反映し、次の戦闘で発動したことが見える。
- 必須情報は敵の予兆/照準/味方ダウンと競合させない。
- ソロ停止と協力停止は別仕様として明示する。個人選択中の無敵を自由に利用できる仕組みは作らない。

## 試作の合格と作り直し条件

数値は検証計画の目安であり、実測結果ではない。

|問い|確かめ方|作り直す兆候|
|強化が気持ちいいか|最初の1分後、本人に何が変わったか説明してもらう|数値欄を見ないと変化が分からない|
|組合せを選んでいるか|異なる構成を最低3回試し、選択理由を聞く|いつも最高レア/最高火力を選ぶだけ|
|TPSとして操作する意味があるか|同じ構成で狙う/回避する場合と移動だけの場合の脅威対処を比較|主要な敵まで自動攻撃だけで終わる|
|防衛が窮屈でないか|戦場での移動経路と拠点周辺の滞在を観察|ほぼ同じ地点で撃ち続けるのが唯一の正解|
|完成を味わえるか|進化から終了までの操作可能時間を記録|進化直後に終了/長い選択が残る|
|協力で足を引っ張られないか|速い/遅い選択者、切断者を含む2人実通信から確認|毎回待たされる、蘇生役だけ成長できない|
|スマホで成立するか|物理端末で10分、入力/熱/フレーム時間/危険視認を記録|設定低下で危険表示まで消える、狙いや回避が不安定|
|保存が安全か|新旧セーブの同時存在、中断/再開/終了重複を検証|新モードの強化が旧武器値へ書き込まれる|

## 開発の入口

最初は既存マップ1、既存兵士1、攻撃武器3系統、カード12、進化3、大型1の遊べる一部分を作る案。砲塔/兵科追加/多数の新マップ/永続育成/ランキングを同時投入しない。
協力の仕様は最初に設計へ含めるが、初回の楽しさ検証はソロで行い、その後2人、4人の順で成立を確認する。ソロ専用処理を後から継ぎ足して通信版にすることは避ける。
リビルド全体の実装を始める前に、未決の持込方式・主モード化・既存資産の扱いをユーザーに具体案で確認する。現在はその判断材料を作る段階。
