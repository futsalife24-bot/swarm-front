## 依頼1：BUDDY確定の単体演出

### BUDDY専用の見分け方（3局面で共通）

通信ジャックと同じ系統に揃え、3局面を「信号を拾う → 中で何かが生きている → 向こうから話しかけてくる」の一続きにする。

| | BUDDY確定 | SSR以上確定 |
| --- | --- | --- |
| モチーフ | 通信と生体反応（波形・走査線・心拍） | 光・衝撃・破壊などの物理現象 |
| 色 | ティール＋ピンクの差し色。金と紫は使わない | 金（SR下限の流星群・目印は紫） |
| 音 | ソナーの「ピン」、無線ノイズ、2拍の心拍。打撃・金管・鐘は使わない | 重い衝撃、うなり、太鼓、金属 |
| 動き | 生き物の拍（トクン、トクン）で脈打つ | 一撃で走る、割れる、広がる |

### B-1 応答信号（①射出時・BUDDY確定）

- **見た目と動き**
  1. 射出画面が出て止まった直後、標的の輪の上をティールの走査線が1周する（レーダーの掃引）。
  2. 走査線が通ったあと、標的の中心にティールの輝点が1つ残り、「トクン、トクン」の2拍で脈打ち続ける。輝点から同じ拍で細い輪が2本ずつ広がる。
  3. 「射出！」の下に、通信ジャックと同じ書体で小さく `SIGNAL DETECTED /// CH-07` と出る（通信ジャックの `UNKNOWN SIGNAL /// CH-07` と同じ回線番号）。右端にピンクの点が点く。
  4. タップすると、衝撃の輪がティールで広がる。輪の縁は滑らかな円でなく、波形のぎざぎざになっている。
- **音**: 待機中は低めのソナー音が心拍と同じ2拍で鳴る。走査の瞬間に短い無線ノイズ。タップ時は通常の射出音に、音程が下から上がる「応答音」を1回重ねる。金の射出の重い一撃は使わない。
- **BUDDY専用と読める理由**: 色がティールで、形が心拍と波形。金の射出は「標的と柱が金に染まり、粒が舞い上がる」ので、色・形・拍のすべてが違う。回線番号を通信ジャックと揃えるので、一度通信ジャックを見た人には同じ相手だと伝わる。
- **実装メモ**: 既存基盤で実現できる。`kakutei-fx.js` の `gold` と同じ場所（標的の座標 `cx, gy`）に、`ring`・`glow` と走査線（扇形の塗り）で描ける。文字は `jack` の描画と同じ書体指定を使う。波形の輪は `ring` の代わりに点列で円を描く小さな関数が1つ要る。音は `sfx.js` の `reso`（音程のある息）と `modal` で作れる。動き減では走査線と輪の広がりを止め、輝点の色と文字だけ残す。

### B-2 心拍の軌跡（②投下時・BUDDY確定）

- **見た目と動き**
  1. BUDDYが入っているポッドだけ、降下中の尾がまっすぐな筋でなく、心電図の波形になる（ティールの細い線。平らな線に2つの山が繰り返し入る）。他のポッドの尾は通常のまま。
  2. 着地の瞬間、そのポッドの足元からティールの輪が「トクン、トクン」と2回、地面に沿って広がる。地面は割れない。
  3. 着地後、ポッドの上に小さな札が出る。ピンクの点と、横に流れ続ける短い心拍の波形だけ（文字なし）。そのポッドを開けるまで残る。
- **音**: 降下中は心拍の2拍が、落ちてくるにつれて少しずつ大きくなる。着地は通常の着地音の直後にソナー音を2回。地割れの「地面が砕ける音」や流星群の「風を切る音」は使わない。
- **BUDDY専用と読める理由**: 尾の形そのものが心拍なので、「中に生き物がいる」と分かる。流星群（空一面に紫の流れ星）とも地割れ（足元に金のひび）とも、色・場所・形が重ならない。箱の色は変えないので、箱色による段階表示とも混ざらない。
- **実装メモ**: 既存基盤で実現できるが、降下中の尾の描き替えは `core.js` の描画に触れずに重ね描きで行う（既存の尾は残し、上にティールの波形を重ねる）。必要な値は対象ポッドの位置と降下・着地の時刻で、`runtime.js` がすでに持っているポッド情報（`x`・`gy`・`h` と着地の合図）から取る想定。着地後の札は `presage` と同じく待機中も描き続ける。対象は `m.pods.find(p => p.tier === 5)`（通信ジャックと同じ選び方）。1連では中央の1個が対象。動き減では尾の波形を静止した線にし、輪の広がりを止めて札だけ残す。
- **BUDDYが複数入っている10連**: 通信ジャックと同じく、合図を出すのは1個だけにする（札が残るポッドと、通信ジャックで話しかけてくる個体を一致させる）。

## 依頼2：SSR以上確定演出の追加

### S-1 多重ロックオン（①射出時）

- **見た目と動き**: 射出画面が止まった直後、画面の四隅から角括弧の形の照準が3組、時間差で飛んできて、標的の輪に「カチ、カチ、ガチャン」と外側から順にはまる。1組目と2組目は白。3組目がはまった瞬間だけ、3組とも金に変わり、標的の輪が一回り締まる。以後は金の括弧が静かに留まり、タップを待つ。タップ後の射出は通常どおり。
- **音**: 留め金の音を3回、1回ごとに低く重くする（既存の錠の音の系統）。3回目に短い低いうなりを重ねる。
- **SSR以上と読める理由**: 通常の射出は標的が1つ出るだけ。照準が3重に重なるのは「通常より厳重に狙っている」ことを示し、最後に金へ変わるので段階が分かる。
- **既存との違い**: 1 金の射出は「色が金に染まり、タップで金の衝撃波が走る」。S-1 は「タップ前に、形（括弧）がはまる」で、金になるのは最後の一瞬の括弧だけ。光の柱・舞い上がる粒・金の衝撃波は使わない。
- **実装メモ**: 既存基盤で実現できる。標的の座標は `gold` と共通。括弧は直線の描画だけ。待機中に描き続ける方式は `presage` と同じ。音は既存の `lock` と `growl` の部品で足りる。動き減では飛び込みを省き、はまった状態の金の括弧だけ出す。

### S-2 大型輸送機の影（①射出時）

- **見た目と動き**: 射出のタップ直後、ポッドが見える前に、画面の上から下へ大きな機影が地面を横切る（約0.8秒）。影が通る間だけ地面と標的が暗くなり、影の縁に沿って金の航行灯が点々と流れる。影が抜けた直後に、通常どおりポッドが降ってくる。機体そのものは描かず、影と灯だけ。
- **音**: 低いエンジンのうなりが頭上を通り過ぎる（左右に流れ、通過後に音程が少し下がる）。衝撃音は入れない。
- **SSR以上と読める理由**: 通常は影が出ない。「いつもより大きな機体が運んできた」ことが一目で分かり、縁の灯が金なので段階も伝わる。明るくなる合図が多い中で、暗くなる合図は見落としにくい。
- **既存との違い**: 1 金の射出は明るく染める合図。S-2 は暗くする合図で、タップ後に出る。S-1（タップ前）とも時点が違う。
- **実装メモ**: 既存基盤で実現できる。地面に沿った暗い多角形（半透明の塗り）と、縁の `glow` の点列だけ。射出のタップから降下開始までの区間に、通信ジャックと同じ方法で `notap` の短い区間を1つ差し込む。差し込む分だけ演出が約0.8秒延びる。全面を暗くする量は既存の「開封直前の静けさ」より浅くする。動き減では影を動かさず、縁の灯が一度点いて消えるだけにする。

### S-3 音速の輪（②投下時）

- **見た目と動き**: SSR以上のポッドだけ、降下の途中で空中に白い輪を3つ突き抜ける。輪はポッドが通った瞬間に内側から外へ弾け、縁だけが金に光ってすぐ薄れる。3つ目の輪は地面のすぐ上。着地は通常どおりで、地面は割れない。10連では他のポッドは輪なしで降りる。
- **音**: 空気の「ドン」を3回。1回ごとに間隔が詰まり、音程が少し上がる。金属音や地面の砕ける音は入れない。
- **SSR以上と読める理由**: そのポッドだけ速く重いものとして落ちてくる。輪の縁が金なので段階が分かり、どのポッドかも分かる。
- **既存との違い**: 2 流星群は「空一面・ポッドより先・紫の流れ星」。3 地割れは「着地後・足元・金のひびが残る」。S-3 は「降下の途中・空中・そのポッドの通り道だけ・残らない」。場所と時点が3つとも違う。
- **実装メモ**: 既存基盤で実現できる。`ring` を縦につぶして3回描くだけ。対象は `m.pods.find(p => p.tier >= 4)`。必要なのは対象ポッドの横位置と降下の時刻で、B-2 と同じ値を使う。動き減では輪を広げず、通過点に金の縁の輪を一瞬出すだけにする。

### S-4 誘導灯の一斉点灯（②投下時）

- **見た目と動き**: 射出のあと、ポッドが降りてくる前に、画面の左右の端から着地点へ向かって、地面の誘導灯が2列ずつ順番に点いていく（手前から奥へ走る）。灯は白で、着地点に届いた最後の数個だけ金になる。全部点いた状態でポッドが着地し、着地が終わると外側から順に消える。どのポッドが当たりかは示さない。
- **音**: 継電器の「カ、カ、カ、カ」という短い音が、灯の点く順に低めの音程で続き、最後の金の灯で低い鐘を1つ。
- **SSR以上と読める理由**: 通常の投下では地面に何も点かない。「基地の側が特別な貨物を迎える準備をした」と読め、最後の灯が金で段階が分かる。
- **既存との違い**: 2 流星群と同じ「回全体」の合図だが、流星群は空・不規則な筋・紫。S-4 は地面・整列した点・白から金。3 地割れは着地後の破壊で、S-4 は着地前の整然とした点灯。
- **実装メモ**: 既存基盤で実現できる。地面に沿った `glow` の点列を、時刻で順に点けるだけ。着地点の座標は各ポッドの `x`・`gy`。流星群と同じ区間（降下の前から着地まで）に重ねる。点滅はさせず、点いたら消えるまで点きっぱなしにする。音は既存の `tile`（一覧の音）の系統と `modal` の低い鐘。動き減では走らせず、全灯を同時に点ける。

### S-5 共鳴の波紋（③個別タップ時）

- **見た目と動き**: SSR以上のポッドをタップした瞬間、指の位置から金の波紋が1つ、地面に沿って広がる。波紋が届いた順に、まだ開けていない他のポッドの灯が一度だけ明るくなり、開封済みの札は小さく揺れる。波紋は画面の端で消える。そのあとは通常の溜めと開封へ進む。1連では、波紋が画面の端で一度だけ折り返して中央のポッドへ戻る。
- **音**: 低い鐘を1つ（長めの余韻）。波紋が各ポッドに届くたびに、ごく小さな金属の「コン」が応える。
- **SSR以上と読める理由**: 通常のタップでは波紋が出ず、周りのポッドも反応しない。金の波紋が場全体を動かすので「このタップは特別」と分かる。
- **既存との違い**: 4 目印の先読みは「タップ前・目印の▼と輪が紫に変わる」。9 画面割れは「タップを重ねて画面が割れ、景色が変わる」。S-5 は「タップした瞬間・指の位置から・金・1回で終わる」。画面は割れず、止まらず、暗くもならない。
- **実装メモ**: 既存基盤で実現できる。タップ座標は画面割れで `runtime.js` がすでに保持している方法（押した座標の蓄積）を使う。波紋は `ring`、他のポッドの灯は各ポッド位置への `glow`。開封済みの札の揺れは DOM 側なので、省いても成立する（省くなら Canvas だけで完結する）。対象ポッドの最初のタップ直後に重ねるだけで、停止点は増やさない。動き減では波紋を広げず、対象ポッドの足元に金の輪を一度出すだけにする。

## 実装時に共通で必要になること（設計上の注意）

- **演出の選び方の拡張が要る**: 現在の `effect-selection.js` は1回の再生につき演出を1つだけ選ぶ。局面ごとに合図を立てるには、「①・②・③それぞれで0か1つ選ぶ」形に広げ、上の「表示側が守る条件」の表を満たす組だけを許す必要がある。これは表示の選択だけで、結果は変えない。
- **検査の追加**: 既存の「予兆が結果を超えない」検査（`verify.mjs`、`eligible()`）に、新規7案の下限と、複数局面のルール（単発はBUDDYのときだけ複数局面、など）を足す。
- **スキップと2倍速**: 7案とも既存の描画の上に重ねるだけなので、スキップでは描かずに最終結果へ移れる。区間を足すのは S-2 だけ。
- **光**: 7案とも全面の白い光と点滅を使わない。S-2 だけ画面を一時的に暗くする。
- **音**: すべて新しい合成音が要る（音源素材の追加は不要で、`sfx.js` の既存部品で作る想定）。聴感は実機のスピーカーで確かめる必要がある。
