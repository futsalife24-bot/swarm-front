## 参考と判断

- [EDF5公式・武器とカスタマイズ](https://www.d3p.co.jp/edf5/edf/weapon.html): 武器ごとの装弾、威力、リロード、射程等の性能差を確認。今回、ユーザー指定の一行一武器リストに共通指標を並べ、同系統装備との差を表示。散弾は1発の威力×弾数を明記。EDFの素材・文章・固有UIは取り込まない。
- [PUBG MOBILE公式・操作キー配置](https://pubgmobile.helpshift.com/hc/en/3-pubg-mobile/faq/280-i-want-to-change-the-location-of-the-control-key/): 設定からカスタマイズして保存する流れを確認。本作は出撃準備の「操作ボタンの配置」からドラッグ編集し、サイズ・濃さ、保存、キャンセル、初期配置を用意。
- 提供されたAndroid写真: タイトルの縦切れ、HPとミッション欄の重複、武器情報と切替ボタンの重複を実際の問題として扱った。ユーザーによる旧版の実機起動報告であり、修正版の実機合格とは扱わない。

## 変更

- 100dvhとsafe-areaを使い、短い横画面でもタイトルの両開始ボタンを一画面内へ配置。
- 装備と戦利品は縦リスト。系統フィルター・入手順/レア度/1発威力の並べ替え、装備枠、装弾・装填・射程・連射性能、保存済み/未保存を表示。装備中の整理禁止と報酬保存処理は保持。
- 出撃中の情報を上部88pxの専用領域へ集約。操作ボタンをその下の安全領域内にクランプ。HUDの3領域とボタンの重なりを実DOMで検査。
- 回避と装填の残り時間を戦闘状態から読み、ボタンの円形ゲージと残秒を表示。独立した演出タイマーで先にREADYにしない。
- 配置設定は別のversion1キー swarm-front-controls-v1へ端末保存。武器保存形式は変更しない。不正設定で武器庫を消さず、表示は標準へ退避して警告。保存エラーは編集画面に表示。画面サイズ変更でカスタム同士が重なれば標準へ退避し、保存した配置自体は保持。
- 戦闘中の配置編集は今回入れず、出撃準備で操作。協力ミッションを設定のために停止しない。
