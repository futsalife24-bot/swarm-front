# 管理者アクセスの切り替え（2026-09-18）

管理画面の集計を「管理者を除外」（初期値）/「すべて」で切替。期間/前日比/日別/Swarm出撃クリアも同条件。各カードからこのブラウザを登録/解除するリンクを開く。専用URLパラメータanalytics_admin=1/0を処理し、localStorage app-analytics-adminを保存してパラメータを消す。成功/失敗を画面通知。LMF/カタモンは同一originなので登録を共有、別端末/別ブラウザは別登録。登録は集計上の自己申告であり、管理者認証・権限・CORS・IP判定を変えない。

記録済みのアクセスに管理者分類がないため遡及除外はしない。登録後のイベントだけadmin booleanで分類。DNT等で既に送信しないアクセスは全件側にも復元しない。集計は参考値で、第三者が自己申告を偽装することを防ぐ認証ではない。

新規3アプリは既存合計を維持し、別SQLテーブルで管理者アクセス数と管理者イベントだけの訪問IDを記録。一般イベントが一度でもあったブラウザは除外側にも1件、管理者イベントのみのブラウザは除外。Swarmは既存日別KVに任意adminカウンタを追加。同日登録/解除で全体ユニークを二重計上しない。既存集計の移行/削除なし、365日削除に追加テーブルも含む。個別IDは管理画面APIに返さない。

検証: 型、集計/認証10テスト（実SQLite/旧イベント互換/分類変更/保持/不正型）、実Chrome+ローカルWorker4アプリの合計・除外・混在日のユニーク・登録解除・320/390/768幅・期間・失敗/再試行/ログアウト成功。送信先はすべてローカルへ差し替え。LMF check.sh全5項目、カタモン版2+shell3+seat20、まよい30項目成功。物理端末・本番ログイン後の数値は未検証。
