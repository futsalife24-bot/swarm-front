# メニューUI・UX刷新 — 2026-09-10

出撃中のゲームルール・通信仕様を維持し、ホームから準備・武器整理・協力・結果までのメニューを見直した。

## 変更した体験

| 画面 | 変更 |
| --- | --- |
| ホーム | ソロ・協力を主操作にし、武器庫・敵レポート・設定・履歴を整理。作戦案内は実ステージデータから表示し、旧「3波・ボスあり」の誤情報を除去 |
| 出撃準備 | 左欄を作戦と装備2枠に限定。設定・操作・保存説明は専用ダイアログへ。出撃を下部に固定し、左欄のスクロールを解消 |
| 装備一覧 | 効果名と説明、5性能、装備中表示を維持。装備・スロット選択時の一覧位置とキーボードフォーカスを保持。並び替えは実効威力で比較 |
| 武器庫 | 一覧に特殊効果を常時表示。詳細も効果を先頭に配置。比較表を拡大でき、保護・分解操作は詳細下部に固定 |
| 分解確認 | OSの確認窓からnative dialogへ。対象武器すべての効果・性能、レア度内訳、獲得武装片を確認可能。取消を初期フォーカスにし、保存失敗時は削除しない |
| 設定 | ホーム・準備から到達。環境／操作／保存の3タブ、音量・感度の現在値、保存成功・失敗を表示。失敗時の入力値も保存前へ戻す |
| 更新履歴・ヘルプ | native dialogでTab・Escape・戻りフォーカスを管理。長文にはスクロール案内、閉じる操作を常時表示 |
| 敵レポート | 既存3D表示と形態切替を保持し、一覧・解説の続き表示、共通パネル・タイポグラフィを適用 |
| 協力入口・ロビー | 既存の人間確認・招待・復帰・ホスト権限を保持。4隊員・装備・準備状態と主操作の見分けを強化。予定チャット欄は主操作より控えめに |
| 結果 | 戦績を日本語にし、地形に依存しない説明へ。狭い画面でも名前・効果・全性能を表示。戦闘終了直後のダメージ数字がメニューへ残らないように |

見出しにBahnschrift／日本語UI書体、数字に等幅の桁組、ミント色の主操作、金の注意・レア度、罫線・グラデーション・輪郭を共通化。外部フォント・画像通信は追加していない。色だけで区別せず、装備番号・状態文字・レア度を併記。

短い横画面の武器行は50pxへ調整。844×390で準備3丁・武器庫4丁、640×280の整理モードで2丁を完全表示する。長い武器一覧は明示されたスクロール領域とし、準備の左欄はスクロールしない。縦画面でも非戦闘メニューを閲覧できる。
