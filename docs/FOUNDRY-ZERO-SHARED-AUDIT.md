## 検出した問題と修正確認

修正前の `fireLaser` は古い発射予定時刻の直前に対象を見つけても、その時刻で撃っていた。独立したVite SSRのインメモリ再現で、当初は射程外、0.79秒で射程内へ移動、0.80秒で発射となり、予告が0.01秒へ短縮された。

shared担当は `pulseAim` の取得と同時に `acidAt = w.time + 0.8` を設定し、発射後の3.2秒予約は維持した。修正差分と新規回帰条件を読取り確認したうえで、別の独立SSR実行を行った。

```json
{"lateAcquisition":0.79,"oldFireTime":0.8,"actualFirstFire":1.59,"warningSeconds":0.8,"secondFire":4.791,"intervalSeconds":3.2010000000000005,"checks":"passed"}
```

0.80秒・1.589秒では発射しないことをassertした。次回捕捉を理論開始から0.001秒遅くしたため、次弾間隔は3.201秒となる。新規回帰テストでは正確な開始時刻で3.2秒の間隔も検査している。射程境界をunit原点の平面距離から実砲口の3D距離へ揃えた追加修正も確認済み。

## 送信量の補助確認（曲率修正前）

実sharedをVite SSRで読み、3体のFOUNDRYを1,000tick移動させ、通常37体を追加。頭3個の破壊で21体の生成を保留し、投射レコード100件を置き、Workerと同じ数値丸めを使って4人worldのstate envelopeをシリアライズした。個人用pending・rewards・dropsはp0宛の分に絞った。

```json
{"wireBytes":28452,"wireLimit":65536,"enemies":40,"bosses":3,"projectiles":100,"pendingGeneration":21,"historyPoints":[32,32,32]}
```

ファイル・ネットワークを変更しないインメモリ負荷fixtureであり、100発は送信量を測るための合成レコード。実Workerで100発同時に撃たせた結果や、全アイテム・イベントが最大の全状態を保証する測定ではない。実Worker射撃・公開用UI検証は主担当の別記録を参照する。

## 曲率・切断方向の最終差分再監査

同日、初回shared監査後に追加された `worm.ts` の曲率処理と、`game.ts:641` 付近の切断後headingを消去しない変更を再監査した。`foundry-navigation.ts` の関数本体は今回の追加修正対象外。既存の生成・抽選・レーザーsweepは再実行していない。

- `worm.ts:216`：初期routeは、配置済みのheadingに対して最も小さく曲がる安全経路を選ぶ。胴が置かれた後方へ即座に反転する原因に対応している。
- `worm.ts:262`：角まで1m以内で次の角へ直接進める場合だけ、通過可能な経路点を省略する。壁を抜ける直線化を行っていない。
- `worm.ts:281`：旋回量を移動距離÷半径で制限し、実際に辿った経路を履歴へ保存する。3節以上は半径目安2.8m、2節は1.6m、単体は0.4m。複数節では目標付近で半径を縮小するため、固定半径を全地点で保証する実装ではない。
- `worm.ts:306`：波形の進路が塞がれたら旋回上限内で目標方向へ再試行する。それも塞がれた場合は中心位置を動かさずheadingだけを更新し、次tickで現在位置から経路を再計画する。残移動量を消費せずループし続ける経路はなく、即breakする。
- `game.ts` / `worm.ts:376`：破壊直後の次節のheadingを保持し、旧snapshot等で欠落している場合だけ履歴末尾の向きを復元する。新leaderの履歴引継ぎと一致する。

差分に必須修正は検出していない。洞窟で2節chainが曲がれなくなる事象は、実装担当が半径1.6mと再計画で修正したものとして受領した。新規の既知折返し回帰は241tickで隣接中心距離>2.8m・非隣接>4.5mを検査し、既存の6マップ巡回・洞窟を含む全切断chain到達・3体snapshot回帰と併せて条件を読取り確認した。任意の長時間・全切断順序で自己交差が一切ない保証までは、この有限回帰から主張しない。

本担当は上記の成功済み試験を重複実行していない。実装担当から既知折返し・洞窟到達の成功を受領し、最終の全suiteおよび実Renderer検証は主担当の統合記録へ委ねた。前項の28,452 bytesは曲率修正前の補助測定値であり、最終曲率で再測定した値として扱わない。
