# 週間ミッションをタイトルへ移動

2026-09-17。設定内の週間入口を削除し、タイトルの既存操作ボタン群へ追加。達成済みかつ未受取の週間ミッション数を右上の赤い数値で表示、0件は非表示。保存/クラウド反映、タイトル描画、タブ復帰、60秒ごとの週判定で更新。バッジの週判定は端末時計を用いる表示上の目安で、報酬の週・受取可否は従来どおりサーバーで判定する。

既存のボタンテーマを使用。角の切り抜きで通知を欠けさせないよう右上内側に配置し、900px以下は操作群を2列にする。ボタンの読み上げ名にも受取可能件数を含める。クラウド未接続でも入口から既存の有効化案内を表示する。

検証: 型チェック・標準/Pagesビルド成功。`scripts/check-weekly-title.mjs` は実Chrome+ローカルWorker/SQLiteで3件達成fixtureから報酬をUI受取し3→2→1→0、合計800コイン、0件/旧週非表示、設定入口削除を確認。1280/844/640×390のボタン/通知の画面内配置・クリック可能性・画像を確認。実機未確認。通常UIの既存継続テストも新しい入口へ更新。
