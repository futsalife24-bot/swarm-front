# 2026-09-14 試遊版の既存UI復元

ユーザー指摘どおり、初回の試遊版は共通の `menu-theme.css` と `body.dataset.screen` を接続せず、タイトル・準備画面・設定・HUDを別構成で作っていた。先の「100%」「仕上げ段階」という評価は、既存UI/UXの継承確認を欠いており撤回する。本記録はUI修正の検証であり、ゲーム全体の完成・実機受入を意味しない。

## 修正

- `src/client/home-screen.ts`：既存タイトルのHTMLを共通化。ロゴ、4つの主ボタン、アイコン、案内文、装飾を既存版と試遊版で共有。既存 `src/main.ts` の今回差分は、この関数のimportとタイトルHTML呼び出しへの置換だけ。
- `src/client/playtest-app.ts` / `playtest.css`：既存テーマと画面状態を接続。準備画面は左に出撃先・装備2枠、右に武器一覧、下に出撃操作。フィルターと整理をヘッダーへ配置。育成とアクセサリは同じパネルを使用し、兵士登録を育成へ移動。新規進行の控え保存確認は初回の出撃等から開く。
- `src/client/hud.ts`：既存HUDを共有するため、最大HP・次波表示とソロ時の蘇生ボタン更新抑止を任意引数で追加。既存呼び出しの既定動作は維持。救急箱は既存操作レイアウトの蘇生枠を使用し、独立した重複ボタンを廃止。
- `src/client/playtest-preferences.ts`：既存設定のタブ・行スタイル、感度、射撃感度、ジャイロ、画質、音量、ミニマップ、ダメージ表示、配置編集の導線を復元。同一オリジンの旧保存から初期設定を読み、以降の試遊設定は別キーへ保存。配置は既存配置キーを共有。保存失敗は表示し、設定変更前の値を維持。
- 関連ブラウザ確認スクリプト4本の操作先を新導線に更新し、`scripts/check-playtest-restored-ui.mjs` を追加。
