# 3択の取得区別と現在の強化（2026-10-05）

利用者の「新規獲得とレベルアップを区別」「3択の空きスペースに現在の強化と選択具合が分かるボタン」に対応。

- 新規獲得は青緑の「＋ 新規獲得」、段階アップは金色の「↑ 段階アップ」。色だけに依存せず、文字・記号・「未取得 → 1段階」「2 → 3段階」で判別。
- 中央3択の見出し左に「現在の強化 取得数/上限」。押すと取得済み項目・各段階・効果・進化条件を表示。「3択へ戻る」またはEscで閉じ、候補と選択回数を維持する。
- 協力プレイの選択期限は従来どおり進行し、その旨を詳細内に表示。戦闘、抽選、保存、旧版の規則は変更しない。更新前作戦のカード文言も既存の委譲を維持。
- 強化3択と詳細以外の画面配置は変更しない。生成済みの各項目画像を再利用。
