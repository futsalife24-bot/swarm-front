# タイトル・メニュー演出の品質改善（2026-10-07）

対象はタイトルの操作演出と、[MENU-EFFECTS.md](MENU-EFFECTS.md) の12場面。戦闘演出と兵士音声PR137は対象外。配置・文言・武器1行表示・保存/通信/入力の規則は変更していない。新規依存・課金・外部サービスなし。

## 実画面で見つけた問題と変更

時刻を固定したコマ撮り（Web Animationsを停止して各時刻を描画）で変更前後を比較した。[比較画像](evidence/menu-polish-20261007)。

| 場面 | 変更前の問題 | 変更 |
| --- | --- | --- |
| 共通の時間配分 | 全体に強い減速カーブを掛けていたため、保持→消える段階付きの演出が前半で消え、線を描き終える前に薄くなっていた | 段階付きの演出は実時間どおりに進め、カーブは各区間に付ける |
| タイトル→次画面 | 遷移線の行き先が新画面全体の外枠で、左上へ伸びて画面幅に広がり、意味も視認性もなかった | 押したボタンの下線が、開いた画面・ダイアログの見出し文字の下へ移る（280ms、非同期ガードとフォーカス復元は維持） |
| 装備変更（保存される装備） | 再描画前の古い行位置の中央（数値の上）から線が出て、描き終わる前に消えていた | 再描画後に「E」表示となった押した行から装備枠へ光点が移動し、到着後に枠を描く。押した行も短く明るくする |
| 作戦選択 | 地形がモード/ステージでほぼ同じ形。装備変更の再描画のたびに入場をやり直していた | ステージ/モードごとに異なる稜線。動きは出撃先が変わった時だけ |
| 協力部隊 | 参加と準備完了が同じ枠線で区別できなかった | 参加は枠線、準備完了は「準備完了」の文字の横にチェック |
| アクセサリ作成・一括合成 | 粒子が行の空白中央に集まり、何から何へ変わったか分からなかった | 押した作成/合成ボタンから新しい完成品のレア枠へ粒子が流れ、到着でレア枠が締まり行を一度だけ光が横切る |
| 育成 | 確定時にレーダー周囲の汎用矩形を描いていた | 確定値の多角形をなぞり、変更した能力枠を内側で強調（ボタンの切り欠きで欠けない） |
| 敵レポート | 一様な格子が160ms程で一斉に縮んで消えた | 走査線に合わせて左から列ごとに解析が完了する |
| 週間報酬 | 粒子が所持コインの左の固定位置から出ていた | 受け取ったミッション行のボタンから所持コインへ金色の粒子が流れ、到着時に確定値が入る |
| 改装版の操作ガイド | 「戻る」ボタンを丸で囲んでいた | 開いたガイドの見出しに下線を描く |
| チュートリアル | 高速にタブを切り替えると前のタブの丸囲みが残った | 新しく選んだタブだけを囲む |
| 設定・強化候補の保存 | チェックが保存文から離れた行の右端に出た。スライダー操作のたびに描き直していた | 保存文の直後に置き、連続保存中は描いたまま表示を延長 |
| サウンドテスト | 再生中に光点が脈動し続けた | 3本のゆっくりしたレベルメーター（動きを減らす設定では静止）。実際の再生状態で点灯/消灯 |

武器詳細の光の横切りと更新履歴の新着表示は適切と判断して維持した。成功演出は従来どおり実際の保存・作成・受取の成功後だけで、改装版の一時装備には保存の線/枠/発光を出さない。未遭遇・協力遭遇シルエットの制限も不変。

併せて `menu-effects.ts` をDOMなしでもimportできるようにし、mainで失敗していた `tests/front-feedback.test.ts` と `tests/media-dialog.test.ts`（`matchMedia is not defined`）が通るようにした。
