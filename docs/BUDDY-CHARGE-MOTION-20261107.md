# バディの短押し・チャージ・発動モーション（2026-11-07）

## 対象と仕様

本人依頼: 短押しはその場でモーション後に発動、長押しはチャージして強化。タタラはジャンプして着地時に衝撃波を出す。

- 進撃バディだけを変更。生存・防衛へバディを追加しない。
- Gキーと既存スキルボタンは押して保持、離して1回発動。短押しの基礎効果・再使用時間・成長率は維持。
- 押し始め0.2秒は通常タップ域、それから1.5秒で最大まで連続強化。保持時間は権威Worldの時刻で計測し、クライアントの自己申告倍率は受け取らない。
- 最大チャージ: タタラの威力60→90、半径4→5m。ヨスガの5秒間の本人総回復量は最大HP25%→37.5%。トバリ・オリハは既存軽減/移動/回避倍率を維持し、支援時間6→9秒。再使用時間20/25秒と範囲/味方判定は維持。
- 解放時点でバディ位置を固定。タタラは0.65秒後の着地で効果、ほか3体は0.35秒後に効果。回復動作0.2秒後に追従へ戻る。支援は解放時の持ち主位置を中心に発動する。
- タタラは屈み→跳躍→着地。採用GLBは変更せず、既存Display/Palmを絶対時刻で1回だけ再生。通常攻撃では跳躍しない。
- HUD配置/CSSは維持。既存の輪・中央文字で充填率/最大/発動を表示し、アクセシビリティ説明も更新。
- 中断・フォーカス喪失・pointercancel・無効化はチャージを取り消す。ダウン・切断は待機中の効果も取り消し、再接続で再発動やCDリセットをしない。
- 新規モデル・新規通信先・資格情報・契約・権限の変更はない。
