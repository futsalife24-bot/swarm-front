## 起動と再開

既存の作業フォルダを上書きしない。新しい空の場所へcloneするか、既存checkoutのorigin・HEAD・変更状況を確認したうえで、このブランチを取得する。未保存差分へreset/clean/stashを自動実行しない。

```sh
git clone --branch codex/rebuild-p1a-cloud-20261001 https://github.com/futsalife24-bot/swarm-front.git swarm-rebuild-p1a
cd swarm-rebuild-p1a
git status --short --branch
git rev-parse HEAD
npm ci
npm run typecheck
npm run test:rebuild
npm run dev
```

試作入口は `http://127.0.0.1:5186/rebuild-p1a.html`。通常の入口・bootstrap・save-writerとは別のHTMLを使う。通常公開用buildに試作入口を追加しない。

```sh
npm run build:rebuild
npm run test:save
npm test
npm run build
npm run server:build:production
npm run test:rebuild:e2e
```

LinuxでChromeではなくChromiumを使う場合は `CHROMIUM_PATH=/usr/bin/chromium npm run test:rebuild:e2e`。権限のないホームディレクトリを持つ一時環境ではWranglerのログ/設定先だけを作業可能な一時領域へ指定する。認証情報の追加やデプロイは不要。

## 完了・受入の区別

1. 実装・自動検証: 初期/追加選択、候補保証、再抽選、爆発起源と上限、XP/時間境界、全停止、勝敗/再挑戦、報酬・保存分離
2. 実ブラウザ: 844×390 / 640×360、選択・再開・押しっぱなし・blur・繰返しクリック、旧保存不変、コンソールエラー
3. 人間の試遊: 1分で違いを説明でき、狙う最初の敵を変える理由があるか。自動botの勝率は面白さの合格証明にしない
4. 実スマホ: 可読性・入力体感・フレーム時間・10分の発熱は物理端末で別途確認
5. 独立監査: リポジトリ指定のIAB通常Chat経路。自己レビューや自動テストで代替しない

実装と自動検証を進め、既存の描画・兵士・武器・操作・テーマを利用する独立入口を追加した。ブラウザの起動制限によりUI受入は未実施。詳細は [検証記録](REBUILD-P1A-VALIDATION.md) を正とする。指定の独立監査、人間の試遊、実機受入は未合格。

## PC引き継ぎと安全な巻き戻し

- GitHub専用ブランチへの試作コード・テスト・引き継ぎ資料の保存は、2026-10-01のユーザーの具体的な承認による。通常の実装→検証→失敗した試作変更の戻しもこの隔離範囲で続ける
- 元のmain `4520c57ede444d44b8699753645f36ce479b72bf` を不変の比較基準にする。旧PC・新PCの未保存作業を取得/削除/上書きする許可ではない
- ローカル初期checkpoint `c46e85979142d0c15bd75472e0b425e1c8dc34b5` とGitHub初期checkpoint `0e37bbb32855e0f24c1664fb04b4b921951e2903` は同じtree `7dec49adfb174ce13e9a8e2f700965c51ba14d85`。Git CLI認証がないため、許可済みGitHub接続で同じ内容を保存し、tree一致とremote refを照合した
- 新PCでは冒頭の新規clone手順を使い、`git rev-parse HEAD` をGitHub専用ブランチと照合。依存はlockfileから再構築する。既存の作業場所へのreset/clean/stashは禁止
- 基準版と比べる際は、新しい空の作業場所で `git worktree add --detach ../swarm-p1a-baseline 4520c57ede444d44b8699753645f36ce479b72bf` を使える。既存のディレクトリを指定しない
- 新しい実験が悪化した場合は、直前の検証済みcommitを残し、新しい実験commitだけをrevertして再検証する。履歴書換え/force-pushで戻さない。他の作業差分を巻き込まない
- 本番はこの試作を公開していないため、本番をロールバックする操作は不要
