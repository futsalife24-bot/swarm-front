# 3人マルチ軽量化・部屋一覧とID参加（2026-09-16）

branch: `codex/coop-performance`。base/main: `ce0c31d70c89ebb703adfd5a450ca44b067fd371`。
未反映PR #15の `fa659f6b60950797d2e7b71e67fc5d42cb6edf8c` を引き継いだ統合差分。#15を二重にmerge/deployしない。

## 変更

- 影を2048から1024へ。低FPSが2秒続くと描画解像度を段階的に下げ、安定後に戻す。最低65%。保存済み画質設定とUI文字の解像度は変えない。
- 味方の骨格更新を近距離30Hz／25m超15Hzへ。移動補間は毎フレーム、装填・武器切替・ダウン等は即時更新。モデル原本・モーション自体は変更なし。
- 射撃・爆発演出のMesh/Materialを再利用。低画質・遠距離では火花数を抑え、当たり判定とダメージは維持。
- 共通の戦闘状態を1回だけJSON化し、装備が変わらない間は接続単位で再利用。再接続・装備変更・終端は完全な装備を送る。旧クライアントは完全形式を継続。武器の小数性能値、所有者別のドロップ・報酬を保持。
- 入力は50ms以上間隔を空け、確認待ち最大4件。滞留中の単発操作を保持する。サーバーの送信頻度制限は維持。
- 爆発範囲外の敵への遮蔽物探索を省略。計測で戦闘計算の余裕を確認できたため、大規模な空間分割への置換は見送った。
- 協力入口を「部屋を作る／公開部屋一覧／8文字ID参加」に変更。カタモンの `stage1-repo/coop-mvp-room.js` の参加構成を参照し、既存のスワフロUIとWorkerへ実装した。Firebase・認証コードは流用していない。
- 公開／ID・招待のみを作成時に選択。既存の32文字招待・再接続は維持。公開一覧は募集中で1〜3人の部屋を最大20件、空室・満員・戦闘中・更新90秒超は除外。IDは1時間の既存部屋寿命まで有効。プライベート設定は一覧非表示であり、IDを知る人の参加を許可する。
- 既存の人間確認・作成数/接続数上限を維持。部屋参照はIPごと30回/分のメモリ内制限、一覧情報は非キャッシュ。更新は非同期のため短い表示遅延はあり、参加可否はRoom側で最終判定する。
