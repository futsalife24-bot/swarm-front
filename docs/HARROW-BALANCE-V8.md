# HARROW v8 戦闘調整の根拠

2026-09-24。ユーザーの「現在のスワフロ最強ボス相応の攻撃力・威圧感」「優雅な羽ばたきだが鈍重でない」という追加指示に対応する採用値と検証条件。数値表は共有コードの生成・ダメージ式から算出したもの。戦闘コードの実装・統合検証は主担当が行い、確認済みの単体検証だけを末尾に記録する。

体格3倍（描画scale 1.95）、巡航0.64m/s、飛行高度34.5m、空中直立、滑空2.1秒、羽ばたき周期4.2秒を維持する。既存の武器性能・波編成・ステージ倍率・プレイヤー性能は変更対象外。攻撃は既存のミサイル・回転・滑空ダイブの3種とし、AirThreatは空中姿勢用の演出クリップとして扱う。

## 既存個体との比較根拠

参照: [敵定義](../src/shared/defs.ts)、[個体サイズ](../src/shared/enemy-size.ts)、[生成・被弾処理](../src/shared/game.ts)、[ステージ倍率](../src/shared/stages.ts)、[ソロ進行](../src/shared/solo-progression.ts)、[HARROW](../src/shared/harrow.ts)、[CALYX](../src/shared/calyx.ts)、[FOUNDRYレーザー定義](../src/shared/foundry-defs.ts)、[連結炉](../src/shared/worm.ts)。

- HARROWの戦闘サイズは1。見た目のscale 1.95はHP・威力に掛けない。v7時点の基準HP5200、攻撃22/34/44は、巨大化だけでは増えていなかった。
- 通常型FOUNDRYは戦闘サイズ2なので、単独時の基準HPは4200×2＝8400、踏み付け威力は40×2＝80。予告3.1秒・半径7m、命中後の待機は3×2＝6秒。攻撃周期の理論最短は約9.1秒。
- CALYXは基準HP360。近接は威力24、予告1秒、半径4m、全体2.2秒＋待機0.5秒＝理論最短2.7秒。花粉は予備1.6秒＋弾道1.2〜1.8秒、半径13.5m、威力4/0.5秒、寿命8秒。重複した花粉の継続ダメージは加算されない。
- 連結炉は各節が0.8秒予告し、威力10×個体サイズのレーザーを撃つ。発射周期は4.8秒×max(1,個体サイズ)。複数節・破断後の移動による継続圧があるため、1発の威力だけでは比較しない。
- v7 HARROWは回転6.3秒＋待機3.5秒＝理論最短9.8秒、Threat7秒＋待機3.5秒＝10.5秒。低い基準威力に長い空白が重なっていた。採用値では回転8.1秒、Threat8.8秒が目安になる。実際は射程・旋回・状態遷移・50ms刻みの処理に左右される。

ソロの敵HPは基準HP×戦闘サイズ×ステージHP倍率、被弾は基準威力×ステージ攻撃倍率。中難易度は通常に対しHP1.25倍・攻撃1.15倍。複数ボスの同時出現ではHPを√ボス数で割るが、対象3作戦の最終波HARROWは単独なので除算されない。

## 予告と回避の公平条件

プレイヤーの基準歩行は7m/s、移動強化最大で8.05m/s。回避は17m/s・公称0.32秒・再使用2.2秒。障害物なしの公称回避移動は5.44mで、正確な到達点は50ms刻みの実処理で確認する。

- ミサイルは左右5発ずつ。表示済みの目標地点は固定し、予告後に兵士へ追従させない。採用値ではマーカーから着弾まで3.5＋1.8＝5.3秒あり、基準歩行の移動距離は37.1m。予告・翼の動き・発射口・実際の発射を同じ時計に合わせる。
- ダイブは滑空2.1＋急降下0.9＝3秒。基準歩行なら21m移動でき、固定された半径12mの着地点から離脱する余地がある。移動中の標的へ着地点を更新してはならない。
- 回転は半径21.2m、予告1.4秒。中心から予告時間内に徒歩だけで離脱することはできない。現行の「回避中の最初の接触も対象IDへ記録し、同じ回転で追撃しない」挙動を維持し、タイミングを合わせた回避を有効にする。
- ダイブ着地から次の回転初撃までは、Land1.75＋待機1＋予告1.4＝最短4.15秒。回避の再使用2.2秒より長い間隔を維持する。
- 地形に投影する赤円と権威側の攻撃半径・遮蔽条件を照合する。壁越し被弾や、赤円の外なのに見えない範囲で被弾する状態を避ける。

## 主担当が実施する検証

以下は統合時の受入条件。末尾の単体検証で確認した一部と、未実施の統合・実機確認を区別する。

1. ST25中難易度・HP160で単発ダイブ後に生存する。回転/ダイブは重い被弾として表示し、ダメージ倍率はクライアントとWorkerで一致する。
2. 回転の判定開始に合わせて回避した兵士は、その回転中に追加被弾しない。回避が間に合わない場合も同じ回転で複数回減らない。円の内側・境界・外側、壁を挟んだ位置を検証する。
3. ダイブの予告地点が固定され、開けた場所では予告を見てからの歩行で離脱できる。滑空2.1秒と最終0.9秒の切替に瞬間移動・姿勢の飛びがない。
4. Threat / AirThreatから左右5発ずつ発射し、3.5秒時点の実モデル弾頭位置と生成原点が一致する。ミサイル飛行1.8秒でも屋根を貫通しない。発射前死亡/怯みは未発射分を取消し、発射済み分は既存規則を維持する。
5. 空中直立と優雅な羽ばたきを実描画で確認する。高度34.5m・巡航0.64m/s、地上/空中交替、1回転、12%累積損傷による怯み落下を維持する。HP増加によりST25の怯み閾値は通常1689.6・中2112となる。
6. 15-A/ST20/ST25×通常/中難易度の計6作戦を現行武器・合法装備・既存波のまま完走検証する。所要時間、残HP、救急箱、作戦目標時間に対する余裕を記録する。15-A最終波は護衛なし、ST20は護衛18体、ST25は24体という差を保つ。
7. 通信・中断再開でHP、攻撃値、予約済みミサイル、回避済み対象、AirThreatを含むモーション時刻が一致する。保存済み攻撃の二重予約・二重被弾を起こさない。

ボットの完走だけで人操作の難易度やスマホの見やすさを合格扱いにしない。最終の実施結果・対象SHA・証拠へのリンクは主担当の統合記録へ残す。

## 実施済みの限定検証

- 実際のST25中難易度のtickと倍率で、未強化兵士がダイブを受けHP160→3.416で生存。続く着地でも二重被弾しない。
- 既存の固定乱数1000回抽選は45%用の範囲390〜510回で成功し、ダイブの目標固定・着地位置を確認。
- 既存のミサイル取消、保存/通信、空中会敵、地形支持、怯み落下の回帰を同じ20件に含む。全6作戦の完走、実通信複数人、v8全クリップと判定の一致、実ブラウザ/実スマホは主担当の後続検証対象。

## 独立監査F1: 公開済みv6の中断保存からの移行

2026-09-24、公開済みv6（`5e743d32dcb23d9771db23fdfaebc90cc2e85e68`）の中断形式とHARROW定数を確認。v7は未公開であり、旧形式を公開済みv7保存として扱っていない。旧保存は攻撃開始時刻・移動の始終点・ミサイルの発射点/発射時刻/着弾時刻をそのまま含むため、新しい時間・体格だけで再開すると、旧Threatの2秒発射が新予備3.5秒より先になり、旧Takeoff途中の位置も逆戻りする。

`battle-checkpoint.ts` は新規保存をversion 3とし、version 1/2は凍結campaignの復元・検証後に `harrow-checkpoint-migration.ts` で一度だけ移行する。保存キーは維持し、読み込みで元の保存文字列へ書き戻さない。次回の通常保存からversion 3になる。

- 旧Spin/Threatを終了扱いにして3.5秒以上の待機を与え、次の新しい予告から現行攻撃を始める。旧Spinの命中済みリストを新攻撃に転用せず、旧攻撃自体からの再命中を防ぐ。
- Takeoff/Glide/Dive/Landは保存時の実位置から、その直下の支持面へ無害なLandを行う。StaggerFallは保存位置から改めて落下し、獲得済みの怯み時間を失わせない。旧攻撃の出発点への逆戻りや旧Dive着弾は発生させない。
- 未発射のHARROWミサイルだけ取り消す。すでに発射された弾は死亡済みの発射元も含め、ID・原点・目標・発射/着弾時刻・旧威力を完全に保持する。移動・追尾し直し・再発射・新威力への置換はしない。
- プレイヤー・進行・武器・通常弾・他種の敵・報酬・凍結campaign・経過時間・乱数状態・採番を保持する。生存HARROWの現在HP/最大HPと空中蓄積損傷も保持し、8800基準への途中回復をしない。新しく生成されるHARROWは現行8800、新たな攻撃は現行36/84/92を使う。
