# HARROW 地上回転 v9

2026-09-24。ユーザー依頼は「範囲が狭い・遅い・ただ回るだけ」の改善。参照は [特異個体ティガレックス 回転攻撃](https://www.youtube.com/watch?v=-_46t4DS4gE) の2〜6秒、手前のプレイヤーは対象外。動画そのものをゲーム素材へ転用せず、低い溜め、片側へのひねり、翼を張る速い薙ぎ払い、接地して止める動きの組み立てを参考にする。

## 対象と設計

- branch `codex/harrow-spin-impact`、base `a6973ed3197d305f67f1c426f08d41c97dc1539b`、作業場所 `../harrow-integration`。元 `game` のClaude/設定/敗北導線の差分は保護する。
- 予備1.40→1.15秒、一周3.50→1.05秒、回復を含む全体6.30→3.00秒。権威側の向きはsmoothstepで加速・制動し、ルートの一周をアニメーション側へ二重に入れない。
- 攻撃半径21.2→28m。翼の薙ぎ払いに地表の風圧を伴う同じ1回の攻撃として表現する。予告円と風圧外縁を28mへ揃える。威力84、回避と命中済み記録、遮蔽を維持する。
- 攻撃選択や近接着地の距離は21.2mを別定数で維持。会敵、体格1.95、飛行高度34.5m、ミサイル、滑空・ダイブ、HPには変更を加えない。
- Blender候補v9はSpinだけを作り直す。胴の沈み込みとひねり、脚の蹴り出し、翼の展開、首・尾の遅れ、踏み直しを追加。v8原本は保存する。
- 公開v8の中断形式v3で途中Spinを保存していた場合、新しい時刻へ直接読み替えると向きが飛び、予告前の保存から即被弾し得る。v4への読み込み時にそのSpinだけを安全に終了し、位置・向き・HPと他の状態を保って待機を与える。

## 性能と限界

風圧追加の固定配列は1,971,200 bytes/view、戦闘と図鑑で3,942,400 bytes（GPUにも同程度の配列）、最大2draw/256粒。デスクトップNodeの初回地形準備は2フレーム分で71.66/50.71ms、キャッシュ後の更新平均0.00117ms。初回準備は単発負荷があり、実スマホGPU負荷や人操作の難度をこの数字から合格扱いしない。

接地の厳密計測は水平面でのモデル検証。起伏上で全ての脚/翼が同時に地形へ密着するIKは追加しておらず、斜面では支持点から離れた部分が浮く場合がある。風圧/予告の地形追従とは別の制約。既存の倉庫見た目屋上8m/支持面6m差、球形身体判定、長時間多数接続は今回の改修対象外。
