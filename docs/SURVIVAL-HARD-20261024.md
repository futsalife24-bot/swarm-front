# 生存の難易度引き上げ（2026-10-24）

本人「スワフロの生存モードの難易度を結構上げてほしい」。生存（融合サバイバル）だけを対象に、敵の体力・攻撃力・出現頻度・時間経過の上乗せ・敵構成を強めた。攻略・防衛・デイリーは変更なし。報酬・BASTIONの出現規則・同時数上限96は変更なし。

## 変更内容

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 進度の敵体力倍率 | `1 + ST × 0.055` | `1.25 + ST × 0.07` |
| 進度の敵攻撃力倍率 | `1 + ST × 0.025` | `1.3 + ST × 0.045` |
| 進度の出現頻度倍率 | `1 + ST × 0.03` | `1.25 + ST × 0.04` |
| 時間経過の敵体力 | 3分ごとに +0.35 | 2分ごとに +0.35 |
| 時間経過の敵攻撃力 | なし | 2分ごとに +0.08 |
| 射撃型（spitter） | 120秒以降・6回に1回 | 60秒以降・4回に1回 |
| 飛行型（hornet） | 210秒以降・8回に1回 | 150秒以降・5回に1回 |
| 1回の出現数 | 2体 | 5分以降は3体 |

例: ST25の開始時は敵体力 2.375→3.0倍、攻撃力 1.625→2.425倍、出現頻度 1.75→2.25倍。10分経過時は体力の時間上乗せが 2.05→2.75倍、攻撃力が 1.0→1.4倍。

実装は `src/shared/front-survival.ts`（`frontSurvivalDifficulty`・`frontSurvivalTimeScale`）と `src/shared/front-run.ts`（`survivalDamage`・`schedule`）。攻撃力の時間上乗せは出現処理のたびに `campaignPlan.damage` を更新して反映する。
