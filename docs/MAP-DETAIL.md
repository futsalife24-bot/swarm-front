# マップ精細化・倉庫入口・軽量モード（2026-09-12）

## 変更

- 街区・倉庫・工業区の空き地に孤立していた階段を撤去し、既存建物の西側外壁につながる階段・高さ1.2mの荷役台・シャッター入口へ再配置。荷箱と台の緩衝材を追加。階段は0.3mずつ4段。中央の進行路・建物の衝突形状は保持。将来の廃墟表現では建物の基礎・瓦礫とセットで配置するというユーザー補足を反映した方針。
- 全6マップの本体に三角形の4分割（辺の細かさ2倍）を適用。標準は近距離を4倍、遠距離を従来密度に切り替える。切替境界はタイル中心から55/65mのヒステリシス。元の輪郭と床高度を保つ。ポリゴン増だけで形状が写真のようになるという実装ではない。
- 標準は地面の法線を高度場から求め、元の素材を保持して粒感・風化の濃淡・粗さを追加。屋外の遠景GLBは据置。原本のBlender/GLBも保持し、読込み後に加工。
- 同じ素材をBatchedMeshでまとめ、タイル単位で画面外を除外。頂点はUV・法線の境界を保って共有。小物はインスタンスでまとめ、輪郭線の別描画を廃止。主マップは選択中の1つだけ保持し、切替時に旧マップの形状・材質・テクスチャ・バッチ内部GPUデータを解放する。遠景は既存キャッシュ。
- ホーム／出撃準備の設定と戦闘中の一時停止に「標準（精細な地形・質感）」「軽量（従来の描画）」を用意。既存quality=1/0.65の保存を利用し、保存形式の移行なし。軽量は従来密度・従来の法線／質感と既存の解像度65%設定。新しい階段配置と描画のまとめ処理は共通。モード変更はマップの再読込み後に反映し、戦闘状態を初期化しない。
