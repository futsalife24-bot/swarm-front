# 武器性能印の同レア基準統一（2026-09-16）

ユーザー指摘: 同レア度なのに異なる値の多数の武器へ★が付く。★は+20%限定、全武器の印を統一。

原因は旧形式の倍率をレア度補正なしで判定し、20%以上をすべて★としていたこと。旧装弾も整数化前のrollを使っていた。PR #25の復元時に残っていた基準の不一致を修正。

- 同じ武器種・表示レア度の現形式補正0を共通基準にする。旧rarityは+1で現形式gradeに対応。新形式の補正・固定装弾は従来通り。
- 旧形式の威力はpower、装弾は実際の整数弾数、射程/連射はrollから基準比を算出。装填は速度（基準秒数/実秒数）で統一しquick特殊効果を除外。
- 負:▼、0:無印、0超〜10:▲、10超で20以外:二段▲、20ちょうど:★。色も同じ分類。浮動小数点誤差1e-9未満のみ整数へ補正し、表示の丸めで★にしない。
- 一覧/固定装備行/武器庫/戦果の共通行、詳細、共有画像へ同じ計算を適用。詳細に同レア基準差と換算説明。共有画像は旧形式にも印を付け、装弾も対象。
- 戦闘式・保存形式・所持武器性能・乱数生成・通信は変更しない。旧武器の多くが▼になるのは現在の同レア標準より低いためで、弱体化やデータ移行ではない。
