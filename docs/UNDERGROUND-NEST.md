# 晶脈の地底巣（2026-09-09）

ST10・16の洞窟を、横向きのアリの巣を意識した地底トンネルへ刷新。旧MAPS-6.mdの岩棚と横穴の洞窟仕様は本書で置き換える。

- 筒状に丸く閉じた岩壁と天井。茶色の岩と床、手元周辺の照明、奥の暗がり、分岐の鉱石。
- 中央の横道を共有する2つの環状ルート。14地点・15接続、入口、分岐・合流、2本の袋小路。通路半径6.8m、主要広間の半径9m。戦場の床は水平で、上下階はない。
- 4人は南側入口から開始し、左右へ分かれて回り込める。ミニマップの味方位置は維持し、背景を実際の巣穴へ変更。
- プレイヤー・敵・射線・カメラが同一の通路と丸い天井の計算を参照。天井越しの射撃や、蜂が岩壁の上へ飛び越える動きを防ぐ。
- 地底用の経路探索で敵と巨大ミミズの胴体が環状ルートを回り込む。岩で見えない相手を近距離と判断して停止し続けない。出現位置は巣穴内の安全な地点から選ぶ。
