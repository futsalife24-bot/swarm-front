## 変更

- `front-combat.ts`: 経験値の高さを地面へ合わせ、撃破地点が建物・壁の上なら最寄りの歩ける候補へ配置する。通行不可・場外を既存衝突判定で除外。候補がなければ経験値へ直接加算し、消失を防ぐ。回収半径と部隊共有は維持。
- `front-run.ts` / `game.ts`: 改装版の出現間隔を1/4、通常敵HPを半分、同時通常敵上限24→96。大型ボスのHP7200・専用枠1体・1.5秒予兆・安全距離は維持。旧版の敵数・HPは変更しない。更新前から保存されている協力作戦は旧描画上限24+ボス1体を維持する。
- `front-app.ts` / `front-settings.ts` / `front.css`: 一時停止から設定・配置へ。視点/射撃/ジャイロ感度、ジャイロ、全体/BGM/SE音量、描画品質と30/60fps。改装版の設定は独立キーに自動保存。配置は既存共通キー。ソロは戦闘を停止し、協力は戦闘継続のままフォームを維持する。
- `playtest-app.ts`: 通常旧ソロのポーズから既存環境設定を開く。旧版専用の設定キーを使用。配置からの復帰は戦闘/回収それぞれを維持し、報酬や武器を変更しない。`main.ts`の旧協力設定には描画上限を追加し、配置編集時はポーズ画面を隠す。戦況受信による再読み込みで配置画面が消える既存不具合も、戦闘中の配置編集に限って防ぐ。
- `state-wire.ts`: 改装版の印は受信者自身の分だけ送信し、他の隊員の印判定はサーバーに保持する。密集時に64KiBを越える場合、送信する古い演出イベントだけを間引く。敵・弾・経験値・当たり判定・保存状態と通信上限は変更しない。旧版の送信内容は維持する。
