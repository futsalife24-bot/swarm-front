## 共通の監査基準

1. 横画面への収まり：844×390と640×360、画像に近い1220×413、画面切替後にも主要操作が切れない。安全領域・ブラウザの高さ減少も確認する。
2. 視認性・入力：文字と背景の判別、画像と名前の対応、押せる領域、キーボードフォーカス、タッチ相当操作。
3. 意味と結果：何を選ぶか、何が保存されるか、何が未保存か、効果・融合条件・未解放の理由が分かる。成功前に成功演出を出さない。
4. ゲームらしい見せ方：既存テーマ・タイトル・武器1行を継承し、画像・色・選択状態・意味のある短い演出で行動を伝える。余白や操作だけの段を不要に増やさない。
5. 動き・後始末：通常と動きを減らす設定、連続操作・閉じる・非表示で残留しない。入力と通信を待たせない。
6. 実通信・実保存：協力は実ローカルWorkerで作成→一覧→参加→準備→出撃を確認。保存は再読込、失敗、保護を確認。fixtureによる短縮と通常操作を区別する。
