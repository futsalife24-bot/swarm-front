## 保存仕様

- ソロ・協力の武器、装備、ロック、武装片、受領記録は共通。旧武器の性能を保持し、新旧形式の武器を双方で使用する。
- すでにd947で統合した旧v2保存がある場合は、その最新の報酬を含む内容を新正本へ引き継ぐ。v1を二重取込しない。まだ統合していなければ旧v1・v2の武器を既存ルールで統合する。
- 移行元と控えを保持する。容量不足などで移行が完了せず、その間に旧タブが更新しても、以前の控えを残し別番号の控えへ保存して再試行できる。
- 更新後は旧版タブを閉じる。**移行が完了した後、古いままのタブで新たに得た報酬は新版へ自動同期しない。** 旧保存自体は残る。
- 同一オリジン・同一ブラウザ保存領域ではゲーム画面1つだけが保存する。別ブラウザ・別プロファイル・別端末間の同期を追加する仕様ではない。
- Web Locksが利用できない環境は保存を始めず案内を表示する。BFCacheで古い画面が復元された場合は再読込して権限を取り直す。
- 管理者の進行・装備は一時状態で共通武器庫へ保存しない。通常保存を書かない管理者・訓練iframeは通常writerを取得しない。名前・操作配置は従来どおり共通。
- ソロ進行・育成・アクセサリを協力戦闘へ適用する変更は含めない。
