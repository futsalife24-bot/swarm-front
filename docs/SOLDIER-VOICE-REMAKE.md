# 兵士音声の再制作（2026-10-06）

利用者から「イントネーションが気持ち悪い、感情や迫力が伝わらない」と指摘され、現在の全11台詞を再制作する依頼。台詞と発声条件を保ち、自然な日本語と場面に合った演技を優先する。現行音声を聴き直した評価は未実施であり、以下は利用者の指摘と既存生成条件から作った新しい演技方針。

## 共通の声と録音指示

架空の成人男性兵士。同じ人物の中低域の地声を全台詞で保つ。自然な標準日本語。喉を潰して低くするのではなく、腹から支えた胸声。戦闘中、数メートル先の仲間へ届く短い発声。単語を一音ずつ強調せず、一つの意味のまとまりとして発音する。語尾の不自然な上昇、歌うような抑揚、母音の過剰な引き伸ばしを避ける。感情は語頭の勢い、呼吸、短い間、言い切りで表す。台詞だけを発声し、演技指示は読まない。音楽、効果音、無線加工、残響なし。

既存Fenrirを最初の比較候補とする。声を変えることで品質が改善するかは試聴後に判断する。現時点では新しい生成物も声の採用結果もない。

## 差し替えと検証の準備

- 元音声は保持。生成原本と台詞・声・モデル・演技指示・生成日時を `assets-src/voice-soldier-v2/` に記録する。費用上限を承認しても、支払い契約や認証設定の変更は別扱い。
- 採用音声は `public/assets/audio/voice-soldier-v2/` に置き、`src/client/soldier-voice.ts` の `SOLDIER_PATH` を変更する。全11IDを維持し、新URLで旧キャッシュの再利用を避ける。
- `src/client/media-menu.ts` の既存試聴導線を使う。HUD・発声頻度・抽選・保存・通信仕様は変更しない。
- 各WAVのデコード、無音の前後、切れた語尾、クリッピング、音量差を確認する。単純な音量増幅だけを迫力の改善と扱わない。
- 型、`tests/soldier-voice.test.ts` と `tests/soldier-playback.test.ts`、実ブラウザの全11台詞の試聴と戦闘中再生、ビルドを検証する。技術的再生成功と日本語・演技の聴感評価を区別する。
- 必要素材と比較証拠を通常Chatの独立監査へ送り、合格後に通常PR統合・既存Worker公開・配信照合を行う。
