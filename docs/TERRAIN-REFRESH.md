# 全6マップの高低差刷新（2026-09-12）

既存のマップ寸法、建物・岩壁・洞窟の接続、素材と遠景を維持し、登れる地面の起伏と小物を追加した。地形正本は `src/shared/terrain.ts`。Blender/GLBの原本は保持し、読込み時に同じ高度場へ床・道路・装飾を合わせる。洞窟の天井は元の高さを維持する。

街区・倉庫・工業区は道路にふさわしい緩い高低差、草原・雪峡は明瞭な稜線、洞窟は低い起伏と壁沿いの棚。新しい足場は0.3mずつの4段、最上段1.2m。小物は0.65/1.05/1.45mの高さで、街では荷箱とコンクリート台、自然マップでは元の岩・雪素材を使用。寸法はワールドメートル。地形の最大高度と個数は `dist-validation/terrain-refresh/layout.json`。

## 移動と次のジャンプ実装

- Player.yは足元の絶対高度。既存スナップショットでは省略可能で、通常移動から地形に追従する。
- moveは0.2m以下の小刻みな移動で狭い障害物のすり抜けを防ぐ。通常歩行の段差上限は0.36m。低い側から4段を登れ、高い側面には止まる。
- 次のジャンプ実装は `move(p,dx,dz,r,blocks,true)` で空中の高さを保持し、下降前後の足元高度を `landingHeight(x,z,fromY,toY,blocks,r)` に渡す。最も高い交差面へ着地できる。上昇では着地しない。上面を越えた足元高度では小物を飛び越えられる。
- ジャンプ入力、上昇速度、重力、落下アニメーション・落下ダメージは未実装。今回は地形と接触判定の準備まで。

銃口、照準補助、カメラ、敵弾・レーザー、近接距離、爆風、ダウン/蘇生表示、戦利品表示も高度へ追従。FOUNDRY ZEROの各節は地形に接地し、支持足は実際の足先位置の床を参照。屋外経路探索は新しい小物も避ける。既存の独立歩行周期は維持。

## マーカー

敵の足元高度がプレイヤーより0.05mを超えて高ければ中抜き。同じ高さ・低い位置は塗りつぶし。5cmは丸め誤差の許容。飛行中でもプレイヤーが高所から見下ろす相手は塗りつぶし。連結炉の各節も同じ判定。ミニマップに高度の濃淡と小物を追加。
