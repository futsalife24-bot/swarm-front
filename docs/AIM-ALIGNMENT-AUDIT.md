# 視点・射撃方向のズレ調査（2026-09-12）

状態: 原因調査完了。ゲーム本体・本番の変更なし。修正は未実施。

## 確認できた問題

1. **画面中央と弾道が30m先でしか一致しない。**
   src/client/render.ts のカメラはプレイヤーからyaw/pitch方向へ30m離れた点を見る。カメラ自体は右約0.8m、後方約5.2m、高さ約2.9mにある（壁寄せによって変化）。src/shared/game.ts の fire はプレイヤーのx/z・高さ1.5mからyaw/pitch方向へ撃つ。画面中央のカメラ光線と発射光線が異なり、近距離で視差が出る。敵の当たり判定の大きさや照準補助がズレを部分的に隠す場合がある。
2. **上半身の見た目の角度だけ旧制限のまま。**
   src/shared/aim.ts は上方向80度まで許可するが、src/client/standard-trooper.ts のSpineへの加算は±0.8rad（約45.84度）で止まる。実モデルのSpineのworld quaternionがpitch=0.8と80度で完全一致した。

## 実測

実Rendererと権威射撃関数fireを同じ隔離ブラウザで実行。ブラウザはChromeタッチエミュレーション、CSS viewport=915×412。プレイヤーはx=z=0で静止。敵なし・散布なしのロケット初速方向から弾道上の点を投影し、通常の武器散布/補助を除外した。値は画面中央からのCSS px差で、マイナスX=左、プラスY=下。

| 入力pitch | 弾道上の距離 | 横ズレ | 縦ズレ |
| --- | --- | --- | --- |
| 0度 | 5m | -17.60 | +31.21 |
| 0度 | 10m | -9.40 | +16.66 |
| 0度 | 30m | 0 | 0 |
| 0度 | 65m | +3.53 | -6.26 |
| 80度 | 5m | -13.91 | +157.31 |
| 80度 | 10m | -6.73 | +76.05 |
| 80度 | 30m | 0 | 0 |

ここで距離はプレイヤー発射点から弾道上への距離。実際の敵への命中可否や壁のある配置での数値ではない。80度は入力と弾道の角度であり、カメラの光軸は同じ80度ではない。両者の角度差は水平入力時約2.54度、80度入力時約8.48度だった。

照準補助も別途確認。正面入力に対してyaw=0.05radの位置にcrawlerを置くと、射撃yawが0.05radへ補正された（全体角度差約2.92度）。これは既存の意図した補助仕様であり、今回初めて発生したバグと断定しない。

## 修正方針

画面中央の光線が指す最初の敵/壁の位置を狙い点とし、発射位置からその点へ弾を飛ばす方式が候補。敵/壁/地面、近接遮蔽、散布、既存の照準補助、三人称カメラの壁寄せ、協力の権威計算と同じ基準にする必要がある。中央から見えても発射点の直前に壁があれば、その壁で止める。

上半身も新しい上下角の範囲へ合わせ、銃と両手の見た目を確認する。単に30mの定数を別距離へ変えても、ズレが小さくなる距離が移るだけ。

動かしながら撃つ場合、カメラは最新のcontrolsのyaw/pitch、上半身pitchはシミュレーションのp.pitchを参照する差もコード上にある。協力通信遅延や位置補間が動作中の見え方へ及ぼす量は今回未計測。
