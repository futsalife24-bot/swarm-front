## ④ 基地デザイン改善：既存4カードを磨く一案

横画面で「今どこを押すべきか」を読み取りやすくする。現行の2×2配置・名称・遷移・工房無効を残し、カード内を「名称／できること／現在の状態」の三段に統一する。武器には所持丁数と整理待ち件数、アクセサリには所持個数、育成には使用可能ポイント、工房には工事中を表示する。数値は既存保存から得られるものだけに限定し、未解放・計算できない値を仮表示しない。育成の状態は現在のポイント定義を確認したうえで表示する。

ヘッダーの「基地」の横に短い説明を一つだけ置く。資源表示は既存位置を維持し、重複する残高や追加の操作段を作らない。カードの余白・文字サイズ・境界線・選択時の反応を既存テーマで調整し、四枚が844×390で完全表示されることを優先。狭い横画面ではカード内の補足を短縮し、操作名と状態を残す。縦方向の余分なスクロールを増やさない。工房の無効状態は見た目だけにせず `disabled` と説明を維持する。

各項目の中身も同じ「情報の整理」を適用する。画面の基本構造・操作・保存は維持する。

| 項目 | 現行構造 | 改善する一点 |
| --- | --- | --- |
| 武器 | 武器系統選択→1行性能の一覧、上部にソート・絞り込み／整理 | 系統カードの名称・所持数・入口を同じ位置に揃え、一覧へ入る前の選びやすさを改善する。一覧の性能列、共通見出し、右端ロック、整理中だけのチェックボックスは維持する |
| アクセサリ | 上部に通常／指定作成・一括合成・装備解除、その下にレア度・効果・装備・ロック・解体の行 | 作成操作と所持品行の境界を既存配色で明確にし、各行の効果・装備状態が操作ボタンに埋もれないよう文字の優先度を整える。保護条件と確認操作は維持する |
| 育成 | 兵士選択、レーダー、能力詳細、確定／キャンセルの下部操作 | レーダーから選ぶ4能力とポイント残量の視線を揃え、未解放・編集中・確定済みを既存の表示で区別しやすくする。確定とキャンセルは常に見える位置を維持する |
| 工房 | 無効・工事中 | 新機能を見せず、4枚目として無効表示と説明だけを保つ |

実装時の合格条件：844×390以上で4カードと共通ヘッダーが重ならず全表示、667×375で安全領域とスクロールを確認、資源・長い件数・空データでも欠けない。武器へ入った後は既存の1行性能と整理モードを `scripts/check-gear-ui-baseline.mjs` で照合。実ブラウザで基地→武器系統／一覧・アクセサリ・育成へ移動→戻る、工房無効、各項目の横画面高さと操作を確認する。

保存案：既存 `tutorials` に導入の段階IDを追加し、通常保存内の案内進捗を管理する。説明表示・操作達成・スキップのどこで既読にするかは実装時に明確化する。再読み込みや中断から復帰しても未完了の案内から再開し、報酬・ミッション・勝敗・セーブ受領票には触れない。協力戦闘では強制停止の段階を表示せず、タイトルの読み物ガイドを利用する。実装前に中断復帰とロード失敗の遷移を確認する。

実装時の合格条件：新規通常保存でST1の全案内とスキップ／再起動／中断復帰、既存保存で押し付け再表示がないこと、通常／テスト保存の分離、説明中のソロ敵・弾・増援・回復・時計停止、説明の有無で報酬・追加目標が同一であることを確認。タッチ横画面とPCの操作表示を実ブラウザで照合し、タイトル・基地・報酬の既存操作が塞がれないことを確認する。
