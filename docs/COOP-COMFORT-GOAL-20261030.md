1. 現行版で各症状の再現条件と、描画・通信・サーバーのどこに遅れがあるかを記録する。実機情報が不足しても隔離環境で計測を進める。
2. 同じ人数・敵構成・射撃量・画面条件で、修正前後のフレーム時間、長停止、受信間隔、入力の滞留、実時間とゲーム時刻、描画個体と権威個体の対応、射撃受理と実弾生成を比較する。
3. 生存・進撃、少人数・4人、敵密集、連射、遅延、切断・再接続、低FPSで確認する。実ローカルWorker/WebSocketと実ブラウザを用い、モックだけで合格にしない。
4. ゲームルール・報酬・セーブの回帰を防ぎ、既存テストと必要な追加回帰を確認する。独立レビューの要否は本人に確認中。無返答を監査実施・不要の決定にしない。
5. PCやエミュレーションの数値をスマホ実機の証明にしない。実機で残る不具合・未確認事項は明記する。軽量化の都合で敵の判定や重要な予告を黙って消さない。
6. 本番反映・外部操作は既存の明示承認と今回の境界を照合して扱い、未実施の段階を完了にしない。新規課金・契約・権限変更は行わない。
