# 融合の発見表示と回避モーション（2026-10-10）

## 依頼と仕様

一時停止の融合条件は共通説明「融合元の能力をレベルMAXで融合可能。1枠空く」にまとめ、素材ごとの現在値/最大値と各行の枠説明を撤廃。取得済み強化の段階数は維持。融合一覧は2列に整理。

未発見は完成形の名前と「？？ × ？？」だけ表示。基地でも素材・効果・素材選択数・素材追加ボタンを出さず、逆引きからの漏えいも防ぐ。自分が実際に融合した確定状態（ソロのrun view／協力の自分用front view）だけ発見として保存。抽選候補や他人の所持は対象外。発見後は次の出撃・再読み込みでもレシピを表示する。

発見記録は専用localStorageキー `swarm-front-fusion-discovery-v1`。従来の進行・デッキ・戦闘保存を変更しない。過去の融合履歴は保存されていなかったため推測で全解放せず、更新後に確認できた融合から記録。保存破損を上書きせず、保存失敗を成功扱いしない。保存失敗時の当該作戦で所持中の融合は表示できるが永続記録には含めない。

融合元の表示名だけ変更：boost-coil＝回避促進、recovery-pack＝回収治癒、burst-cell＝爆圧増幅。内部ID・効果・素材対応・解放条件は維持。融合先9種はカタカナ名を維持。
