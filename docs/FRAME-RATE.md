# 描画上限30/60fps（2026-09-17）

画像の最優先候補のクラウド引き継ぎ・ソロ中断再開と、高優先の週間ミッションは既存実装済み。未実施の高優先候補「省電力設定・30/60fps切替」を選択した。既存の軽量描画は維持し、設定に「描画上限: 60fps（なめらか）/30fps（省電力）」を追加。初期値60、旧保存の未指定も60として扱う。

ソロ・協力・訓練の共通Rendererで描画と描画用更新を間引く。入力・固定刻みの戦闘・通信は既存ループのまま。フレームを飛ばした時間は次回のアニメーションへ合算し、長い停止は0.1秒に制限。非表示時は描画を停止。初遭遇演出の直接描画にも同じ上限を適用し、通常描画が完了した時だけ遭遇を開始する。自動画質調整の判定は選択したfps基準とし、正常な30fpsを過負荷と誤認しない。

ソロ設定は既存端末環境設定、協力設定は既存coopPreferencesに保存し、従来どおり別管理。訓練は起動元の設定を継承。未指定保存の互換性を維持し、30/60以外の保存値は拒否する。設定保存失敗時は従来値と表示を維持。武器/報酬/戦闘ルール、サーバー/API、公開設定の変更なし。
