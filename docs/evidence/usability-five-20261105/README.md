## 原因と変更

1. 武器一覧: `gear-weapon-list.ts` が装備比較行を先頭へ追加し、通常一覧にも同じ武器を残していた。所持1丁を1行だけ表示し、選択枠の装備はその行の金色の枠とE1/E2で示す。装備・詳細・ロック・整理・絞り込みを維持。現在の生存は専用ライフル1種類のため一覧を増やさず、防衛と進撃の共通一覧を修正。
2. 協力参加: 現行版でも `testtest` は入力エラーになったが、通常案内と似た小さな文言だった。パスワードは16進8文字。入力エラー／存在しない部屋／通信失敗を明示し、失敗欄に背景と左線、確認中は「確認中…」と無効化を付けた。公開一覧の通常表示へ戻る際はエラー装飾を解除する。
3. 戦場読込: 94%付近はシェーダー・プログラム初期化・GPU予熱。工程名、件数、経過秒、初回に数十秒かかる場合がある旨を表示する。実処理に合わせて更新し、完了時だけ100%。再試行は既にエラー時だけだったので条件を維持。60秒の準備期限・GPU待ち・戦闘開始条件は変更しない。キャンセル済み処理は旧画面へ通知しない。
4. 設定共有: Frontと基地が別キーを使用していた。`environment-preferences.ts` へ共通保存先をまとめ、進撃協力も読み書きする。感度・ジャイロ・音量・品質・fps・基地固有の2項目を保持。共通キーが無い初回だけ、旧Front→旧基地→旧Saveの順に復元。共有項目の衝突はFrontを優先し、ミニマップ/ダメージ表示は基地側を維持。旧キーは消さず、所持品・進行は移行しない。協力で設定変更しても武器保存を更新しない。
5. 白画面: moduleの読込前に背景と表示が無かった。両HTMLへ暗色の初期表示を置き、実UIの初回生成時に `boot-screen.ts` が取り除く。戦闘中にUIが空になっても再出現しない。既存の画面切替演出は維持。
