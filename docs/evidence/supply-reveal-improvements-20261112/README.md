# 補給演出・結果画面の検証

- 金射出の文字と地割れの背面表示を[比較画像](contact.png)で目視。上段は金射出・地割れ・2回タップ後の画面割れ、下段は本体の10連結果・単発選択画面・単発結果。
- 昇格時の「SR+」・下限反応の文字を表示しない。通常の確定結果名は表示する。
- 実ローカルWorkerと本体UIの844×390・640×360で、試しガチャの武器・未所持バディの詳細を開閉して10件の結果へ復帰し、ローカル保存が不変。通常10連は武器詳細を3回開閉後「次へ」で受領確認まで成功。ページ例外なし。[実画面結果](game-report.json)
- X共有はテスト内で投稿画面のURLを捕捉し、3件以内の要約と試しガチャの「取得なし」表示を検査した。外部への投稿・実X画面の接続は行っていない。
- 初期箱色が素材/Nは既定、Rは既定/青、SRは既定/青/紫、SSRは既定/青/紫/金の範囲で、1連・動き減切替にも維持されることを検査。バディの上限は既存バディ色。
- 飛び級・時間停止・通信ジャックは対象箱の最初の操作に続く演出であることを、1連と10連の再生時間軸で検査。
- 画面割れは実入力の3座標を蓄積、長押しは1回、獲得確認後に残りの箱へ戻ることを確認。1連の動き減切替とスキップも確認。音は0.16秒の有限で非無音の合成波形であることを確認し、聴感は未確認。[隔離検査結果](isolated-report.json)
- 既存SWに旧無印CSSを残し、新しいクエリ付きURLから変更後CSSとフォント参照が取得されることを844画面で確認。検査は隔離保存・ポートのローカルWorkerを使用した。[再現](../../../scripts/check-supply-reveal-game-ui.mjs)、[演出再現](../../../scripts/check-supply-reveal-improvements.mjs)。
- 開発者向け1連は選択された10種類すべての時間軸生成、単発に対応させた流星・地割れ・先読みの通し再生、ランダム、結果詳細・共有・戻りと保存不変を確認。獲得確認中のカード位置タップ・Enterも演出を進めた。通常単発の演出候補と確率は維持。[単発検査結果](single-report.json)、[再現](../../../scripts/check-supply-preview-single.mjs)。

実スマホ、実際の聴感、公開環境の認証済み抽選・Xへの接続は未確認。
