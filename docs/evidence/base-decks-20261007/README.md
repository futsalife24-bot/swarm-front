# Windows UI/UX自己検証の証拠

本体仕様・条件・限界は `../../BASE-DECKS-UIUX.md`。画像・動画は今回の実ローカル画面で取得。秘密情報・保存実体・認証ファイルを含めない。

- `before-*` / `before.json`: main基点の協力幅崩れと旧基地。
- `base-*`, `fusion-*`, `coop-*`, `base-checks.json`: 844×390・640×360・1220×413 × 通常/reduced。
- `motion-*.mp4` / 同`.json`: 実時間のCDPフレームと時刻、20fps動画。アニメーションの時間をseekした比較ではない。
- `surfaces/`: 共通メニュー27画面×4条件。画面寸法・主要操作のヒット判定もJSONに保存。
- `rooms/`: 実Workerへの作成UI→公開一覧→別ブラウザ参加→準備→退出、2サイズ。
- `front/`: 装備・初期候補・戦闘・現在強化・停止・設定・結果。旧方式継続作戦の表示fixtureも含むので「進化」の画像は現行融合画面と区別する。
- `battle/`: 両モードのタッチ相当HUDと設定・配置・再開。実機タッチの証明ではない。
- `results/`: 従来版の回収/報酬/勝利/ダウン/敗北5画面×4条件。ローカル表示fixtureであり、通し攻略の証明ではない。
- `safe-area/`: 左44px・右20pxのCSS安全領域を両版8画面で確認。
- `weekly.png`, `squad.png`, `logs/menu-network-fresh.txt`: 実ローカルWorkerの週間受取と協力準備。認証・クラウド処理を架空レスポンスに置き換えていない。
- `logs/`: 失敗を含む初回ログと対象修正後の再実行ログ。旧UI名/DOMを参照するE2Eと、初遭遇演出の期待条件を修正。初回の失敗だけを成功扱いしていない。

実非表示時のcleanup・実機タッチ・GPU長時間・全敵モデルは未実測。実行モデルID/推論設定は未確認。これは独立Chat監査合格の記録ではない。
