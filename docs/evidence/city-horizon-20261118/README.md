# 灰明の街区と大型ANOMALYの歩行

2026-11-18。進撃・生存の「灰明の街区」と、HARROW・FOUNDRY ZERO通常形態の表示を改修。ゲームの移動速度、攻撃判定、同期データは従来通り。

## 灰明の街区

112棟の外装に階ごとの反射、控えめな窓灯、地面に近づくほど暗くなる陰影を焼き込んだ。三方の通信塔と山の明度差で方角・距離を読み取りやすくした。標準画質のソロでは雲の帯が見える。協力・軽量設定では同じ素材の遠山までを描画する。描画範囲は部屋・設定の切り替えにも追従する。[同地点の改修前後](city-comparison.jpg)・[協力表示の街区](coop-street.jpg)

## 事前保存

実画面で、既存の生存カード画像10点（WebP）が端末側の素材一覧検査で拒否され、メニュー全体が利用できないことを再現した。カード画像の専用ディレクトリを検査対象に加え、配布表の全URLを端末の規則で照合する回帰テストを追加した。

## 協力プレイの計測

ローカルWorkerに2人で接続し、片道143ミリ秒の遅延を加えた。Windows版Chrome・D3D11、844×390。ホストは通信のみ、ゲストが描画。同一フレームのカメラ・敵・兵士を固定し、旧遠景と新遠景を交互の順番で描いた。最初の16組を除き80組を集計。時間は描画開始から画素の読み戻しまで。これは実スマートフォンや公衆回線の測定値ではない。[計測結果](multiplayer-render.json)

| 1フレームの描画 | 改修前 | 改修後 |
| --- | ---: | ---: |
| 中央値 | 10.4 ms | 10.5 ms |
| 95パーセンタイル | 14.5 ms | 13.3 ms |
| 同一時点の描画呼び出し | 56 | 56 |
| 同一時点の三角形 | 572,518 | 544,536 |

雲を協力でも描く版は、2回の比較で中央値が各0.2 ms、95パーセンタイルが0.3～0.4 ms増えた。照明を焼き込んだ試作の1回は並行負荷のなかで状態受信数の基準にも届かなかった。最終版の2人接続・補間検証は合格し、ゲストは計測区間に111状態を受信、GLエラー0件。試作の計測を最終版の値に混ぜていない。

## 大型ANOMALY

- **HARROW**。0.64 m/秒で同じ2.88 mを歩かせ、0.5～5.0秒を確認。従来の歩行は30fpsで136/136コマ、60fpsで0/271、120fpsで0/541。修正後はそれぞれ136/136、271/271、541/541。全サンプルで表示座標は一致した。既存の図鑑の「移動を見る」でも脚の動作を確認。[歩行の比較動画](harrow-walk-comparison.mp4)・[図鑑の移動表示](report-harrow.png)
- **FOUNDRY ZERO**。六脚の歩幅を描画倍率に合わせ、通常出現時の1周期を1.44 mに補正。60fpsで接地中の足裏の平均水平速度は、直進2.800→0.0000075 m/秒、緩い旋回3.494→1.151 m/秒。停止時は前後ともほぼ0。120fpsで歩行409/409コマ、停止169/169コマ。図鑑本文と再生の歩調を更新し実画面で照合した。旋回時の横滑りが一部残る。[比較画像](foundry-walk-comparison.png)・[足裏の計測](foundry-metrics.json)・[図鑑の実画面](report-boss-walk-after.png)
- **次の候補**。CATENAは実戦のレーザー予兆が頭と偶数節に出るが、図鑑の攻撃展示では頭と前半7節に出る。CALYXの叩きつけ1.0秒・花粉射撃1.6秒は実戦と展示で一致した。
