## 実装の境界

- `shared/buddy-combat.ts`、`game.ts`：権威側の攻撃/回復/支援、共有追従位置。`main.ts` の協力移動予測も同じ係数。
- `shared/buddy-progression.ts`：取得/抽選/育成/突破/報酬。`buddy-controller.ts` は保存成功前に結果を返さず、同じ要求IDで再試行。`buddy-presentation.ts` は表示用の純粋変換。
- `progression-save.ts`、`shared-armory.ts`：既存ソロ/協力の戦果IDを用いて二重報酬を防止。追加フィールドは任意、旧保存を維持。`growth-save-guard.ts`/`player-vault.ts`は旧クライアントによるバディ情報消失を拒否する。
- `worker.ts`/`network.ts`：装備・生成・同期・同一所有者の再接続。戦闘中の変更拒否、旧装備パケットの未指定は維持、nullは明示解除。所持証明は既存ローカル武器と同じ信頼境界で、暗号的な所持検証や課金ガチャではない。
- `buddy-visuals.ts`/`render.ts`：戦闘状態から表示と動作を接続、終了時にmixer/GLB資源を解放。DEV確認UIと製品表示は分離。

生存の中立ライフル・属性カード・抽選・基地カードUI、防衛、旧設定、公開済み使い勝手修正を戻していない。
