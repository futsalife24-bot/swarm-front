# 生存戦のランダム出現・大量出現

- 生存戦（成長規則3）の通常敵とBASTIONは、生存中・接続中の隊員の周囲から位置を抽選。壁の内側で全員から16m以上離れた通行可能な位置のみを採用。乱数は戦闘・報酬とは別に保持し、保存復帰で継続する。進撃・防衛・デイリーの出現規則は変更しない。
- 戦闘時間2分ごとに最大24体を予告し、包囲リングと一方向の集中を交互に実行。2分・6分・10分…がリング、4分・8分・12分…が集中。既存の1.5秒予告と最大96体を維持。実施12秒前から通常出現の空き枠を確保し、8枠以上と安全な位置がない場合は最大15秒再試行して見送る。既存の敵は消さない。
- 新規 `tests/front-survival-spawns.test.ts` は30種のseed・2種類の隊列・実出現・上限・空き待ち・四隅/2人の安全距離・保存復帰・旧状態互換を確認。関連6ファイル70テスト、client/Worker型、production build・Worker dry-runが成功。隔離Workerの実WebSocketで2人への予告・出現・64KiB上限を確認。
- 隔離Worker・Chrome 844×390の生存協力画面で、テスト用fixtureにより戦闘時間を2分/4分へ進め、各24体と画面例外0を確認。[包囲予告](ring-warning.png)、[包囲](ring.png)、[集中](cluster.png)、[結果](browser-result.json)。集中の出現は視点左側で一部画角外。SwiftShaderのためFPSや実機快適性の証明ではない。fixtureの入口は `server/testing.ts` のみで本番Workerに含めない。
- 実スマホ・実回線の多人数・長時間連続プレイや出現タイミングの難易度調整は未確認。満員・安全地点不足では大量出現が減少または見送りになる。
