## 採用と本人の追加決定

Claude Codeの試作 `claude/survival-card-design-20261104` / `82611a0a8b91b0e3703c1b3975dc4c4e5119129c` のREADME・HANDOFF・描画・撮影画像を読み、共通のカード部品を4場面で使う方針を採用した。試作worktreeは編集せず、アカウント限定のclaude.aiページは未閲覧。原案の「基礎・デッキ・融合」という仮分類は、以下の本人決定へ置き換えた。

| 分類     | レア度・表現                                     | 現行カードへの割当                                            |
| -------- | ------------------------------------------------ | ------------------------------------------------------------- |
| 能力強化 | 通常。緑系の枠と文字ラベル                       | 装甲、経験値回収、回避後の地雷・防御、回避短縮、回復。7種     |
| 武器強化 | 同じ通常レア。青系、枠の形・厚みは能力強化と同じ | 射撃・爆発の威力/範囲、貫通、跳弾、迎撃、装填、弾倉など。15種 |
| 融合     | 上位レア。金の二重枠、四隅の金具、紋様、◆        | 既存の融合9種                                                 |

「射撃付与」は本人の指示で「武器強化」に変更。能力強化のIDは `armor`, `magnet`, `afterimage-mine`, `emergency-armor`, `boost-coil`, `recovery-pack`, `life-drain`。他の通常カードは武器強化。分類は表示専用で、出現確率や既存効果を変更しない。

最後の本人指示「金枠はもっと燃えるようなきらめき」に従い、融合枠に金〜橙の光が巡る動きと緩やかな輝きの変化を追加。原案の「常時発光なし」はこの指示で更新された。通常カードには継続アニメを加えていない。OSとゲームの動きを減らす設定のどちらでも停止し、金枠・装飾は残す。

現行の爆発・貫通・迎撃・補強の系統表示を使用する。火炎/氷結/電撃/呪い/風の属性、分裂などの射撃方式は対応する戦闘効果の実装時に追加し、仮例を製品UIに混ぜない。獲得/未獲得はレア度から独立した状態表示。

## 組み込み

- `survival-card.ts/.css` を共通部品にし、3択L → HUD S/取得一覧row → 基地Mへ統合。カード名・数値・アイコンは既存の定義と計算を利用。新しい画像ファイル・依存パッケージは追加していない。
- 新生存の獲得済み全候補閲覧と、防衛の候補編集を保持。防衛の四角いチェックは見た目20px、操作域38px×カード全高。カード本文・境界外の操作では選択を変えない。
- HUDは24px、融合の◆と段階数字を残した。未発見融合の画像と素材名は伏せたまま。
- `front-fusion-glow` を削除し、新しい枠の光へ置き換えた。共有メニューのテーマを壊さず、カード内ボタンだけを調整。
- 出撃DEPLOYの重なりは同じ統合作業で修正。初回3択を確定し、カード決定の演出が終わってから表示する。追加選択・宝箱の表示中は中央の作戦演出を取り消す。

## レベルアップと宝箱

- 新生存（`survivalBuildVersion: 1`）の経験値による追加選択は、0.8秒のLEVEL UP文字カットインから3択へ遷移。初回のカード選択は対象外。再抽選で再生せず、連続する別の選択では毎回表示する。協力の選択時間15秒にカットイン分を加えた。
- ボス級 `bastion` / `boss` / `harrow` を倒すと、通常XPとは別に共有宝箱を1個落とす。現行の新生存で定期出現する対象はBASTION。屋上撃破でもXPと同じ探索で歩ける地面へ落とす。XPオーブが上限でも箱を作る。
- 2.5m以内で拾うと、生存中の各参加者が、その作戦で取得済みかつ未MAXのカードをランダムに1枚+1段階。所持済み融合も対象。未取得カード・新規融合・融合で消費済みの素材は対象外。切断中でも生存者の報酬を保持し、死亡者は対象外。
- 宝箱は約2.4秒の独立イベント。戦闘時間と戦闘処理を止め、抽選は権威側で確定。同時にXP条件を満たしても、宝箱→LEVEL UP→3択の順に進む。取得権を消費せず、XPの上限119も増やさない。
- 所持カードがすべてMAXなら、本人回答を受け回復/攻略コインをランダム化。仮値は最大HPの25%回復または10コイン、満タン時はコイン。コインは既存の作戦結果受取と同じ保存経路で一度だけ加算し、途中退出の戦果破棄を保持。コイン10・回復25%は調整可能な初期値で、バランス確定値ではない。
- 地上の箱は3つの単純なメッシュ、描画上限128。画像・常時パーティクルを使用しない。旧作戦・防衛・進撃には箱やカットイン規則を後付けしない。恒久セーブの移行は行わず、未保存の作戦結果には互換な任意の宝箱コイン項目を加えた。
