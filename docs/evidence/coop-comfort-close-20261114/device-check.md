# 本人用・5分の実機確認票

OPPO Find X8・ホーム画面から起動する版・普段の回線で確認する。11/13の実機報告は受領済み。今回は押しっぱなしの連射を時刻と対応させる確認票で、goalを閉じる判断は本人が行う。

| 時間 | 操作 | 控える内容 |
| --- | --- | --- |
| 0:00–0:45 | ホーム画面版のタイトル→ソロ→生存→出撃準備の「設定・操作」→下までスクロール。「通信の詳細診断」をオンにして版を控える。 | 版の先頭7桁、ホーム画面から起動したか、Wi-Fi/モバイル回線。タイトル共通設定・戦闘中の設定にはこの切替はない。 |
| 0:45–1:30 | 戻って生存ソロへ出撃し、歩行・停止・射撃・装填を数回行う。 | 指を離した後の移動、弾が出ないのに弾薬が減る症状。 |
| 1:30–4:30 | 自分の非公開協力部屋で出撃。可能なら手持ちPCや協力者も参加。使った武器を控え、射撃を10秒ほど押しっぱなしにしてから離す。弾切れ・装填中は別に控える。 | 実際の人数、武器名、ばらついたゲーム内時刻、歩行/連射の途切れ・着弾抜け・敵の不自然な消失。1人の協力モードを4台確認とはしない。 |
| 4:30–5:00 | 戦闘の一時停止画面から「通信診断を保存」。JSONと下の確認票を作業チャットへ渡す。 | 症状がなくても保存する。端末のダウンロード一覧も確認する。 |

確認票: `版: ____ / OPPO Find X8・ホーム画面版: はい・いいえ / 回線: ____ / 協力人数: ____ / 武器: ____ / 押しっぱなしの連射: 規則的・ばらつく / 弾切れ・装填と別の症状: はい・不明 / 症状のゲーム内時刻: ____ / 歩行の途切れ: ____ / 着弾抜け: ____ / 敵消失: ____ / 診断JSON: 保存済・未保存`

診断JSONだけでは物理タッチ・1発ごとの射出/表示は復元できないため、時刻・武器・人数も必要。新しい版が来ない場合は再読込みまでにとどめる。端末/ルーターの設定や保存データ、アプリ削除は行わない。スマホ4台・長時間発熱・Safari音量はこの5分に含まれず、未確認のまま維持する。
