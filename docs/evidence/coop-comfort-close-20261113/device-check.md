# 本人用・5分の実機確認

対象は OPPO Find X8・ホーム画面から起動する版・普段のWi-Fi。端末・ルーター設定や保存データは変更しない。PC計測の合格を、この確認の代わりにしない。

診断切替の入口は **ソロ → 生存 → 出撃準備の「設定・操作」→ 下までスクロール**。タイトル共通の「設定」（環境設定・保存書き出しが並ぶ画面）や、戦闘中の「設定・操作」にはこの切替はない。オンにした後は戻って出撃し、協力へ接続し直すと適用される。

| 時間 | 操作 | 記録すること |
| --- | --- | --- |
| 0:00–0:45 | ホーム画面版のタイトルから「ソロ」→「生存」へ進み、出撃準備の「設定・操作」を開く。下までスクロールして「通信の詳細診断：オフ」を押し「オン」にする。表示された版の先頭7桁を控える。 | 版、起動方法、Wi-Fiかモバイル回線か。新しい版が来ない場合は再読込みまでで止め、アプリ削除・データ削除はしない。 |
| 0:45–1:30 | 生存のソロを起動。歩行→停止→射撃→装填を各数回。 | 指を離しても歩き続けないか、弾が出ないのに弾薬だけ減らないか。 |
| 1:30–4:30 | 自分で作った非公開の協力部屋で出撃。参加可能な自分のPCや協力者がいれば参加し、実際の人数を控える。密集時に歩行・停止・連射を繰り返す。 | 入力の途切れ、瞬間停止、着弾抜け、敵の不自然な消失。症状の時刻、人数、FPSと通信表示を控える。1人の協力モード確認を4台確認とはしない。 |
| 4:30–5:00 | 戦闘の一時停止画面から「通信診断を保存」を押す。症状がなくても保存し、結果とJSONをこの作業チャットへ渡す。 | 「症状なし／あり」、症状の時刻、何人だったか。保存先は端末のダウンロード一覧も確認する。 |

確認票: `版: ____ / OPPO Find X8・ホーム画面版 / 回線: ____ / 協力人数: ____ / 途切れ: なし・あり / 着弾抜け: なし・あり / 消失: なし・あり / 診断JSON: 保存済・未保存 / 気付いた時刻: ____`

5分は本人の短い受入確認であり、スマホ4台・長時間の発熱・Safari音量の全条件を含まない。未確認の条件はそのまま残す。goalを閉じるかは、この実機結果と計測表を見て本人が決める。
