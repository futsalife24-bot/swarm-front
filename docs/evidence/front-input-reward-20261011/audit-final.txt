## 2. 修正内容の独立確認

`front-reward-status.ts` と `front-progress.ts` の実コードを照合しました。

| 確認事項               | 判定      |
| ------------------ | ------- |
| 未記録かつ履歴境界以前なら対象外表示 | 合格      |
| 正常な日替わり0功績は `+0`   | 合格      |
| 既存受領記録の金額を優先       | 合格      |
| 対象外の場合の再試行ボタン非表示   | 合格      |
| 再呼出しによる表示・功績の不変性   | 合格      |
| 保存形式・報酬計算への影響      | 変更なしを確認 |

特に、受領済み記録の検索が履歴境界の判定より優先されるため、過去に正しく受け取った功績が誤って対象外扱いされることを防いでいます。

また、対象外でも `status.error` が `false` となるため、再試行で解消できない結果にボタンを表示しない設計は妥当です。
