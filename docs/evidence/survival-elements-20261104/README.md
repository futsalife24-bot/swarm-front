## 仕様と判断

| 獲得条件 | カード | 1 / 2 / 3段階の効果 |
| --- | --- | --- |
| 進撃1突破 | 火炎弾 | 命中で3秒燃焼、0.5秒ごとに6 / 9 / 12ダメージ。再命中で期限を更新し、次の燃焼ダメージは延期しない |
| 進撃2突破 | 氷結弾 | 命中で通常敵を0.5 / 0.75 / 1秒停止。解除後2秒は再凍結不可。ボス級・分節敵は停止無効 |
| 進撃3突破 | 連鎖雷 | 異なる敵も含めて手動射撃が3回命中すると、最大2 / 3 / 4体へ各18 / 24 / 30ダメージ。隣の敵まで6m、壁越し不可 |

火炎は撃ち替え・貫通と組み合わせる継続ダメージ、氷結は間合いを作る足止め、電撃は群れを削る役割。数値は初版で、人間の熱中度や長時間の難度を実証したものではない。

最初は氷結も3命中で検討したが、初期の通常サイズ敵は専用ライフル24ダメージの2〜3発で倒れるため、停止が役立たない。初撃から凍結し、共有の再凍結耐性で永続停止を防ぐ方式へ変更した。火炎の再命中は同一プレイヤーの燃焼を重複加算しない。電撃は近い敵を優先し同距離はID順、同じ射撃での重複連鎖・二次ダメージからの再発動を防止する。

初期8種と既存報酬は維持。新規保存の獲得数は進撃0〜7で **8 / 11 / 14 / 17 / 19 / 21 / 23 / 25種**。突破済みなら遡って獲得する。従来の所持品も維持。新属性は除外・再抽選・作戦中の成長・宝箱によるランダム強化の既存経路へ参加する。今回の融合レシピは既存9種のまま。呪い・風・分身、属性融合、進撃専用バディは後続。

- 新しい専用武器の生存戦だけに属性を適用。防衛は既存22種、既存武器・旧デッキを維持する。
- 保存形式の版は増やさず、新属性の除外IDを既存の検証・保存経路へ追加。古い31種類の途中作戦は元の候補で続行でき、不正な欠損は引き続き拒否する。
- 協力のカード対応版を3へ更新。旧版2だけの部屋には旧22種の候補を送る。旧版と新版が混ざる開始、および版3作戦へ旧画面で復帰する場合は更新を案内し、未知のカードを旧画面へ渡さない。
- ダメージ・撃破・経験値は共通の権威側処理。氷結耐性は協力プレイヤー間で共有する。
- 電撃の演出イベントは射撃姿勢の対象にしない。既存の表示上限内で短い炎・氷の輪と結晶・紫の電撃を描く。モデルに埋もれた初版は高さと太さを調整。壁の遮蔽は維持する。
- 新カード画像は3枚とも小さいSVG。素材一覧生成器も更新し、一括保存に含める。追加の大きい画像・音声・3Dモデルはない。
