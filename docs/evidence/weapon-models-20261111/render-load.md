再現: `node scripts/weapon-render-load-probe.mjs`。製品 `Renderer` と標準兵士・武器・通常の建物を使用する隔離されたローカル画面。新規のUI設定・音量設定・モデル・製品コードは変更していない。

## 条件

Windows 10表記、Headless Chrome 157.0.8103.39、WebGL 2、GPU `ANGLE (Intel, Intel(R) Iris(R) Xe Graphics (0x000046A8) Direct3D11 vs_5_0 ps_5_0, D3D11)`。ビューポートと描画バッファは 844×390、デバイス倍率1。兵士１人、敵０、射撃エフェクトなし、立ち姿。各武器を手に持ち、背中は全条件で同じAR-9。各１秒の事前描画後、約５秒を１回ずつ測定した。マップ・兵士・背負い武器込みの全画面であり、武器単体の値ではない。

既存AR-9・SG-4・RL-2を比較基準とし、対応する構えごとに値を見る。既定の合否基準は設けず、測定条件下の比較として報告する。画面更新はブラウザーの requestAnimationFrame の回数、CPU時間は `Renderer.render` の実行時間。GPU処理の完了時間は測っていない。モデルの読み込みや事前描画時間は測定に含まない。

## 未確認
