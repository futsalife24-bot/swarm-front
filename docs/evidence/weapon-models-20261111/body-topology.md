# 兵士モデルの閉じた体積としての適性

2026-11-12。`public/assets/characters/swarm-soldier.glb` の体・頭の各メッシュを、GLBの位置・三角面・スキン情報から静止初期姿勢で調査。製品ファイルは変更しない。実行はworktreeのルートで `python -X utf8 scripts/weapon-body-topology-probe.py`、結果は `dist-validation/weapon-body-topology-probe/report.json`。保存した今回の結果は `body-topology-report.json`。PythonとNumPyが必要。

頂点の分割を考慮するため、生の頂点番号のほか、位置を1μm単位、重みを0.000001単位で丸め、ジョイント番号と重みが一致するものを解析上だけ統合した。位置のみの統合も参考値として記録。丸めは正確な距離閾値や、変形後に常に一致することを保証しない。閉じた四面体の境界辺0本、1面を除いた四面体の境界辺3本を既知の対照で確認。

スキン情報を考慮して統合しても、体は境界辺5,267本・3面以上が共有する辺352本、頭は境界辺4,840本・3面以上が共有する辺117本。体の広い胴体近傍の箱（|x|≤0.35m、y=0.8〜1.45m、|z|≤0.25m）だけでも境界辺2,131本。箱は背中・身体・衣装を意味的に分離していない。

この結果から、兵士全体を単一の穴のない体積として扱う単純な内外判定は適切でなく、判定を実施しても「めり込みなし」の証明にはしない。閉じた位相の個別成分は存在するが、各成分の自己交差、重なり、衣装・ベルト・体の意味分離や実際の変形後の形は未検証。背負い武器・兵士との接触、動作中、実ゲームと実機の結果ではない。別途、穴のある体表や装備に適切な局所形状を設計する必要がある。
