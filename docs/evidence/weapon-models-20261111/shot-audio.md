# 12武器の初回射撃音：ローカル信号検査

再現: `node scripts/weapon-shot-audio-probe.mjs`。12丁を一時セーブで個別に装備し、844×390 のデスクトップ Chrome で実際のローカル単独プレイへ入り、それぞれ初回の射撃を入力。音量の設定や製品ファイルは変更していない。射撃の前に製品側で `AudioContext` が running となり対象音声が復号されるのを待っている。

実射撃イベントと、該当プレイヤー・武器系統の `Sound.play` 要求を照合した。製品が作成した音源から個別効果音のゲインを通った後、音量マスター・ステレオ定位・圧縮器より前の信号を AnalyserNode に分岐して450ms測定。追加分岐はゲイン0であり、製品の元の接続を置き換えない。再生直前に同分岐が0であることを無音対照とした。音源の AudioBuffer が復号済みの正規射撃クリップそのものであることを照合し、フォールバックの短いクリックとは区別した。

## 結果

12丁すべてで初回射撃イベント・対応する再生要求・対象クリップの音源作成・非ゼロ信号を確認。各測定の開始前は0、画面例外は0。下記のピークは測定中に観測した絶対値であり、クリップ全体の厳密な最大値や聞こえる音量ではない。

## 未確認

観測点は個別効果音ゲインの後・マスターより前であるため、マスター以降の混合、圧縮、OS・スピーカーまでの出力、耳での聴感は確認していない。450msより後の波形、複数同時射撃、その他の効果音、モバイル実機・音量スイッチ・負荷も未確認。復号完了前の初回射撃は今回の対象外。リリース後の配信や実機で音が聞こえることの証明ではない。
