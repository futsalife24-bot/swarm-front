## 生成検査のコピー手順

ZIPの展開先で `public/assets/weapons/unique-v1/<kind>_<tier>.glb` を、対応する `design/weapon-models-20261111/out/<kind>/` にコピーする。

```powershell
$kinds = "smg","slug","heavy","sniper","laser","grenade","sticky","kick","medic"
foreach ($kind in $kinds) {
  Copy-Item "public/assets/weapons/unique-v1/${kind}_*.glb" "design/weapon-models-20261111/out/$kind/"
}
```

各フォルダの既存 `report.json` のSHA-256とコピー元を照合し、`PRODUCTION.md` に従って Blender 5.2.1 の `check_weapon.py` を実行する。作業ブランチの読み取り時点では９種×５等級すべてが公開用GLBと生成報告のSHAに一致し、９件とも40項目・失敗０・警告０。
