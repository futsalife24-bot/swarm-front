# 装填時の手骨ウェイト面と武器表面

## 条件

N等級12丁と製品の StandardTrooper を隔離ページで使い、各武器の装填25・50・75%を固定して各4回更新。兵士メッシュは手袋だけに分かれておらず制服と統合されている。手袋や指だけを厳密に特定できないため、各三角面の3頂点すべてについて Hand_L または Hand_R の骨ウェイトが0.5以上の面を、その側の「手骨ウェイト面」として抽出した。各時点で左347頂点・486面、右367頂点・508面。その他の手表面や境界部分を除外し得る。

変形済みの手骨ウェイト面と武器面の辺・面交差を測る。距離は抽出頂点から武器の三角面への最小距離であり、面全体の最小距離の上限。距離0や交差件数は接触の自然さ・深いめり込みの判定ではない。武器にはネオン描画を含めない。

## 対照と実行

合成三角形で交差・非交差、点から三角面まで50mmを検証。rifleの25%で、武器をワールド座標のX方向へ40mm移動した実物正例は21組、各軸へ10m離した負例は0組。画面例外・HTTP失敗は0件。兵士GLBと武器12 GLBのSHA-256は検査前後で一致し、測定時の値は report.json に記録した。

再現: `node scripts/check-reload-hand-skin.mjs`。通常サンドボックス内ではローカル配信の `bundle.js` が `net::ERR_NETWORK_ACCESS_DENIED` となり待機がタイムアウトした。正式な権限確認後、1武器・1時点で処理段階を確認してから全条件を実行した。結果は `reload-hand-skin-report.json`、比較画像は `reload-hand-skin.png`。

## 限界

独立した弾倉ノードは既存の12武器診断では見つかっておらず、今回の測定も武器全体を対象としている。弾倉への手の接触・交換動作・指先の位置は判定できない。手骨ウェイト面は手袋全体ではなく、骨の境界・隠れた面やウェイト0.5未満を除く。辺面交差は共平面・完全内包・交差深さを判定せず、頂点距離は正確な面同士の距離ではない。時点間の連続動作、実ゲーム入力、他のレア度、通信、スマホ実機は未確認。
