# ダウン時に武器を体側へ移す隔離試作（不採用）

既存SG-4・新SR-1の両背負い位置について、ダウン時に背負い武器を左右へ最大320mm移し、床を避けるため必要な高さを加える。復帰時は補正を戻す。製品には反映していない。平面上で実兵士を60fps固定入力で直接更新し、床高は各時点、兵士体表と武器の辺／面交差は各9時点で測定した。

4条件の武器最下点は床上1.6mm以上だったが、体表との交差はダウン中に最大4,319組、復帰後にも最大990組。元の位置から最大331.3mm移動し、補正の向きと大きさを含む1フレームの変化は復帰時に最大77.2mmだった。画像でも武器が体に入り、自然な動作とは言えないため不採用。ページ例外0。完全内包・共平面・ネオン・他スロットとの交差・時点間の体表交差・実ゲーム・地形・通信・実機は未確認。

過去に本人が許容したのは低い回避中の一瞬の武器の床めり込みであり、ダウン静止中のめり込みまで許容されたと判断していない（`docs/STATE.md` の2026-10-09の記録）。
