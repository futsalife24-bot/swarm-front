# SMG-3 装填中の左手IK隔離試作（不採用）

再現: `node scripts/reload-smg-ik-probe.mjs`。製品コード・モデル・アニメーション・既存３丁は変更しない。結果は `comparison.png` と `report.json`。対象は SMG-3 のN等級のみ。

## 条件

製品の `StandardTrooper` は３構えの装填クリップを使い、通常時の左手支持IKを装填中には適用しない。試作では兵士の更新後、既存の二関節IKと同じ幾何計算で左の上腕・前腕の回転を操作する。手首の向きと上腕・前腕の長さを保ち、武器や弾倉は移動しない。SMG-3 の生成元にある弾倉の位置をもとに、結合済み武器メッシュの座標範囲を弾倉候補とみなす。範囲に入る三角形には弾倉以外も含まれ得る。

装填20〜80%の間のみ滑らかに効き、手首を候補領域に向けて最大60mm誘導。元の手首と候補面の距離が60mm以下なら誘導しない。平面で製品モデルを直接60Hz更新し、91時点の距離と位置を計測。0・約25・50・75・99%の現行／試作を描画した。実ゲーム操作そのものではない。

## 正負対照

開始時の手首から到達可能な目標へ約18mm移す正例は、目標誤差0.001mm未満。遠方の到達不能目標では残差約8.18mであることを確認し、到達不能でも有限値になることを検査した。正例で二つの腕の長さは小数誤差内で一致。これらはIK計算の検査であり、指先接触の正例ではない。最初の試行は静止画像の抽出条件が２時点を重複採取し失敗したため、時点の抽出を修正して再実行した。画面例外・取得失敗0。

## 結果

最大手首補正60.0mm。左手首の1フレーム移動の最大は現行14.1mm、試作13.9mm。装填50%における手首中心と候補領域の距離は現行206.6mm、試作146.6mm。手袋の表面や指先の距離ではない。比較画像では中盤の手が候補領域に近づくものの、弾倉をつかんで操作する自然な動作には見えず、動く弾倉もないため、完成案として不採用とする。

## 限界

結合されたモデルからの位置推定は弾倉専用メッシュの特定ではなく、表面・指先・弾倉の接触や貫通は測っていない。手首の向きを維持するだけで握り形状は変化させておらず、他の８丁への適用可否も未検証。実ゲームでの入力、歩行・照準・持ち替えと重なる動作、ネットワーク、連続衝突、モバイル実機や負荷は未確認。距離・位置だけで自然さは保証できない。
