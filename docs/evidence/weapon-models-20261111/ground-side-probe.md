# 横向き胴のDown隔離試作（不採用）

製品コード・GLB・アニメーションを変更せず、`node scripts/ground-side-probe.mjs` で再現。既存Downを土台にSpineを骨盤から胸への軸で最大90度回し、腕・胴・手持ち・背負いを一緒に動かす。下半身は既存動作を使う。身体や武器の自動的な押し上げ・移動は行わない。復帰時は倒れた時の骨姿勢を0.5秒で製品姿勢へ補間。新たに制作した完成アニメーションではない。

平面でSG-4・短筒RL-9・SR-1の両背負い位置、計6条件。身体・手持ち・背負いの最低高と胸・各武器原点の1フレーム移動量は60Hz。身体と武器、武器同士の辺面交差は各9時点。既存交差関数は解析上の交差・非交差の正負対照を実行する。ポーズは手元のGLBを使用。`report.json`に全フレームの値、`timeline.png`に代表画像がある。

床の上下はy=0基準。身体の全期間の最深は床下227mm、1.9秒の静止時は182mm床下。背負い位置2の静止時は床下199〜248mm。手持ち武器の全期間の最低は床上249mm以上だが、これは自然な支持を意味しない。復帰0.5秒の1フレーム移動は胸で最大51mm、手持ち原点145mm、背負い原点68mm。画像でも復帰は不自然。静止時の辺面交差はSG-4背負い位置1で体と背負い1,336組、SR-1背負い位置1で979組・武器同士16組。体と手持ちは握りの接触を含み、組数は異常数ではない。ページ例外0。

`angleStep` は追加回転の内部値の差であり、復帰時の骨の実角度変化ではないので連続性の指標に使わない。連続性の数値は胸と武器原点の位置差。最初の試行で復帰先クォータニオンを上書きする試作コードの不具合を検出し、修正後の再実行結果のみを記録した。ブラウザーの別検査との一時的な並行があったが、修正後は終了コード0・例外0。

本案は不採用。側臥姿勢のすべての設計の不可能性は示さない。完全内包・共面・時点間の辺面交差、斜面・建物・全武器組合せ・実ゲーム操作・通信・スマホ実機・負荷は未確認。
