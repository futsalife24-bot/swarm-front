# 装填中の手元の隔離拡大診断

再現: `node scripts/reload-hands-close.mjs`。出力は `comparison.png` １枚と `report.json`。製品コード・モデル・アニメーションは変更していない。

## 条件

12種のN等級の実製品GLBと `StandardTrooper` の既存クリップを使用。右手ソケットへの接続を確認し、装填時間の25・50・75%を固定入力して各２方向から描画した。各姿勢を4更新している。画像の L/R は手首ボーン中心から武器の最も近い三角形までの距離（mm）で、手の表面や指先と弾倉との接触距離ではない。手袋に大きさがあるため距離だけから接触可否を断定できない。画像では手の反対側や銃の裏に隠れる部分もある。

距離関数は、単独の三角形で距離0と50mm、実際の武器表面の点で距離0、遠方点で1m以上の正負対照を通過。12ファイルはいずれも実行前後のSHA-256が一致。画面例外・取得失敗0。

## 観察

右手は12丁とも選んだ３時点で握り付近に見える。ただし指と握りの接触や貫通は画像から断定できない。ライフル構え５丁は25・75%で左手が弾倉または銃体下の付近に見え、50%ではより下方へ離れて見える。散弾構え３丁も中盤は左手が銃から離れて見える。肩担ぎ４丁は25%に左手が銃体から離れ、50・75%に近づく。これらは既存アニメーションの観察であり、離れる瞬間だけで不具合と断定しない。

全12丁のGLBには独立した弾倉ノードやモデル内アニメーションがないことを確認した。画像とこの構成からは、手が弾倉を外し交換している動作までは確認できず、弾倉の位置に合う装填表現としての合格判断は保留とする。兵士側など別経路の表示処理による表現全般の不在を、この確認だけで証明したものではない。

## 未確認

ボーン中心と武器全体との最近距離であり、弾倉だけとの距離、指先・手袋表面の接触や貫通の判定ではない。選択した３時点以外、実際のゲーム入力に連動した連続映像、他の等級・動作・角度、スマホ実機と負荷はこの診断の対象外。過去の実ゲーム装填記録とはモデル更新時点が一致する保証がないため、本検査の代わりに使わない。
