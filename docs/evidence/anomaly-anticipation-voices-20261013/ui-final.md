# 最終UI確認の到達点（2026-10-13）

実ゲームRendererを使う固定ケース画面とChromeの音声一覧を操作した自己検証。実通信戦闘の代用、独立Chat監査、本人の美術的採用とは区別する。スクリーンショットはツールで目視したが、PNG保存は接続障害で未達。

## 音声

16/16のHTML audioがreadyState=4、error=null、有限duration、currentTime増加（約0.22〜0.49秒）。切り替えると同時再生は1件、HARROWのpauseも確認。聴感による採否と、実戦AudioContextの中断試験ではない。AudioContext中断は回帰テストで確認。

## 画面で確認できたもの

- HARROW全7攻撃の構え・赤予告・発動段階を観測。低姿勢、翼爪発射、爆撃2列、Diveの左右3爪ずつの予告を確認。早期の観測JSONは履歴であり、気になった箇所を省略しない。
- CALYX Slam: 0.25秒は閉じた蕾と赤なし、0.55秒は花弁を開いて前方の赤範囲、1.05秒は前方花弁を下ろし広い予告が消えて短い攻撃軌跡へ移る。
- CALYX PollenShot: 0.40秒は蕾と赤なし、0.85秒は開き始めた花弁と対象付近の大きな赤い着弾範囲、1.65秒は予告解除。後半2枚は範囲視点なので、細かな花弁の動きの評価には使わない。
- 通常FOUNDRY: 最終のシーク修正後、0.78秒で脚・胴の持ち上げと赤なし、1.60秒で前脚を大きく持ち上げて胴を反らせ、赤い範囲を表示。3.15秒では胴脚を戻した解放姿勢と赤予告解除を確認。以前の「姿勢差が小さい」という懸念は確認ページのdt=0に起因した。
- 連結FOUNDRY: 0.20秒の構えと赤なし、実モデル表示まで確認。0.45秒へ切替時に接続が途切れ、最終修正版の赤線と発射段階は未確認。
- 通常種の赤予告は前回観測で確認。RAYは1.65秒以降に赤が出るため1.70秒で赤線を確認。近接円、VOLLEY三射線、PRISM射線も観測した。

## 検証ページ修正と残件

旧fixtureはdt=0のためANT/LEAPER/PLEAT/PRISM/RAY/通常FOUNDRYの遷移ブレンドが進まず、固定時刻の構え姿勢評価が無効だった。4cabb7aで50ms刻みの再現・モデルロード後の再シーク・実cool値へ修正した。HARROW/CALYXは経過時刻でブレンドするので同じ停止には該当しない。

修正後の通常FOUNDRYは再確認済み。ANT近接/射撃・LEAPER・PLEAT・PRISM・RAYの6ケースは再視認を試みたが、Chrome接続障害で未実施。red表示の記録は保持するが姿勢合格とは記載しない。実step/Controllerの回帰検証とは分ける。

ChromeはRuntime.evaluateとFocus命令のタイムアウト、既存ChatのDebugger unattached、全体getStateの60秒タイムアウトを確認。kernel再初期化後のURL限定取得では同じChatの2タブが検出されたが、現存IDを指定した接続も10秒タイムアウトした。再監査ZIPは未送信。承認の不足ではなく、操作接続の外部障害。

## 16時台の再接続後の最終確認

Chromeの新しいタブで復旧し、固定時刻を50ms刻みで進める最終fixtureを再確認した。以下で通常6ケースの姿勢再確認の未完了を解消する（人の美術採用とは別）。

- VOLLEY近接: 0.20秒で頭/胴を沈め赤なし、0.45秒でさらに溜めて円予告、0.85秒で前下方への解放と予告解除。
- VOLLEY射撃: 0.20秒の構え、0.45秒で頭部を起こし三方向の赤い山なり予告、0.85秒で前方解放と赤解除。監査任意R1に従い確認ページの射撃coolを実値2.7へ修正（近接1.2維持）。
- LEAPER: 0.20秒で頭部を前に向け支持脚を広げ、0.45秒は低い構えと赤円、0.85秒で体を前へ倒し赤解除。Leapのままではないことを回帰テストと分けて目視。
- PLEAT: 0.20秒で胴を沈め、0.45秒で深い溜めと前方扇形、0.85秒で頭/鋏の前方解放と赤解除。
- PRISM: 0.20秒は外装の角度変更と赤なし、0.45秒は外装を縦に集め前方赤射線、0.85秒で外装の射撃姿勢と赤解除。
- RAY: 0.51秒で翼を持ち上げた構えと赤なし、1.70秒で翼の角度変化と赤射線、2.10秒で翼を寝かせ解放、赤解除。
- 連結FOUNDRY: 0.20秒で頭部/触手の構えと赤なし、0.45秒で頭部口から前方へ伸びる赤帯、0.85秒で触手/頭の解放と赤解除を目視。確認ページは実弾を生成しないため、この画面を実レーザーの移動確認とは数えない。実弾到達範囲は実step回帰と独立監査で照合済み。

連結炉の旧細線は目視しづらく、製品renderの横幅を2m（プレイヤー中心から射線1m以内の権威判定に対応）、厚み0.06〜0.10mへ変更。距離/壁/地面/時刻/威力は変更なし。この追加は93b7ba0の合格に含めず追加監査へ渡す。

確認ページの連結炉は元の安全配置の向きを保持し、頭部の前に標的、照準高を実戦の地面+1.2m、近距離カメラと赤線本数の診断表示を追加。旧fixtureは頭向きを0へ上書きして胴体側へ狙っていた。製品の頭向きや攻撃仕様の問題とは分ける。

PNGダウンロードは期限切れに続いてChrome接続が切れたため未保存。新接続の新タブで作業は復旧済み。目視した画像はツール出力にあり、保存済みPNGや監査側の目視とは記載しない。実通信長時間戦闘・実スマホ・本人の聴感/美術採用は引き続き未確認。
