# タイトルの操作演出（2026-10-07）

対象は改装版と従来版のタイトル入口だけ。主要ボタンの押し込み・戻り、ホバーとキーボード選択の強調、190msの入場と210msの細いアクセントを追加した。既存の配置・文言・遷移処理を継承し、入力処理を演出終了まで待たせない。

共通実装は `src/client/title-motion.ts`。タイトル表示時に1回登録し、各決定後のDOM監視は最大900msで解除する。二重クリック・キー長押しを抑止し、タッチ取消・フォーカス喪失・非表示時に押し込みと演出を解除する。キーボードから次画面へ移動して戻った際は元ボタンへフォーカスを復元する。動きを減らす設定では移動演出を省略し、設定変更中にも取消する。常時ループ・描画フィルター・戦闘中の継続監視は追加していない。
