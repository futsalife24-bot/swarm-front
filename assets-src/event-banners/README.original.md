# SWARM FRONT — ClaudeCodeデザイン準拠 演出素材

2026-10-12。ClaudeCodeが制作した `event-banners` のアウトラインSVG・PNG・motion.jsonを正本として、7イベントを透過APNG化しました。旧独自草案および却下済み文字APNGメーカーの画像・コードは含みません。ゲームへの実装、公開、BGM/音の変更はしていません。

## 見るファイル
- `preview.mp4`: 本作の提供背景に重ねた全7種の動画。背景は確認用でAPNGには含まれません。
- `comparison-sheet.png`: 左=Claude元PNG、中央=APNG保持フレーム、右=Claudeモバイルレイアウト。同じ見た目を確認できます。
- `motion-storyboard.png`: 各演出の登場途中・保持・退場途中。
- `assets/standard/*.apng`: 960×336、30fps相当
- `assets/mobile/*.apng`: 640×224、15fps相当。Claudeが組み直したモバイル用レイアウトを採用し、単純縮小していません。
- 同名の `.png`: Claudeの正本PNGそのもの。元ファイルとSHA-256が一致します。
- `consumer-manifest.json`: 全イベントのファイルパス、寸法、時間、実測容量、符号化フレーム数、ハッシュ。
- `validation.json`: 全14 APNGの検証結果。
- `source-design/`: 提供されたClaudeCode原稿を未変更で保持。編集用/アウトラインSVG、フォント、motion.json、元検証結果を含みます。
- `build_animations.py`, `render_probe.py`: 今回追加したAPNG再生成ソース。

## 制作上の忠実性
- 構図、字形、色、シンボル、文言はClaude原稿を維持。
- motion.jsonの各レイヤーの開始時刻、長さ、移動量、回転、スケール、マスク方向、減速/加速曲線、シェブロンの時間差、失敗片の一度だけのずれを反映。
- 入場の out-expo は cubic-bezier(0.16,1,0.3,1)、out-quart は (0.25,1,0.5,1)。退場は in-quart=(0.5,0,0.75,0) を指定に従い使用。
- 保持中・APNG既定画像・静止フォールバックは提供PNGそのものです。
- 動作途中のSVGはlibrsvg/Cairoで描画。元PNGのChromiumとはアンチエイリアスに微差があります。静止比較の最大でも、RGBAのいずれかが32/255を超えて異なる画素は0.71%未満。保持・フォールバックの一致とは区別して検証しています。
- 変形中心はSVG図形の境界に基づきます。ブラウザCSSのfill-boxと線幅込み境界に小差があり得ます。見た目の再デザインはしていません。
- 各イベントを約30/15fpsでサンプリング。保持区間を損失なく1フレームへ統合し、実際の符号化数は標準28〜36、モバイル15〜19フレームです。詳細はmanifest参照。

## 実装担当向け契約
1. 形式はPNGコンテナのAPNG、RGBA透過、1回再生。最終フレームは全面alpha=0。APNG非対応時は完成状態の既定PNG画像を表示します。
2. CSSで幅100%、最大960px、aspect-ratio:960/336を維持。モバイル640×224も同じ比率です。画面を黒い一枚絵で覆いません。
3. 演出はゲーム状態を決めません。撤収成功が確定してから撤収完了、進撃目標達成が確定してから作戦達成、生存終了確定から戦闘終了へ。保存/報酬確定をアニメーション終了イベントに依存させないでください。
4. 全レイヤーはpointer-events:none。メニュー・戻る・再出撃・新しいイベントは即時操作可能。古いイベントは即破棄し、同じ演出を重ねません。イベント世代IDまたはAbortControllerで古い終了タイマーが新画面を消すことを防止。
5. APNGの再生完了通知に依存せず、manifestのdurationMsでレイヤーを回収。画像ロード失敗/遅延でもゲームの操作や記録保存は続けます。
6. `prefers-reduced-motion: reduce` またはユーザー演出OFFでは、APNG自体を読み込まずPNGを使用。Claude仕様は静止PNGを160msフェードイン→holdMs保持→160msフェードアウト。動きOFF設定ではフェードも省略可能。メディアクエリだけではAPNGの内部再生が止まらないためsrcも切替。
7. 結果文字は別の通常DOMにも置き、画面読み上げの通知は一回だけ。画像を装飾扱いにする場合はalt=""。実データ・確認ボタンは画像の外で保持します。
8. 低性能端末はmobile版を1枚だけデコード。同時に全14 APNGをプリロードしないでください。mobileファイル最大約0.59MiB、符号化フレーム全展開の概算は最大約11MiB（ブラウザ実装の追加メモリは別）。standard最大約1.53MiB、最大約46MiB。実機測定は未実施です。
9. 30fps/15fpsのAPNGに読みやすい静止保持を含めています。連続点滅・ストロボ・反復振動は追加していません。音は別管理です。
10. 戻る、再出撃、二重クリック、画面切替、途中キャンセル、画像エラー、reduce設定変更をゲーム組込時にテストしてください。この納品ではゲーム統合テストは行っていません。

## 編集・再生成
1. `source-design/svg/editable/` で文言編集、確定後にoutlineへ変換。字形を固定したい場合はアウトラインを正本にします。
2. タイミング編集は `source-design/src/motion.json`。
3. このフォルダで `python build_animations.py`。Python + Pillow + numpy + lxml、librsvg2/Cairo、Inkscape CLI、ffmpegが必要です。ネットワーク接続は不要。独自追加スクリプトはsource-designを削除/変更しません。
4. 元の `source-design/src/build.py`/`build_all.sh` はClaudeの環境依存パスと出力削除を含むため、目的・依存を確認せず直接実行しないでください。
5. バージョン比較のため提供原稿ZIPとハッシュを保持しています。フォントや画像の差し替えは別レビュー対象です。
